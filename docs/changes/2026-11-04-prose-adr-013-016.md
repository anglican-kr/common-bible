## 먼저 보실 곳

뜻이 달라질 수 있는 고침이다. 숫자, 날짜, 인용, 코드 표기는 바꾸지 않았다(아래 「검증」의 사실 토큰 비교).

- ADR-013 「채택 안 함」: 「`project_unit_test_expansion.md`의 계기에 닿은 때」의 「닿은」을 「이른」으로 바꿨다. 원문의 뜻이 흐려, 메모에 적은 계기에 이른 때로 읽었다.
- ADR-013: 「가상의 시간 정보를 참조하므로」(2곳)를 「시간을 가상으로 다루므로」로 썼다. 가상 타이머를 쓴다는 뜻으로 읽었다. 「`unit` job」은 「`unit` 작업」으로, 「glob」은 「패턴」으로 바꿨다.
- ADR-014: 「**Drive 비동기화**」를 「**Drive 동기화 안 함**」으로 바꿨다. 「비동기화」가 비동기 처리로 읽힐 수 있다. 「회귀 +5」, 「+3」은 「회귀 테스트 5개 추가」, 「테스트 3개 추가」로 풀었다.
- ADR-014: 「피커」를 「선택기」로, 「in-flow」를 「일반 흐름 배치」로, 「`:has()`에 기댄다」를 「`:has()` 선택자를 쓴다」로 바꿨다.
- ADR-015 「맥락」: 「**넷에 쿠키 미사용**으로 늘었지만」을 「**네 가지**로 늘었고 쿠키는 쓰지 않았지만」으로, 「그것은 위 문제의 정의를 부정하는 것이다」를 「그러면 위의 평문 저장 문제가 그대로 남는다」로 풀었다. 「(cold-start silent refresh)」는 앞의 「앱을 처음 열 때 조용히」와 같은 말이라 뺐다.
- ADR-015: IDB로 「올린다」(4곳)를 「옮긴다」로 바꿨다. 이 문서에서 「올리다」는 드라이브에 올리는 뜻으로도 쓴다. 캐시 이름의 「rev」는 「번호(rev)」로, 「bump 트리거」는 「번호를 올리는 조건」으로 썼다.
- ADR-015 D4: 「shell은 navigate할 때 network-first로 폴백한다」를 「셸 캐시는 페이지를 열 때 네트워크를 먼저 시도하고 실패하면 캐시를 쓴다(network-first)」로 풀었다. 「cache-first」에도 뜻을 붙였다.
- ADR-015: 「다른 탭이나 창으로 새면」을 「노출되면」으로, 「흐름의 정체」를 「흐름의 이름」으로, `SyncDoc`의 「per-record mtime + tombstone」을 「레코드마다 수정 시각과 삭제 기록」으로 바꿨다.
- ADR-016 상태 줄: 「IDB sidecar」를 「IndexedDB의 메타 저장소」로 풀었다.
- ADR-016: 「quota」를 「할당량」, 「origin」을 「출처」, 「persist」를 「영구 저장」으로 바꿨다(처음 나오는 곳에 영어를 괄호로 남겼다). 「prefetch」와 「preload」는 이미 쓰던 「미리 받기」로 썼다. 「epoch ms」는 「유닉스 시간(밀리초)」으로 바꿨다.
- ADR-016: 「iOS의 7일 규칙을 피할 수 있다」를 「7일 규칙이 적용되지 않게 할 수 있다」로, 「그대로 노출된다」를 「막지 못한다」로, 「「최근」으로 찍혀」를 「기록되어」로 바꿨다. 「`requestIdleCallback`이 호출할 때」는 「`requestIdleCallback`의 콜백이 호출될 때」로 고쳤다.

## 결정 대기

- ADR-013의 기능 이름 「Pull-to-refresh」, 「drawer」, 「save modal」, 「tree render」, 「drag handle」, 「sheet drag」: 후보는 「당겨서 새로고침」, 「서랍」, 「저장 모달」, 「트리 그리기」, 「드래그 핸들」, 「시트 끌기」로 바꾸기와 그대로 두기다. 권장안은 한꺼번에 바꾸기다. 「PKCE primitives」는 「PKCE 기본 함수」가 후보다.
- 「refresh token」, 「nonce」(ADR-015): 후보는 「갱신 토큰」, 「리프레시 토큰」, 그대로 두기다. OAuth 표준 용어라 이번에는 그대로 두었다.
- 「origin」: ADR-016은 「출처」로 바꿨고, ADR-015는 그대로 두었다. 후보는 「출처」(MDN 한국어판), 「오리진」, 그대로 두기다. 권장안은 「출처」이고, 정하면 ADR-015도 맞춘다. 「할당량」(quota)도 「용어」 표에 올릴지 정해야 한다.
- 「id」(ADR-015의 「기기 id」, 「북마크 id」): 후보는 「식별자」, 「아이디」, 그대로 두기다. 권장안은 「식별자」다.
- 「콘텐츠 어드레스 파일」(ADR-015의 `fonts` 캐시): 후보는 「콘텐츠 주소 파일」, 「해시로 주소를 정한 파일」이다.
- 「ring buffer」(ADR-016): 「링 버퍼(ring buffer)」로 썼다. 후보는 「링 버퍼」, 「순환 버퍼」다. 권장안은 「링 버퍼」다.

## 요약

문장 교정 진행 목록 3절(ADR)의 ADR-013, 014, 015, 016을 고쳤다(한글 줄 403줄). 열린 PR이 없어 충돌할 파일이 없었다.

- 기계 검사 항목 전체: 213건에서 97건으로 줄었다. `particle`, `tilde`, `term`은 1건(「화면 읽기 프로그램」을 「스크린 리더」로)에서 0건이 됐다. 남은 것은 대부분 `english?`(제품 이름, 단위, OAuth 용어)와 「채택 안 함 날짜 · 이유 · 재검토」 줄의 가운뎃점, ADR 상태 줄의 줄표다.
- 기계 검사 밖에서 고친 곳은 약 90곳이다. 줄표와 가운뎃점, 「+」, 「/」로 이은 명사(약 30곳)와 화살표(→)로 이은 동작을 조사와 서술어로 풀었고, 「부딪치다」, 「새다」, 「집어」, 「찍혀」, 「내놓는다」 같은 비유 동사와 영어 낱말(revoke, ciphertext, legacy, string, blob 등)을 바꿨다. 코드 이름과 값(`null`, `fetch`, `'hidden'`, `totalSize`)에 역따옴표를 달았다.
- 검토 단계에서 4곳을 다시 고쳤다. ADR-013의 「**Node 자체 테스트 러너(`node --test`)**로」는 굵은 글씨 닫는 표시 뒤에 조사가 붙어 GitHub가 굵게 그리지 않으므로 「**Node 자체 테스트 러너**(`node --test`)로」로 바꿨다. ADR-016의 「7일 규칙이 적용되지 않는다」는 원문의 「할 수 있다」를 살렸고, `pickEvictions` 문장의 어순을 바로잡았다. ADR-015의 「실패하면 캐시로 폴백한다(network-first)」는 뜻이 겹쳐 「캐시를 쓴다」로 썼다.
- 제목 2개를 고쳤다. ADR-014 「# ADR-014: 검색 히스토리 + 검색 입력창 터치 타깃」의 「+」를 「와」로, ADR-015 「### 보조 결정 — 쿠키 미사용」의 줄표를 쌍점으로 바꿨다. ADR-014 제목을 인용한 `docs/topics/search.md` 「결정」의 한 줄을 함께 고쳤다. 두 제목으로 오는 링크 앵커는 없었다. ADR-015 「### 캐시 이름에 rev를 붙여 따로 올리기」는 ADR-001의 같은 제목(「캐시 이름에 rev를 붙여 …」)과 맞춰 그대로 두었다.
