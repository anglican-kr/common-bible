# style: 오디오 플레이어 재생 버튼·진행바 색상 중립화

## 요약

오디오 플레이어의 재생 버튼과 진행바 포인터(thumb) 색상을 색상 스킴을 추종하던 `--theme` 에서 테마 중립 색 `--accent`(고정 중립 차콜)로 교체했습니다.

## 변경 내용

`css/style.css` 의 다음 속성에서 `--theme` → `--accent`:

- `.audio-play-btn` 배경 (재생/일시정지 버튼)
- `.audio-progress` 진행바 채움 그래디언트
- `.audio-progress::-webkit-slider-thumb` 및 `::-moz-range-thumb` 배경
- thumb 포커스/호버 링 (`color-mix` 알파)

재생 버튼 아이콘은 그대로 `--bg` 라 차콜(라이트)·밝은 회색(다크) 배경 양쪽에서 대비를 유지합니다.

## 영향

테마색(`--theme`, 색상 스킴 추종) 적용 범위가 **절 번호·단락 기호·FAB·오디오 플레이어 4곳 → 절 번호·단락 기호·FAB 3곳**으로 좁혀졌습니다. 오디오 바는 하단 chrome 표면(frosted glass)에 얹히는 컨트롤이라 스킴 시그니처보다 chrome 톤 일관성이 자연스럽다는 판단입니다.
