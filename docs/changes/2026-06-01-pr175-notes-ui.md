# feat: 노트 UI·마크다운 엔진 (ADR-026 Stage 1a-②)

## 개요

ADR-026 노트의 **사용자 UI**(1a-②) — 데이터·동기화 계층(#174)을 화면에 붙입니다. `/notes` 플레이스홀더가 실제 목록/에디터로 대체됩니다. base = `release/1.6.0`.

## 포함

**마크다운 엔진** `js/app/markdown.js` (무의존, 보안 우선)
- `renderMarkdown`: 제목·굵게/기울임·인라인코드·인용·순서/비순서/체크박스 목록·hr·문단(단일 줄바꿈=`<br>`). **모든 텍스트 이스케이프 후 화이트리스트 태그만** — 원시 HTML·`style`·이벤트핸들러 차단. 링크는 `http(s)`·내부경로만(외부 `noopener noreferrer`, `//host` 거부).
- `plainText`(검색·제목), 도구모음 순수 변환(`wrapSelection`/`toggleLinePrefix`/`insertLink`).

**노트 화면** `js/app/notes.js`
- 목록: Drive 게이트, 새 노트, 동기화 상태칩, 노트 행, 빈 상태, `onChange` 라이브 갱신.
- 에디터: 제목·편집가능 날짜·마크다운 textarea + **도구모음**(굵게/기울임/제목/목록/인용/체크박스/링크, 선택 보존) + **편집/미리보기 토글**(미리보기는 `renderMarkdown` 안전 렌더) + 삭제.
- **자동저장**: 디바운스(600ms)+blur → `notesStore.updateNote`(내용 변경 시만 bump). 내구성은 `beginEditing/endEditing`로 store에 위임.

**진입점**: 읽기 화면 절 선택 액션바 **"노트" 버튼** → 선택 구절을 인용블록+출처 링크로 단 새 노트 → 에디터.

route()·index.html·sw.js·types·CSS 배선.
