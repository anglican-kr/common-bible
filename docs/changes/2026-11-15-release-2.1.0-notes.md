## 요약

2.1.0 릴리스 PR(#556)을 머지한 뒤 태그를 만들기 전에 #562, #563, #564가 main에 들어왔다. 릴리스 노트 초안은 머지된 원장 `docs/changes/2026-11-14-release-2.1.0.md`에 있어 고칠 수 없으므로, 세 PR을 반영한 초안 전체를 이 원장에 다시 적는다. GitHub Release와 태그 메시지는 아래 「릴리스 노트 초안」을 쓴다. 버전은 2.1.0 그대로다.

## 확정 · 근거

- **버전은 2.1.0으로 둔다**(사용자 결정 2026-11-15). 2.0.2로 낮추는 안을 검토했다가 하지 않기로 했다.
- **#562와 #563을 노트에 넣는다**(사용자 결정 2026-11-15). 두 PR은 이번 판에서 새로 만든 기능을 다듬은 것이라 `docs/writing.md` 「릴리스 노트」의 규칙으로는 「버그 수정」에 넣지 않는다. 그래서 따로 고친 문제로 적지 않고 다음처럼 넣었다(구현하며 정함).
  - #562(운문에서 선택 구절이 시작되는 절의 번호 위치): 선택 구절을 〔 〕로 묶는다는 「기능 개선」 항목에 한 문장을 더했다. 번호가 밀려 보이던 것은 운영에 나간 적이 없어 고친 문제로 적지 않는다.
  - #563(소속교회를 세례명 앞에, 설명 단추를 크게): ⓘ 단추는 2.0.1의 「백업 & 동기화」에도 있던 것이라 단추를 키운 것을 「기능 개선」에 한 줄로 적었다. 소속교회를 세례명보다 먼저 보이는 차례는 「새 기능」이 이미 그 차례로 적고 있어 더하지 않았다.
- **#564**(데스크톱 헤더를 한 줄 상단 바로): 그 원장 「릴리스 노트에 더할 것」의 네 줄을 「기능 개선」 끝에 그대로 옮겼다. 일반 사용자가 읽는 글이라 「데스크톱」을 「컴퓨터 화면」으로 적었다(구현하며 정함. 사용자가 고른 표현은 아니다).
- **변경 목록**: 릴리스 PR 본문의 「변경 사항」(`changelog.py 2.0.1 HEAD`의 출력) 뒤에 앱 PR 셋이 더해진다. #562, #563, #564다. 본문 데이터는 바뀌지 않았다. 목록은 git 이력에 있어 여기 다시 적지 않는다.
- **이 초안에 적지 않은 것**은 릴리스 원장과 같다(성무일과 전례독서 데이터, 문서와 시험 정리).

## 릴리스 노트 초안

### 새 기능

- 카카오톡, 라인, 네이버, 인스타그램, 페이스북에서 링크를 누르면 본문이 보인 뒤 Safari나 Chrome 같은 기기의 브라우저로 넘어갑니다. 이런 앱 안의 화면에서는 홈 화면에 앱을 설치할 수 없고, 저장한 북마크도 브라우저와 따로 보관되기 때문입니다. 넘어가지 못한 때에는 「브라우저에서 열기」와 「주소 복사」 단추가 있는 안내가 열립니다.
- 설정의 「전례독서」에서 소속교회를 고를 수 있습니다. 고른 교회의 축성일에는 전례독서가 축성일 독서를 먼저 보여 줍니다. 그날이 주일이나 대축일이면 축성일은 전례독서 목록의 맨 앞 줄에 나옵니다.
- 소속교회가 속한 교구의 설립일에는 그날의 본기도 뒤에 교구 설립 본기도가 이어집니다. 서울교구와 대전교구는 5월 27일, 부산교구는 6월 1일입니다.
- 설정의 「전례독서」에서 세례명을 고를 수 있습니다. 고른 성인의 축일에는 전례독서 목록에 그 성인의 독서가 나옵니다.

### 기능 개선

- 전례독서에 나오는 교회 축성일을 「2026 전례독서」 책자에 맞췄습니다.
- 전례독서에서 「시편 116 또는 116:1-9」처럼 뒤의 본문이 앞 본문의 일부인 독서를 「독서 1」, 「독서 2」로 나누지 않고 하나로 보여 줍니다. 긴 본문을 싣고, 짧게 읽을 때 빼는 절을 〔 〕로 묶습니다. 성 십자가의 날(9월 14일), 성 십자가 발견(5월 3일), 라틴 문 앞의 사도 성 요한(5월 6일)의 시편, 성지주일 가해와 다해의 수난 복음, 세례명의 축일에 나오는 성인 공통 독서가 해당합니다. 시편처럼 행을 나누어 적은 본문에서는 〔를 왼쪽 여백에 두어, 절 번호와 본문의 첫 글자가 다른 절과 같은 자리에 있습니다. 화면 낭독기는 〔 〕로 묶은 절의 처음과 끝을 「선택 구절 시작」, 「선택 구절 끝」으로 읽습니다.
- 모바일 화면 아래 탭 바의 홈 아이콘을 집에서 펼친 책으로 바꿨습니다.
- 성서에 나오는 인물의 이름을 공동번역 성서의 표기로 바꿨습니다. 「스테파노」는 「스데파노」로, 「미카엘」은 「미가엘」로 나옵니다.
- 설정에서 설명을 여는 ⓘ 단추와 설명을 닫는 단추를 키워 누르기 쉽게 했습니다.
- 컴퓨터 화면의 위쪽 메뉴를 한 줄로 바꿨습니다. 왼쪽에 「성서」, 「캘린더」, 「북마크」, 가운데에 제목, 오른쪽에 검색창과 설정이 있고, 본문을 내려 읽는 중에도 그대로 보입니다. 이전에는 조금만 내려도 검색창과 캘린더, 설정 단추가 사라져 맨 위로 돌아가야 했습니다.
- 컴퓨터 화면의 위쪽 메뉴에 지금 보는 곳이 성서인지 캘린더인지 표시됩니다.
- 컴퓨터 화면에서 「북마크」를 누르면 어느 화면에서나 북마크가 열립니다. 이전에는 성서의 장 화면에서만 열 수 있었습니다.
- 컴퓨터 화면의 캘린더와 전례독서에서 「오늘」 단추를 날짜 오른쪽으로 옮겼습니다.

### 버그 수정

- 설날이나 추석이 주일과 겹치는 날에 캘린더와 전례독서 제목이 주일이 아니라 명절로 나오던 문제를 고쳤습니다. 이제 주일이 먼저 나오고, 명절 독서는 전례독서 목록에서 고를 수 있습니다. 2027년 2월 7일이 처음 해당하는 날입니다.
