# feat: 검색 옵션 — 책 picker·결과 내 검색·진입 시 최근 검색 (ADR-033)

## 요약

검색 화면에 **검색 옵션 바**를 도입하고, 진입 시 **최근 검색 목록**을 노출합니다. 옛 버전이 `in:` 연산자를 칩으로 노출했던 것을 대체·확장합니다. Apple HIG의 검색 패턴(스코프/필터 바 · 칩 · recents 목록 · 시트 선택)을 따릅니다. (ADR-033)

## 변경 내용

### 1. 책 picker
- 검색 옵션 바의 **"책 선택"** 버튼 → 분류별(구약·외경·신약, 외경 설정 반영) 그룹 다중 선택 **시트**(`#book-filter-sheet`).
- 선택한 책은 입력창 아래 **제거 가능한 칩**으로 표시.
- 내부적으로는 워커의 책 제한(`in:`/`restrictBooks`)을 재사용 — 새 `scopeBooks` 메시지로 book id 전달, 타이핑 `in:` 토큰과 합집합.
- 시트는 `createOverlay` + `attachSheetDrag`(ADR-032) 재사용. 모바일 바텀 시트 / 데스크탑 중앙 모달.

### 2. 결과 내 검색 (AND)
- 검색어가 있을 때만 노출되는 **"결과 내 검색"** 입력. 추가한 낱말이 기존 검색어와 **AND** 결합되어 두 낱말이 모두 든 절만 남김.
- 워커 `gatherResults`에 다중 키워드 AND 매치 추가 (`andTerms` 메시지). 부분문자열 선형 스캔(ADR-005) 유지.

### 3. 진입 시 최근 검색 목록 + 삭제
- 빈 쿼리로 `/search` 진입 시 **"최근 검색"** 목록 노출(없으면 기존 안내 + 검색 예시).
- **행 탭 = 재검색**, **× = 개별 키워드 삭제**, 머리글 **"지우기" = 전체 삭제**.
- ADR-014 저장 모델(`bible-search-history`, 로컬 전용)을 그대로 사용하며 헤더 ▾ 드롭다운과 같은 저장소를 공유해 동기화.

### 4. 노트 검색 대비
- 검색 범위(scope)를 검색어 필드에서 분리한 별도 바로 격리 → 나중에 책 picker 위에 **성서/노트 세그먼트**를 끼우는 형태로 확장.

## 상태 모델
- 필터는 URL 인코딩: `?q=…&in=<bookId>&and=<낱말>&page=…` (반복 파라미터). 히스토리·뒤로/앞으로·탭 복원(ADR-031)·페이지네이션·공유 링크가 모두 일관.
- 새 검색어 커밋은 **책 범위 유지**, 결과 내 검색·페이지 **리셋**. 필터 변경은 페이지 1 리셋.
