# docs: 코드 주석 언어 규칙 완화 — 데이터 저장소와 맞춤

두 저장소가 컨벤션을 공유하는데(커밋 메시지 규칙도 「앱 저장소와 동일」) 여기만 `- 코드 주석: 영어` 로 남아 어긋나 있었다. 데이터 저장소는 2026-08-29 에 고쳤다(data `9436dd6`).

거기서 규칙의 문제가 실제로 드러났다 — 리뷰 봇이 파이프라인의 **근거 주석**(왜 이 검사가 절기·주만 봐서는 안 되는가)을 「저장소 컨벤션 위반」으로 지적했고, 그 규칙 때문에 도메인 주석 둘을 영어로 옮겼다가 되돌렸다. 품계·전례색·소재일 같은 용어가 한국어고, 그 주석들은 기도서 대조 결과와 사용자 확인 날짜를 남기는 자리라 번역하면 근거가 흐려진다.

언어를 규칙이 아니라 **내용**이 정하도록 바꾼다:

- 코드가 왜 그렇게 도는지(경계·자료구조·성능) → 영어
- 도메인의 근거와 결정 이력 → 한국어
- 규칙에 맞추려고 번역하지 말 것
