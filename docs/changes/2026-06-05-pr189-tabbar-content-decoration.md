# style: 탭 dock 뒤 콘텐츠 데코레이션 scrim 추가

## 배경

탭바 도입(ADR-029/030) 후속. floating 캡슐(탭 바·검색 원형·미니 오디오)이 투명 `#tab-dock` 위에 떠 있어, 캡슐 **양옆 틈·아래 sliver**로 스크롤되는 본문이 그대로 노출돼 지저분했다.

## 변경

dock 바로 아래(z = `--nav-z` − 1, 스크롤 콘텐츠 위)에 화면 폭 전체 **페이드 그래디언트 scrim**(`#tabbar-scrim`, 순수 장식 `aria-hidden`)을 깔아 본문이 캡슐에 **닿기 전에** 배경색으로 사라지게 한다.

- **기하**: `--scrim-solid`(= `--tabbar-reserve` ≈ 캡슐 윗변)까지 솔리드 `--bg`로 캡슐 영역·옆틈·아래를 가리고, 그 위 `--scrim-runway`(3rem) 구간에서만 투명으로 페이드. 절대 길이 stop 으로 솔리드 경계를 캡슐 윗변에 고정(height 변동에 안 흔들림).
- **얇은 blur**: `::before`에 `backdrop-filter: blur(8px)` + 상단 fade-out mask 로 '유리 밑으로 사라지는' 질감 보강. blur 미지원 브라우저는 그래디언트만으로 동작.
- **오디오 공존**: 오디오 바 표시 중(축소 아님)이면 `:has()`로 솔리드 경계를 오디오 바 높이(3.5rem)만큼 상향.
- **상태 동기화**: 절 선택 모드는 dock 과 함께 숨김. 모바일(≤768px) 전용. `--bg` 토큰 추종으로 다크/라이트 자동 대응.

## 검증

- dev 스크린샷(라이트·다크) — 본문이 캡슐 닿기 전 배경색으로 자연스럽게 페이드, 캡슐은 테두리+그림자로 배경과 구분 유지.
