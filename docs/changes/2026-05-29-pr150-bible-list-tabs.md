# feat: 성서 목록 탭 통합 + 읽기 헤더 내비게이션 재설계

## 요약

흩어져 있던 성서 목록 네 화면(첫 페이지 · 구약 · 외경 · 신약)을 **탭 스위처 한 페이지**로 통합하고, 그에 맞춰 읽기 화면 헤더 내비게이션을 재설계했습니다. 상세 결정은 **ADR-024**.

## 변경 내용

### 1. 단일 탭 페이지
- `/` 와 세 구분 라우트(`/old_testament` · `/deuterocanon` · `/new_testament`)가 모두 `renderBookList(books, activeDivision)` 하나로 렌더됩니다. 차이는 활성 탭뿐.
- 탭 집합은 **설정의 제2경전 옵션**을 반영합니다.
  - canonical: `구약 | 외경 | 신약` (3탭)
  - vulgate: `구약 | 신약` (2탭, 외경은 구약 탭에 편입)
- 탭은 구분 라우트로 가는 `<a>` 라 **딥링크 · SEO 색인(ADR-009) · sitemap · 읽기 헤더 홈 버튼 타깃**이 그대로 유효합니다.
- 탭 스트립은 `flex:1` 로 **가로 폭을 꽉 채웁니다**. 구약 탭은 기존 소분류(오경·역사서·시서와 지혜서·예언서) 유지.

### 2. 읽기 헤더 홈 버튼
- 장 · 머리말 · 장 목록 헤더 좌측 버튼을 *뒤로가기* 대신 **홈 버튼**(`buildHomeBtn`)으로 교체. `history.back()` 이 아니라 항상 그 책이 속한 **구분 탭**으로 이동합니다.

### 3. 상단 브레드크럼 제거
- `<nav id="breadcrumb">` 와 모든 `setBreadcrumb` 호출 · 관련 CSS 제거.

### 4. 설정(⚙) 버튼 반응형 배치
- **데스크탑**: 기존대로 상단 검색줄에 유지(스크롤 시 함께 접힘).
- **모바일**: 항상 보이는 제목 헤더로 이동 → 읽는 중에도 접근 가능. 단일 팝오버를 다중 트리거가 공유(`buildSettingsTrigger`).
