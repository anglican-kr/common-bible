## 요약

전례독서 화면 e2e 둘이 2026-12-20(대림 4주일 나해)의 시편 89를 복사하는데, 그날 첫 세트가 성모송가로 바뀌어 실패했다. 두 테스트가 주소에 `?set=2`를 붙여 시편 89 세트를 열게 했다.

## 확정 · 근거

- data#42(2026-10-25)가 기도서대로 대림 4주일 나해의 성모송가 세트를 첫 세트로, 시편 89 세트를 둘째로 바꿨다. 화면은 첫 세트를 먼저 보이므로 테스트가 성모송가를 복사했다.
- 실패는 #429 작업 중 e2e 전체를 돌리다 찾았다. e2e는 CI에서 돌지 않아 data#42 머지 때 드러나지 않았다.
- 테스트가 보려는 것(◯, ¶, 부 소제목, 영광송, 출처 표기)은 그대로이고, 연 세트만 바꿨다. 성모송가 복사는 같은 파일의 다른 테스트가 본다.

- e2e 전체는 #429 작업 때(같은 날, 데이터 `02d9d39`와 같은 독서 데이터) 이 둘을 빼고 376개가 통과했다.
