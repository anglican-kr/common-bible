# chore: 1.6.4 릴리스

## 이번 릴리스에서 달라진 점

### 북마크를 오름차순·내림차순으로 정렬할 수 있어요

북마크 목록 정렬에 **방향 선택**이 생겼어요. 이름순·저장순 같은 기준에 더해 오름차순(예: 오래된 것 → 최신)과 내림차순을 골라 볼 수 있고, 지금 고른 기준이 어떤 순서로 늘어놓는 건지 짧은 설명도 함께 보여줍니다.

### (데스크탑) 검색의 책 범위 고르기가 옆에서 펼쳐지는 패널로 바뀌었어요

데스크탑에서 검색할 책 범위를 고르는 화면이, 화면 한가운데 뜨던 작은 창에서 **오른쪽에서 미끄러져 나오는 패널**로 바뀌었어요. 북마크 패널·인용 구절 패널과 같은 모양·동작으로 통일했습니다.

또 검색창에 커서를 두면 **어느 화면에서든** 책 필터 버튼(깔때기 모양)이 검색창 왼쪽에 나타나, 곧바로 책 범위를 지정해 검색할 수 있어요. 예전에는 검색 화면에서만 보였습니다. (데스크탑 북마크 패널의 폴더 버튼 순서도 수정 → 삭제 → 읽기로 다듬었어요.)

### 북마크를 쓰다 마주치던 자잘한 문제를 고쳤어요

- 선택 모드에서 항목을 폴더로 옮길 때 동작이 멈추던 문제를 고쳤어요.
- 화면을 눕혔을 때(가로 모드) 북마크 `⋯` 메뉴가 잘려 보이거나, 화면을 돌릴 때 메뉴 높이가 어긋나던 문제를 손봤어요.

> 이번 릴리스는 위 변화 외에 북마크 기능의 내부 구조를 여러 조각으로 정리하고(동작은 그대로) 자동 테스트를 크게 보강한 작업이 많습니다. 사용 화면에서 바로 보이지는 않지만, 앞으로의 기능 추가를 더 안전하고 빠르게 해 줄 바탕 정리예요.

> **Overview**

> 
> **북마크:** The ⋯ menu gains **per-field 오름/내림** sort direction (stored per mode in `localStorage`, defaults unchanged), **field-specific direction hints** in the menu, and **scrollable overflow** with JS `sizeMenu()` on open and on `resize` while open (landscape / rotation). **bookmark-core** sorts via an ascending comparator with sign flip for `desc`; `_isDescendant` and shared help copy move to core. **Fix:** `_isDescendant` export so folder moves in select mode no longer throw.
> 
> **검색·데스크탑 UI (CSS + related JS in release):** Desktop **book-filter** shifts from centered modal to a **right slide-in panel** (close animation, resize grip, × close). **Funnel** shows when the search field is focused on any screen, not only on `/search`. Desktop bookmark drawer folder rows reorder trailing actions to **수정 → 삭제 → 읽기** via flex `order`.
> 
> **Docs/tests:** ADRs and QA notes for sort direction, menu scroll, and ADR-034 split; known-issues for headless folder-toggle e2e.
