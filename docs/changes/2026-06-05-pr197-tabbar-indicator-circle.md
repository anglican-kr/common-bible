# fix: 탭 인디케이터를 정사각 슬롯 기반 정원으로 (타원 깨짐 수정)

## 요약

탭 인디케이터가 **가로로 찌그러진 타원**이 되고 우측 검색 근처 레이아웃이 흐트러진 문제를 수정했습니다.

### 원인
직전 PR(#196)에서 인디케이터를 `.tab-item { flex: 0 1 auto }` + `.tab-icon-wrap { height:100% + aspect-ratio:1 + max-width:100% }` 로 구성했는데, 이 조합이 flex 콘텐츠 사이징과 얽혀 실제로는 폭이 불안정한 타원이 됐습니다.

### 수정
- 각 `.tab-item` 을 **명시 정사각 슬롯**으로 고정: `width: calc(--touch-target + --space-2*2)` (= 바 높이 60px), `flex: 0 1 auto`, `min-width: 0`.
- `.tab-icon-wrap` 은 `width: 100% + aspect-ratio: 1` 로 슬롯을 채워 **슬롯 폭에서 높이를 파생** → 좁은 화면에서 슬롯이 축소돼도 **항상 1:1 정원** 유지.
- `height:100%` / `max-width:100%` 의존 제거(확정적 사이징).

### 결과 (요청 스펙 충족)
- 아이콘이 들어갈 공간(인디케이터) = **가로세로 1:1**.
- **탭 바 양끝 반원 지름 = 인디케이터 지름 = 검색 버튼 지름 = 60px** (모두 같은 토큰 `--touch-target + --space-2*2`).
- 아이콘은 슬롯/wrap flex 중앙 정렬로 **인디케이터 정중앙**.
- 양 끝 슬롯은 `space-between` 으로 캡 안쪽에 정렬되어 끝 인디케이터가 캡과 동심.
