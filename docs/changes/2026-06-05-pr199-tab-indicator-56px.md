# style: 활성 탭 56px 정원 인디케이터 복원 (테마색 틴트)

## 요약

활성 탭에 **56px 정원 인디케이터**를 다시 넣었습니다. 후속³(PR #198)에서 인디케이터를 없앴더니 활성 탭의 시각적 앵커/히트영역 단서가 약해서, 테마색 언어로 복원했습니다.

## 변경 (CSS)
- `.tab-icon-wrap` 지름: 슬롯 채움(≈60px) → **56px**(`calc(--touch-target + --space-2*2 − --space-1)` = 바 높이 60 − 상하 2px 인셋). `max-width: 100%` 로 좁은 화면에서 슬롯 초과 방지(정원 유지).
- 활성 탭 인디케이터 복원: `.tab-item.active .tab-icon-wrap { background: color-mix(--theme 14%, transparent) }`. 아이콘 색은 그대로 `--theme`.
- 검색 버튼 활성도 동일 언어: `#tab-search.active` 에 `--theme` 14% 틴트(다크 18%) 복원.
- 모핑 홈(`.collapsed`/`.searching`)은 60px 캡슐 자체가 인디케이터라 안쪽 56px 틴트 제거(`background:none`) — 이중 원 회피.

## 결과
- 활성 탭/검색 = **아이콘 `--theme` + 56px 테마색 14% 틴트 정원 인디케이터**.
- 인디케이터 지름 56px, 탭 바 높이 60px(상하 2px 인셋). 양 끝 인디케이터는 캡 안쪽에 2px 여백으로 안착.
