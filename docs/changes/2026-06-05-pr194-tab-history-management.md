# feat: 탭별 위치 복원(탭 히스토리) 도입 (ADR-031)

## 요약

탭(홈·북마크·설정·검색)을 오가다 같은 탭으로 돌아오면, 그 탭이 **마지막으로 본 라우트 + 스크롤 위치**로 복원합니다(iOS 탭 관용구). 성서를 읽다 북마크·설정 탭에 갔다가 홈으로 돌아오면 **읽던 장·지점**으로 복귀합니다.

기존엔 홈 탭 버튼이 정적 `href="/"` 라, 읽다가 다른 탭에 갔다 홈으로 오면 항상 성서 목록(루트)으로 떨어져 컨텍스트를 잃었습니다.

## 동작

- **홈** — 다른 탭(북마크·설정·검색)에서 홈 탭을 누르면 마지막 읽던 위치로 복원. **이미 홈 스택에 있으면 기존대로 루트(성서 목록)로** — iOS pop-to-root. → 읽다가 홈 누르면 목록으로 가던 기존 동작은 **회귀 없이 유지**, "다른 탭→홈 복귀" 케이스만 새로 복원됩니다.
- **검색** — 돋보기 버튼을 다시 열면 마지막 검색어·결과를 그대로 복원(`/search?q=…`), 입력창은 바로 수정 가능. (사용자 결정: "마지막 검색 복원")
- **북마크·설정** — 단일 라우트라 스크롤 위치만 경로 키 메모리로 자동 복원.
- **뒤로/앞으로(popstate)** 스크롤 복원도 같은 메모리로 일관 처리(부수 이득).

## 구현

- `js/app/tab-history.js`(신규, `window.tabHistory`): `scrollMemory`(경로→scrollY) + `lastPathForTab`. `route()` 가 떠날 때 `onRouteStart()` 저장, 도착 후 `onRouteEnd()` 복원. 모듈 로드 시 `history.scrollRestoration = "manual"`(커스텀 저장·복원 정확성 — auto 면 popstate 시 브라우저가 먼저 스크롤을 옮겨 떠나는 위치를 못 읽음).
- `js/app/views-routing.js`: `route()` 상단 `onRouteStart` + `_routeSeq` 발급, `finally` 에서 시퀀스 일치 시 `onRouteEnd`. **재진입 가드** — 내부 리다이렉트(books+resume, 외경 vulgate, 검색 verse-ref auto-nav)로 route 가 재진입하면 낡은 바깥 호출의 복원을 차단.
- `js/app/tabbar.js`: 홈 탭 클릭 가로채기, `openSearch()` 가 `lastPath("search")` 로 진입.
- `index.html`·`sw.js`: 모듈 등록 + SHELL 프리캐시. `js/types.d.ts`: 타입.

> [!NOTE]
> **Medium Risk**
> Touches core SPA routing, scroll restoration, and tab-bar navigation; regressions could wrong-scroll on chapter links or home/search tab behavior, though POP-only restore and _routeSeq guard reduce that risk.
> 
> **Overview**
> **ADR-031** adds **in-session tab history** so switching tabs (or browser back/forward) can bring back each tab’s last **route + scroll**, similar to iOS tab apps.
> 
> A new **`js/app/tab-history.js`** (`window.tabHistory`) keeps per-path `scrollY` and per-tab last URLs. **`route()`** in `views-routing.js` saves scroll on leave, restores only when **`requestRestore()`** was set (tab switch or `popstate`), and uses **`_routeSeq`** so nested redirects don’t apply stale restore. **`history.scrollRestoration = "manual"`** makes leave/restore scroll positions reliable.
> 
> **`tabbar.js`** intercepts home from another tab → `lastPath("home")`; search open → `lastPath("search")`; bookmarks/settings → `requestRestore` on cross-tab entry while keeping pop-to-root when already on home.
> 
> Docs (**ADR-031**, architecture index, `CLAUDE.md`), **`index.html` / `sw.js`** shell load, **`types.d.ts`**, and **`tabOf`** unit tests are included. Scroll/restore wiring stays **e2e**-tested per ADR-013.
