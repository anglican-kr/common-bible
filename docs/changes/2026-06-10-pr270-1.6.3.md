# release: 1.6.3

## 릴리스 노트 (초안)

가로로 화면을 돌렸을 때의 사용 경험을 손봤습니다.

- 휴대폰을 가로로 눕혀도 아래쪽 탭 막대가 그대로 남아, 세로로 볼 때처럼 화면 사이를 편하게 오갈 수 있습니다.
- 가로 모드에서 오디오 재생 막대가 작게 정리되고, 읽던 곳으로 바로 돌아가는 "이어읽기" 단추와 검색이 같은 자리에서 깔끔하게 보입니다.
- 아이폰을 가로로 돌렸을 때 글자가 제멋대로 커지던 현상을 막았습니다.
- 홈 화면으로 돌아오면 마지막으로 읽던 책 카드가 또렷하게 강조됩니다.
- 책갈피 폴더의 "읽기" 단추 모양과 정렬을 다듬고, 책갈피를 밀어 넘길 때의 반응을 일관되게 맞췄습니다.
