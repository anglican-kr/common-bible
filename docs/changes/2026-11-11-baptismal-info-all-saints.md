## 요약

설정에서 세례명 옆 ⓘ 단추를 누르면 열리는 설명에 둘째 문장을 덧붙였다. 성인 목록에서 자기 세례명을 찾지 못한 사람에게 모든 성인의 날을 알리는 글이다. 앞 문장은 그대로다. 보이는 글이 달라질 뿐 동작은 바뀌지 않는다. 문구는 [ADR-041](../decisions/041-settings-structure-and-lectionary-preferences.md) §7이 정해 두었으므로 코드보다 먼저 ADR의 문구를 고쳤다.

> 세례명과 일치하는 성인 축일에 성인을 기념하는 전례독서를 보여줍니다. 성인 목록에 세례명이 없는 분들에게는 모든 성인의 날이 있습니다! ❤️

## 확정 · 근거

- **둘째 문장은 사용자가 정했다**(2026-11-11). 느낌표와 ❤️까지 정한 대로 넣었다. 소속교회 설명(「…보여줍니다.」)과 어조가 다르다.
- **동작은 바꾸지 않았다.** ADR-041 §5가 이미 「맞는 성인이 없으면 모든 성인의 날로 둔다」는 ADR-036의 폴백을 이 설정에 쓰지 않기로 했다. 목록에 없으면 「선택 안 함」으로 두고, 모든 성인의 날은 누구에게나 그날의 기본 독서다. 새 문장은 이 사실을 알리는 안내 글이다. §7의 문구 옆에 이 뜻을 적었다.
- **일부러 바꾸지 않은 것**: 설명 상자의 줄바꿈. `.settings-drive-info-desc`에는 `word-break: keep-all`이 없어 모바일에서 「없는」이 두 줄에 걸쳐 끊겨 보인다. 모든 ⓘ 설명이 같은 상자를 쓰므로 이 PR의 범위 밖이다.

## 검증

- `node --test tests/unit/*.test.js`: 1,712개 통과(문서 검사 23개 포함).
- e2e `tests/e2e/test_settings.py`의 세례명 관련 3개 통과(작업 폴더 서버로 실행). 설명 문구를 확인하는 시험이 새 문장까지 확인하도록 고쳤다.
- 손으로 확인한 것: 데스크톱 설정 팝오버와 모바일 설정 화면(`/settings`)에서 설명을 열어 세 줄로 줄바꿈되고 ❤가 보이며 닫기 단추가 제자리에 있음을 화면으로 봤다.
- 돌리지 못한 것: 타입 검사(`npm run typecheck`). 작업 폴더에 `node_modules`가 없다. 문자열 한 줄만 바뀌어 CI의 `Unit tests`가 돌린다.
