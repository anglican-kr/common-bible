## 요약

버전을 2.2.6에서 2.2.7로 올린다(`scripts/release.py patch`). 2.2.6 뒤에 아이폰의 Safari에서 선창 끝 ◯가 혼자 다음 줄로 넘어가고 운문 행의 여는 따옴표만 줄 끝에 남던 줄바꿈의 수정(#658, #661), 하단 막대를 본문 글자 선에 맞춘 것(#662), 전례시편 119:104의 쉼표를 바로잡은 본문 데이터(데이터 #95, 앱 #660)가 들어간다. e2e의 통계 차단(#659), `.python-version` 삭제(#663), 아이폰 확인 기록(#664)은 개발용과 문서다.

아래 「릴리스 노트 초안」은 머지한 뒤 GitHub Release에 그대로 쓴다. 「변경 사항」은 `python3 scripts/changelog.py 2.2.6 HEAD`의 출력이고, 끝의 비교 링크만 2.2.7 태그를 가리키게 고쳤다.

## 확정 · 근거

- **버전은 2.2.7이다.** 운영(`https://bible.anglican.kr/version.json`)이 2.2.6과 앱 커밋 `0fa59f0`을 내려 준다(2026-11-24에 확인). 열린 PR은 없었다.
- **노트의 짜임**(`docs/writing.md` 「릴리스 노트」). #658과 #661은 2.2.5에서 들어온 줄바꿈 규칙이 아이폰의 Safari에서 지켜지지 않던 문제라 「버그 수정」이다. #662는 가로 화면에서 탭 바와 검색 단추가 본문 글자보다 바깥에 있던 것을 맞춘 모양의 변화다. 데이터 #95는 본문 수정이다. 줄마다의 문구는 세 가지씩 내놓은 것 가운데 사용자가 골랐다(2026-11-24). 리뷰가 #662와 #661 줄의 범위를 바로잡은 뒤에 골랐다(아래 「리뷰 반영」).
- **노트에 넣지 않은 것.** #659(e2e), #663(개발 환경), #664(문서)는 사용자가 겪는 변화가 없다.
- **릴리스마다 하는 정리**(CLAUDE.md 「지식 베이스 루프」 3번).
  - 2.2.6 뒤의 원장은 #658, #659, #661, #662, #663, #664의 것이다. 새 ADR은 없다. ADR-030, ADR-053, ADR-055를 제자리에서 고쳤다.
  - `docs/index.md`와 실제 파일, 링크, 번호 대장은 문서 검사가 본다(통과). 끝나서 `archive/`로 옮길 설계 문서는 2.2.6과 같이 없다.
  - `docs/topics/design-system.md`가 193줄에서 209줄이 되어 200줄을 넘겼다. #658이 「지금 동작」에 ◯ 상자를 적고 「남은 일」에 known-issues §79를 더했고(8줄), #661이 「지금 동작」의 따옴표 묶음을 고치고 「남은 일」에 known-issues §81을 더하며 §79의 해소 기록에 당시 기록을 남겼다(8줄). 2.2.6에서 넘긴 `docs/topics/platform.md`는 216줄에서 215줄이다. 두 문서 모두 늘어난 것의 대부분이 「남은 일」이라 고치면 줄어든다. 이번에는 나누지 않고 다음 릴리스의 정리에서 다시 본다.

## 검증

버전 파일 둘을 2.2.7로 바꾼 커밋에서 점검했다.

- `node --test tests/unit/*.test.js`: 1,999건 통과(실데이터 시험 포함). 타입 검사 `tsc -p tsconfig.json --noEmit`와 `tsc -p tsconfig.worker.json --noEmit`: 통과. `scripts/test_changelog.py`와 `scripts/test_release.py` 44건: 통과.
- e2e(서버 8096): 버전과 관련된 `test_update_toast.py`와 `test_liturgical_lazy_load.py` 20건 통과.
- 이번 판에서 바뀐 화면의 e2e는 각 PR에서 돌렸다. #662는 #658과 #661이 들어간 dev(`57e6a64`) 위에서 관련 e2e 133건을 돌렸고, 그 시험 트리(`b07df92`)와 이 커밋의 앱 파일(`js/`, `css/`, `index.html`, `sw.js`)은 버전 파일 둘 말고 같다.
- CSP 점검: `python -I tools/csp/csp_sweep.py http://localhost:8096`(서비스 워커 막음)과 `--sw`(켬) 모두 위반 0종. 건너뛴 단계는 이 브라우저에서 할 수 없는 데스크톱 오디오 재생 하나다(2.2.6과 같다). 2.2.6 뒤로 `index.html`, `sw.js`, 통계 태그(`js/gtag-init.js`)는 바뀌지 않았지만, 구글이 요청 주소를 바꾸는 일을 찾으려고 사용자가 돌리기로 했다(2026-11-24). 이 점검은 구글의 주소로 진짜 요청을 보내므로, 점검한 시각(21:45-21:47)에 `localhost`의 방문이 통계에 섞였을 수 있다.
- 배포한 뒤 `dev`와 운영의 `version.json`이 2.2.7인지 실제 사이트에서 확인한다.
- 실제 아이폰에서는 #661의 따옴표를 dev(`a0b30c7`, #658 포함)에서 확인했다(사용자, 2026-11-24, #664). #662의 가로 화면과 나머지는 dev에 올린 뒤 사용자가 본다.

## 리뷰 반영

1회차(`/code-review medium --fix`): 중요한 지적 셋과 사소한 지적 둘.

- **릴리스 노트의 범위를 바로잡았다.** #662 줄은 「글자를 작게 하면」만 적었으나 기본 글자에서도 어긋났고 아이폰만의 일이 아니어서 「휴대폰을 가로로 돌렸을 때」로 고쳤다. #661 줄은 「시편」으로 좁혔으나 따옴표 묶음은 운문 전체에 적용되므로 「시편처럼 행을 나눈 본문」으로 고쳤다.
- **CSP 점검을 건너뛴 것**은 고치지 않고 사용자에게 물었다. 사용자가 돌리기로 해 돌렸다(「검증」).
