## 요약

모바일 하단 탭 바의 홈 탭 아이콘을 집에서 펼친 책으로 바꿨다(ADR-030의 아이콘 전용 탭 바). 홈 탭은 성서 목록과 읽던 장으로 가는 탭이라 책이 하는 일을 더 잘 나타낸다. 누르면 가는 곳과 스크린 리더가 읽는 이름(「홈」)은 바꾸지 않았다.

## 확정 · 근거

- **펼친 책**(사용자 결정 2026-11-14: 홈 아이콘을 책 모양으로). 덮은 책은 북마크 탭이나 숨겨 둔 노트 탭의 네모 아이콘과 헷갈려 펼친 책으로 그렸다.
- **광학 크기**: 다른 탭 아이콘과 같은 규칙(`index.html`의 탭 바 주석)으로 `viewBox` 속성과 획 굵기를 맞췄다.
- **바꾸지 않은 것**: 데스크톱 헤더의 성서 목록 단추는 집 그대로다. 데스크톱은 나중에 메뉴 구조를 한꺼번에 개편한다(사용자 결정 2026-11-14). 탭의 이름 「홈」도 그대로 두었다.

## 검증

- `node --test tests/unit/*.test.js` 통과(1,535개 통과, 211개 건너뜀. 이 작업 환경에 데이터 서브모듈이 없어 실데이터 케이스는 건너뛰었다). `npm run typecheck` 통과.
- e2e(`tests/e2e/test_tabbar.py`)는 돌리지 않았다. 이 작업 환경에 pytest가 없다. 바뀐 것은 아이콘의 그림뿐이고 탭의 선택자와 이름은 그대로다.
- 아이폰 13 크기의 화면에서 밝은 화면과 어두운 화면, 활성과 비활성 상태의 탭 바를 찍어 눈으로 확인했다.
