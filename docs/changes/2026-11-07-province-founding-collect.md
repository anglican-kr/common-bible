## 요약

9.29 전례독서 화면에서 성 미카엘 본기도 뒤에 관구 설립 본기도를 잇고, 제목 아래 이름 줄에 「1992년 9월 29일 관구설립일」과 「대한성공회 선교 기념일」을 보인다. 전례독서 목록에 있던 「대한성공회 설립 기념일」 줄은 없앴다. ADR-041 §6(단계 3의 관구 갈래)을 구현하고, 설계서 미결49의 9.29 이름 표기를 정한다. 데이터는 data 저장소의 같은 이름 브랜치가 고친다.

## 확정 · 근거

- **1890년과 1992년을 나눈다(사용자 결정 2026-11-07).** 사용자는 9.29를 성 미카엘 축일이면서 관구 설립일로 보고, 이름 줄을 「1992년 9월 29일 관구설립일」, 「대한성공회 선교 기념일」 두 줄로 정했다. 기도서 「월별 축일」의 「대한성공회 설립기념일, 1890년」은 그래서 「대한성공회 선교」가 되었다.
- **1890년 행을 기념일로 바꿨다.** 데이터의 주요축일C 행을 화면에서만 감추면 화면이 9.29를 따로 다뤄야 하고, 캘린더 칸도 옛 이름으로 남는다. 기념일은 이미 「… 기념일」 이름 줄로 그리고 본문이 없다는 규칙이 있어 그대로 맞는다. 기도서의 등급(그 외의 축일(다))과 달라져 미결49에 사제 확인을 남겼다. ADR-041 「검토한 대안」 D.
- **관구 설립일은 교구 설립일 표의 행이다.** ADR-041 §6이 「덧붙이는 방식은 교구 설립일과 같다」고 정해, `dioceses.md`에 층위 열을 더하고 관구 행(대한성공회, 09.29, 1992)을 넣었다. `local-observances.json`의 `province`로 나가므로 교구 목록과 본당 조인에는 끼지 않는다. 연도와 날짜를 앱 코드에 적지 않으려는 것이다.
- **전례일 후보로 넣지 않는다.** 관구 설립일은 교회력 판정(대표, 색, 옮김)에 끼지 않고 화면이 덧붙인다(`findFoundings`). 후보로 넣으면 성 미카엘과 겨루고 옮김 계산과 픽스처가 달라진다.
- **본기도는 주일에도, 다른 전례일을 골라도 잇는다.** ADR-041 §6의 교구 설립일 규칙(2026-11-05)을 따랐다. 처음에는 기리는 성인처럼 기본 독서를 볼 때만 이었다가 ADR을 다시 읽고 고쳤다.
- **본기도 문장의 뒤쪽 「이 교구를」을 「이 교구(관구)를」로 고쳤다.** ADR-041 §6에서 사용자가 확인한 문장이다. 치환은 「{name}교구(관구)」를 「대한성공회 관구」로, 남은 「교구(관구)」를 「관구」로 한다.
- 일부러 하지 않은 것: 캘린더에 관구 설립일을 보이는 일, 교구 설립일(소속교회 설정)의 줄과 본기도. 교구 쪽은 줄의 표기를 관구 줄과 맞출지 구현할 때 정한다(주제 문서 「남은 일」).

## 검증

- 유닛 `node --test tests/unit/*.test.js`: 1,565건 통과, 실패 0건(데이터 브랜치의 산출물로). 타입 검사 통과.
- 데이터 `pytest tests/`: 3,290건 통과. 파이프라인의 전례 단계(`parse_readings.py`부터 `gen_manifests.py`까지)를 다시 돌려 산출물을 만들었다.
- 화면 모델: 2027-09-29(수)와 2030-09-29(주일)에서 제목, 목록, 이름 줄 둘, 본기도 둘과 송영 하나를 확인했다. 9.28에는 줄이 없다.
- 화면: Node Playwright로 폭 390px의 `/lectionary/2027-09-29`를 그려 제목 아래 두 줄과 본기도 순서를 보았다. 콘솔 오류는 외부 글꼴 요청의 터널 실패 하나뿐이다.
- 사실 토큰 비교(`docs_facts_snapshot.py --diff HEAD WORKTREE`): 사라진 토큰 둘(「51건」, 옛 전례일 id)과 새 토큰 둘(「50건」, 「29일」)은 의도한 것이다.
- 돌리지 않은 것: e2e. 이 환경에 pytest-playwright가 없다. 머지 전에 `test_lectionary_view.py`와 `test_calendar_view.py`를 돌린다.
- 데이터 서브모듈 포인터는 이 PR에서 올리지 않았다. 데이터 PR이 머지되면 포인터와 사이트맵을 이 PR에 올린다. 그 전까지 앱은 옛 데이터로 전과 같이 그린다(`province`가 없으면 줄과 본기도가 없다).
