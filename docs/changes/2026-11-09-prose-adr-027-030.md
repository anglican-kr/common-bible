## 먼저 보실 곳

뜻이 달라질 수 있는 고침이다. 숫자, 날짜, 인용, 코드 표기는 바꾸지 않았다(아래 「검증」의 사실 토큰 비교).

- ADR-027: 「source」를 「원본」, 「element」와 「엘리먼트」를 「요소」, 「footnote anchor」를 「각주 앵커」, 「parser」를 「파서」로 썼다. 「의도한 우연이다」는 앞뒤가 맞지 않아 「의도한 겹침이다」로 바꿨다. USFM `\r`를 설명하는 「단락 머리 뒤에」는 「단락 제목 뒤에」로 썼다. 대안 표의 「(다시 쓰기)」는 「(재사용)」으로 썼다. 「다시 쓰다」가 「고쳐 쓰다」로도 읽혀서다.
- ADR-027 §2 「화면」: 「머리는 `range`」를 「제목은 `range` 값」으로, 「ref를 골라 시트에 띄운다」를 「출처를 눌러 시트에서 연다」로 바꿨다.
- ADR-028: 「chrome」을 「UI」로(용어 표), 「elevation」을 「그림자 단계」로 썼다. 「시그니처 강조」는 「대표 강조」로, 「명시 토글」은 「사용자가 직접 바꾼 토글」로, 「elevation이 아닌 관용구」는 「그림자 단계와 상관없는 쓰임」으로 풀었다. 「적응형 내비게이션」 절의 활성 표시 괄호는 문장 순서를 바꿔 한 문장으로 합쳤다.
- ADR-028: 관련 ADR 줄의 「ADR-025(스크롤 elevation)」를 ADR-025의 지금 제목 「읽기 헤더의 스크롤 그림자」로 맞췄다(지난 묶음 #529에서 미뤄 둔 곳).
- ADR-029: 「공유 파괴 확인(`bm-confirm`)」을 「공용 파괴 확인」으로 바꿨다. 「공유」가 공유하기 단추로 읽혀서다. 「내비 시그니처로 한정」은 「내비게이션을 나타내는 색으로만 쓴다」로, 「약한 어포던스, 위계」는 「눈에 덜 띄고, 같은 단계」로 풀었다. 「covered로」는 「상위 폴더에 포함돼」로 썼다.
- ADR-030: 「쉴 때」(영어 idle)를 문맥대로 「검색 중이 아닐 때」나 「쓰지 않을 때」로 썼다. 「오늘의 … 인디케이터」는 「최종 결정인 …」으로 바꿨다. 「CTA」는 「단추」로 썼다. 「스킴을 따르는」은 색 구성(`[data-color-scheme]`)을 가리키므로 「색 구성을 따르는」으로 썼다.
- 대안 절의 「채택 안 함 날짜 · 이유:」와 「채택 안 함 날짜. 이유:」를 이미 교정한 ADR의 표기인 「채택 안 함(날짜). 이유:」로 맞췄다(14곳). 날짜 뒤의 괄호(「(dev 검토)」, 「(후속⁶)」)는 날짜와 함께 괄호 안에 넣었다.

## 결정 대기

- **scrim**(ADR-030 「검토한 대안」, 지운 장식 요소 `#tabbar-scrim`): 후보는 「가림막」, 「그러데이션 가림막」, 그대로 두기다. 권장안은 「그러데이션 가림막」이다.
- **squircle**(ADR-029, ADR-030): 후보는 「스쿼클」, 그대로 두기다. CSS 값 `superellipse(2)`와 함께 나와 권장안은 그대로 두기다.
- **sheen/inset 질감**(ADR-029 §2): ADR-030은 토큰 이름 `--glass-sheen`, `--glass-inset`으로 풀었다. ADR-029도 같이 풀지 정해 주시면 맞춘다.
- **network-first, cache-first**(ADR-030 「구현 메모」): 후보는 「네트워크 우선」, 「캐시 우선」이다. 권장안은 처음에만 영어를 괄호에 다는 것이다.
- **런치 페이드**(ADR-028 §9): 후보는 「시작 화면 페이드」, 「실행 화면 페이드」다. 권장안은 「시작 화면 페이드」다.
- ADR-028 §5의 「frosted glass를 아무 데도 쓰지 않는다」는 낫표 안이라 그대로 두었다. 같은 문단의 굵은 글씨는 「반투명 유리」로 바꿨다.

## 요약

문장 교정 진행 목록 3절(ADR)의 ADR-027, 028, 029, 030을 고쳤다(한글 줄 431줄). 열린 PR이 없어 충돌할 파일이 없었다.

- 기계 검사 항목 전체: 4개 파일에서 374건이 71건으로 줄었다. `particle`, `tilde`, `term`은 14건(모두 「chrome」)에서 0건이 됐다. 남은 것은 ADR 상태 줄의 줄표, 미는 방향 표시(← 삭제, → 수정), 축일과 상관없는 「이동」, 제품 이름과 CSS 단위, 위 「결정 대기」의 낱말이다.
- 기계 검사 밖에서 고친 곳은 약 250곳이다. 영어 낱말(element, source, parser, hairline, frosted glass, dock, pill, elevation, thumb, toolbar)을 한국어로 바꾸고, 코드 이름에 역따옴표를 달았다. 「나르는」, 「따로 논다」, 「물들이던」, 「무너졌다」, 「닿는」, 「얹고」, 「먹어」, 「녹였다」 같은 비유 동사를 바꿨다. 「=」, 「→」, 「/」, 가운뎃점으로 이은 말을 조사로 풀었다.
- 검토 단계에서 고친 곳: 역따옴표 안의 코드 9곳을 원래 글자로 되돌렸다(`sticky→fixed`, `offsetLeft/Width`, `--font-sm→--font-md` 등). ADR-030의 「알약 버튼로」를 「알약 버튼으로」로, 「스킴」을 「라이트와 다크」로 잘못 푼 두 곳을 「색 구성」으로 고쳤다. ADR-029에서 「역전」을 「문제」로 바꾼 것과, 같은 문장에서 뺀 `_setupDragHandle` 하나를 되돌렸다. ADR-027의 「다른 마커 안에 중첩해」(뜻이 바뀐 곳)를 「마커끼리 중첩해」로 고쳤다.
- 제목 27개를 고쳤다. 줄표, 「+」, 「/」를 쌍점이나 쉼표로 바꾸고, 영어 낱말(element, source, Source, Parser, elevation, dock, frosted glass, Liquid Glass)을 한국어로 썼다. ADR-027 「위치 잡기」는 「위치」로, 「단락 머리 배너」는 「단락 배너」로 썼다.
- 바꾼 ADR 제목을 인용한 곳을 함께 고쳤다: `docs/topics/bible-text.md`(ADR-027), `docs/topics/design-system.md`(ADR-028), `docs/topics/routing.md`(ADR-029). ADR-030 제목의 인용 「모핑 탭 바」는 그대로 맞다. 링크 앵커로 이 제목들을 가리키는 곳은 없었다.
