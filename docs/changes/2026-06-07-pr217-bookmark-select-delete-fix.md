# fix: 북마크 선택 캡슐 너비 명시(WebKit intrinsic flex 버그)

## 문제

북마크 전체뷰 ⋯ 메뉴 → **선택** 진입 시, 화면 하단 캡슐(`#bm-select-bar`)에 들어있어야 할 공유·이동·삭제 버튼이 캡슐 오른쪽 반원 캡 **밖으로 삐져나왔다**(삭제 아이콘이 캡슐 밖에 노출).

[bug](사용자 제공 스크린샷)

## 원인

선택 캡슐(`.verse-action-pill`)이 `flex: 0 0 auto`(= `width:auto`)로 자식 버튼들의 `flex-basis`(각 `--dock-control` 60px)에서 너비를 파생하려 했다. 그러나 **WebKit/iOS Safari 는 flex 컨테이너의 intrinsic(max-content) 너비를 계산할 때 자식 flex 항목의 `flex-basis` 를 무시**한다. 그래서 캡슐은 아이콘 글리프 폭(~절반)으로 줄어든 반면, 버튼들은 각자 60px 를 유지해 → 3 × 60 = 180px 가 ~90px 캡슐 밖으로 흘러넘쳤다. (스크린샷이 iOS 환경.)

## 수정

캡슐 너비를 슬롯 수에서 **명시**:

```css
#bm-select-bar .verse-action-pill {
  flex: 0 0 auto;
  width: calc(var(--dock-control) * 3); /* 공유·이동·삭제 */
}
```

- intrinsic 사이징 경로를 우회 → 캡슐이 항상 180px(3 슬롯)로 모든 버튼을 담는다.
- 디자인 의도(**캡슐 너비 = 아이콘 수 × 슬롯**, DESIGN.md §다중-아이콘 캡슐)는 그대로. 향후 액션 추가/제거 시 배수만 갱신.
- DESIGN.md 에 WebKit 주의 한 줄 명문화(앞으로 `width:auto` 로 되돌리지 않도록).
