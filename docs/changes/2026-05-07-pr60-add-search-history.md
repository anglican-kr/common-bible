# feat: 검색 히스토리 + 44×44 터치 타깃 (ADR-014)

## 요약

검색 입력창에 최근 검색어 드롭다운을 추가하고 클리어·히스토리·닫기 버튼을 모두 WCAG 2.5.5 AAA(44×44 CSS px)로 키웠습니다. 설계 결정은 [ADR-014](docs/decisions/014-search-history.md), 살아있는 설계 문서는 [docs/design/search-history.md](docs/design/search-history.md).

## 변경 내용

### 검색 히스토리

- `localStorage["bible-search-history"]`에 `string[]` 저장 (최신이 인덱스 0)
- 정규화: `trim().replace(/\s+/g, " ")` 후 비교 → 공백 차이 dedupe
- LRU: 동일 쿼리 재검색 시 기존 항목 제거 + 맨 앞 push
- **저장 30건 / 표시 10건 분리**: 패널 기본 10건만 노출, 11~30건은 `더 보기 (N개)` 토글로 점진 펼침
- 키보드 ↓로 마지막 가시 항목에서 누르면 자동 펼침 + 다음 항목으로 이동
- 저장 시점: 키워드 검색이 실제로 시작될 때(`commitTopSearch`/`commitSheetSearch`). 절 참조(`refMatch`)나 빈 쿼리는 미저장
- **Drive 동기화 비대상** — 디바이스 휘발성 행동 데이터 + 프라이버시 측면

### 패널 UX

- 입력창 우측 ▾ 토글 (히스토리 0건이면 자체 hidden)
- ARIA combobox/listbox 패턴: `aria-haspopup`, `aria-expanded`, `aria-activedescendant`
- ↑/↓로 이동, Enter로 선택, Esc로 닫기, 외부 탭 시 자동 닫힘
- 항목별 × 삭제 버튼, 3건 이상일 때 푸터에 "모두 지우기"
- 모바일 시트는 `:has(#search-sheet-history:not([hidden]))`로 컴팩트 시트 높이를 28rem까지 자동 확장

### 접근성 / 터치 타깃

- 클리어, 히스토리 토글, 시트 닫기, 항목, 항목 삭제 모두 **44×44 px** (Apple HIG 44pt, Material 48dp, WCAG 2.5.5 AAA 충족)
- 입력창 자체 `min-height ≥ 44px`
- `:focus-visible` `box-shadow` 대비 강화, 색상 토큰 `--text-secondary` → `--text`로 가독성 개선
- 한국어 `aria-label`: "최근 검색어 열기", "검색어 지우기", "최근 검색어 \"<쿼리>\" 삭제"
