## 요약

애널리틱스 관리 화면의 웹 스트림 「공동번역성서」(`https://bible.anglican.kr`, 측정 ID `G-2Q4SRGVNQN`, 스트림 ID 14348950825)가 「웹사이트에서 데이터 수집이 활성화되어 있지 않습니다」와 「수신된 데이터 없음」을 보였다(사용자 화면, 2026-11-23). 앱이 다른 측정 ID(`G-CWVVPW11TE`)로 보내고 있었기 때문이다. `index.html`의 태그 주소와 `js/gtag-init.js`의 `config` 두 곳을 `G-2Q4SRGVNQN`으로 바꿨다.

## 확정 · 근거

- **원인은 측정 ID가 달랐던 것이다.** 처음 연동(`75b0286`)은 `G-2Q4SRGVNQN`이었고, 2026-05-05 커밋 `a38c017`(「측정 ID를 G-CWVVPW11TE로 통일」)이 두 곳을 모두 `G-CWVVPW11TE`로 바꿨다. 그 뒤로 이 스트림에는 데이터가 오지 않았다. 운영(`https://bible.anglican.kr/`)이 내려 주는 `index.html`과 `js/gtag-init.js`도 `G-CWVVPW11TE`였다(읽기만, 2026-11-23).
- **수집 경로는 고장이 아니다.** 태그 스크립트는 200으로 내려오고, CSP는 구글 태그 주소를 허용한다. 수집 요청이 204로 성공하는 것은 `docs/changes/2026-10-18-csp-google-collect.md`에서 확인했다.
- **사용자 결정 — 화면의 스트림(`G-2Q4SRGVNQN`)으로 모은다**(2026-11-23). 보인 안은 둘이다. ① 코드를 그대로 두고 `G-CWVVPW11TE` 스트림을 찾아 본다, ② 코드를 `G-2Q4SRGVNQN`으로 되돌린다. 사용자 「2로 진행」.
- **`G-CWVVPW11TE`가 어느 속성의 스트림인지는 확인하지 못했다.** 저장소에는 단서가 없다. 5월 5일부터 오늘까지의 기록이 그쪽에 있다면 이 변경을 운영에 낸 뒤로 두 스트림으로 나뉜다.
- **운영에서는 버전을 올려서 내야 새 측정 ID로 바뀐다.** 운영의 서비스 워커(`sw.js`)는 `index.html`과 `js/gtag-init.js`를 셸 캐시에 저장해 둔 것부터 내주고, 셸 캐시는 버전이 올라야 새로 받는다. 버전을 올리지 않고 내면 앱을 이미 쓰는 기기는 옛 측정 ID로 계속 보낸다. 버전을 올려도 기기마다 업데이트 알림을 받아들인 뒤에 바뀌므로, 한동안 두 스트림에 나뉘어 기록된다.
- **방문 2건 기록(known-issues §46)은 이 PR에서 다루지 않는다.** 따로 진행 중인 작업(`fix/analytics-double-pageview`)이 같은 줄을 고친다. 그 작업 폴더의 측정 ID도 같은 값으로 맞춰 두었다(사용자 결정 「따로 PR」, 2026-11-23).
- **두 곳의 측정 ID가 같은지 보는 유닛 검사는 그 작업에 넣었다**(코드 리뷰 지적). 그 작업이 `tests/unit/gtag-init.test.js`를 새로 만들고 있어, 여기서 같은 파일을 만들면 충돌한다. 그 PR이 머지되기 전에는 이 검사가 dev에 없다.

## 검증

- 저장소 전체에서 `G-CWVVPW11TE`를 찾으면 코드에는 0건이고, 경위를 적은 문서 두 곳(이 원장과 `docs/topics/platform.md`)에만 있다. `G-2Q4SRGVNQN`은 코드 두 곳과 같은 문서 두 곳에 있다(`grep -rn`).
- `https://www.googletagmanager.com/gtag/js?id=G-2Q4SRGVNQN` — 200.
- 유닛 `node --test tests/unit/*.test.js` — 1991건 모두 통과. `npm run typecheck` — 0.
- e2e는 돌리지 않았다. 바뀐 것은 측정 ID 문자열 두 곳이고, e2e는 그 값을 보지 않는다.
- 운영에 낸 뒤 애널리틱스 관리 화면의 실시간 보고서에서 수신을 확인해야 한다(사용자 확인 필요). 개발 서버(dev.anglican.kr)도 같은 측정 ID로 보내므로, 개발 서버에 배포한 뒤의 수신은 운영의 수신이 아니다. 「수신된 데이터 없음」 표시는 반영에 최대 48시간이 걸릴 수 있다.
