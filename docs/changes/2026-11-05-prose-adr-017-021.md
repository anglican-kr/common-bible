## 먼저 보실 곳

뜻이 달라질 수 있는 고침이다. 숫자, 날짜, 인용, 코드 표기는 바꾸지 않았다(아래 「검증」의 사실 토큰 비교).

- ADR-017: 「secret」을 모두 「비밀값」으로 썼다. 이 파일에는 「비밀 값」이 이미 한 곳 있었으나, `CLAUDE.md`와 ADR-020이 쓰는 「비밀값」으로 맞췄다. 「dev」, 「prod」는 「개발 환경」, 「운영 서버와 개발 서버」로, 「upstream으로」는 「Google 서버로」로, 「(deprecated)」는 「(사용 중단 대상)」으로 바꿨다.
- ADR-017: 「`code` + `code_verifier`나 `refresh_token`」을 「`code`와 `code_verifier`, 또는 `refresh_token`」으로 풀었다. 「mode 0644 root:root」는 「파일 권한 0644, 소유자 root:root」로, 「nginx 설정 파일이 새어 나간다」는 「유출된다」로 바꿨다.
- ADR-018: 「getter/setter」를 「값을 읽고 쓰는 함수」, 「읽기와 쓰기」로, 「verse spec」을 「절 지정 문자열 처리」로, 「Multi-script」를 「스크립트 여러 개」로 풀었다. 「최적화를 할 길이 열렸다」는 「할 수 있게 됐다」로 썼다.
- ADR-019: 「의존 그래프의 명시」를 「의존 관계를 분명히 드러내는 일」로, 「테스트에만 쓰는 맞춤」을 「조정」으로 바꿨다. 「저절로 deferred가 되어」는 「저절로 지연 실행(`defer`)되어」로 썼다.
- ADR-019, 018: 「sync 레이어」를 「동기화 레이어」로, 「module scope」를 「모듈 범위」로, 「lazy load」를 「지연 로딩」으로, 「tree-shaking」을 「트리 셰이킹」으로 썼다.
- ADR-020: 저장소의 짧은 이름 「data」, 「audio」, 「server」를 「데이터 저장소」, 「오디오 저장소」, 「서버 저장소」로 약 30곳 바꿨다. 「서브모듈 마운트」는 「서브모듈 연결」로, 「오디오 버전을 잠금)에 들어온다」는 「고정)으로 관리할 수 있다」로, 「docroot」는 「문서 루트(docroot)」로 바꿨다.
- ADR-021: 「webhook」을 「웹훅」으로, 「sitemap」(파일 이름이 아닌 곳)을 「사이트맵」으로, 「1st-party」를 「GitHub 공식」으로, 「rev」(산문)를 「번호」로 썼다. 「LRU sidecar」는 ADR-016 상태 줄이 쓰는 「메타 저장소」에 맞춰 「LRU 메타 저장소」로 썼다.
- ADR-021 「4」: 「자동으로 버전을 올리면 … 쌓였기 때문이다」를 「자동으로 버전을 올리던 때에는 … 쌓였기 때문이다」로 바꿨다. 가정과 과거가 섞인 문장이었고, 아래 「검토한 대안」이 실제로 그랬다고 적는다. 「PAT가 새면 공개 push 위험」은 「PAT가 유출되면 공개 저장소에 push될 위험」으로 풀었다.
- 「채택 안 함 날짜 · 이유:」 줄 7곳을 이미 교정한 ADR(010 등)의 표기인 「채택 안 함(날짜). 이유:」로 바꿨다. 표 안의 「채택 안 함 — 이유」는 이미 교정한 ADR이 대개 쓰는 쌍점으로 바꿨다.

## 결정 대기

- **facade**(ADR-018, 019의 「`window.X` facade」, `window.X`로 내놓는 전역 객체): 후보는 「퍼사드」, 「호환용 전역 객체」, 「`window.X` 객체」다. 권장안은 「호환용 전역 객체」이고 처음 나오는 곳에 「(facade)」를 단다. ADR-034에도 많이 나와 함께 정해야 한다. 이번에는 그대로 두었다. ADR-019의 제목 「### 전역 facade는 남긴다」도 이 결정에 따라 바뀐다.
- **classic script**(ADR-019, 모듈이 아닌 일반 스크립트): 후보는 「클래식 스크립트」, 「일반 스크립트」다. 권장안은 「일반 스크립트」다.
- **multi-script**(ADR-018, 019의 방식 이름): ADR-018은 「스크립트 여러 개」로 풀었고, ADR-019는 인용과 표 칸에 그대로 남았다. 후보는 「다중 스크립트」, 「스크립트 여러 개 방식」이다. 권장안은 「다중 스크립트」다.
- **minify**(ADR-019): 후보는 「압축」, 「코드 줄이기」다. 권장안은 「압축」이다.
- **Compact header**(ADR-018, 옛 `views-routing.js`의 기능 이름): 후보는 「축소 헤더」, 「컴팩트 헤더」다. 권장안은 「축소 헤더」다. ADR-034에도 나온다.
- **token endpoint**(ADR-017): 「토큰 엔드포인트(token endpoint)」로 썼다. 「용어」 표가 refresh token을 그대로 쓰기로 한 것처럼 OAuth 용어로 둘지, 「토큰 요청 주소」로 할지 정해 주시면 표에 올린다. 권장안은 「토큰 엔드포인트」다.

## 요약

문장 교정 진행 목록 3절(ADR)의 ADR-017, 018, 019, 020, 021을 고쳤다(한글 줄 373줄). 열린 PR이 없어 충돌할 파일이 없었다.

- 기계 검사 항목 전체: 240건에서 61건으로 줄었다. `particle`, `tilde`, `term`은 1건(ADR-020의 「~6.3 GB」)에서 0건이 됐다. 남은 것은 대부분 `english?`(제품 이름, 인용, 위 「결정 대기」의 낱말)와 ADR 상태 줄의 줄표, 관형사 「한」이다.
- 기계 검사 밖에서 고친 곳은 약 150곳이다. 「+」와 「/」로 이은 명사를 조사로 풀었고, 「돈다」, 「돌린다」, 「새다」, 「끼워 넣다」, 「덧대다」, 「갇힌」, 「혼자 서다」 같은 비유 동사와 영어 낱말(implicit any, namespace, scope, issue tracker, baseline, entry 등)을 바꿨다. 코드 이름(`burst`, `cache.put`, `TypeError`, `rev`, `workflow_dispatch`)에 역따옴표를 달았다.
- 검토 단계에서 약 15곳을 다시 고쳤다. 「채택하지 않았다(날짜).」를 다른 ADR의 「채택 안 함(날짜).」로, 표의 「채택 안 함.」을 쌍점으로 맞췄다. ADR-019의 「ADR-001의 SPA의 단순성」을 「ADR-001이 내세운 SPA의 단순성」으로, ADR-018의 「지연 불러오기」를 ADR-019와 같은 「지연 로딩」으로 고쳤다. ADR-020 표에 남은 「github」 한 칸을 「GitHub」로 고쳤다. ADR-021의 「보조 기록(sidecar)」은 ADR-016의 「메타 저장소」로 바꿨다. 사실 토큰이 줄어든 두 곳(ADR-021의 `[skip ci]` 되풀이, ADR-018의 `import/export`)은 원래 표기로 되돌렸다.
- 제목 4개를 고쳤다. ADR-017 「### C. … (Node.js / Python)」을 「(Node.js나 Python)」으로, ADR-018 「### IIFE + `<script defer>` + `window.appXxx`와 …」의 「+」를 쉼표로, 「### `index.html` / `sw.js` 영향」을 「### `index.html`과 `sw.js`의 영향」으로, ADR-020 제목의 「(app / data / audio / server)」를 「(앱, 데이터, 오디오, 서버)」로 바꿨다. ADR-020 제목을 옮겨 적은 `docs/architecture.md` 부록 A의 ADR 인덱스 한 줄을 함께 고쳤다. 네 제목으로 오는 링크 앵커와 다른 인용은 없었다. ADR-018 제목의 「module-vs-script 예외」는 ADR-019가 절 이름으로 인용하므로 그대로 두었다.
