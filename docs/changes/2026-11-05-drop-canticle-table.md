## 요약

전례독서를 열 때 송가 표(`canticles.json`)를 함께 받았지만 읽는 코드가 없었다. 받을 파일에서 빼고 색인과 시험에서도 지웠다. 화면은 달라지지 않는다. 파일과 그 표를 만드는 코드는 data#57에서 지운다.

## 확정 · 근거

- **쓰이지 않는 파일을 지운다**(사용자 결정 2026-11-05). 화면의 송가 이름은 송가 장의 제목에서 오고, 색인에 넣은 표를 읽는 코드는 앱에 없었다.
- **앱을 먼저 고치고 그다음 파일을 지운다.** 이 표는 전례독서 묶음의 필수 파일이라, 앱이 찾는데 파일이 없으면 전례독서 화면 전체가 실패한다. 데이터 동기화의 실데이터 시험도 이 파일을 읽었다.
- **출시한 앱에는 영향이 없다.** 최신 태그 1.6.4에는 전례독서 코드가 없어 이 파일을 찾지 않는다. 이 PR 전의 빌드를 띄운 개발 환경의 기기는 새 빌드를 받기 전까지 전례독서가 실패할 수 있다.
- **그대로 둔 것.** 독서 데이터의 `canticle`과 `scripture_ref`도 앱이 읽지 않지만, 파일을 지우는 일과 별개라 두었다.

## 검증

- 유닛: `canticles.json`을 지운 데이터로 `node --test tests/unit/*.test.js` 1,505건 모두 통과. 가짜 응답에서 이 표를 빼서, 앱이 다시 받으려 하면 실패한다.
- 타입 검사: `tsconfig.json`과 `tsconfig.worker.json` 모두 오류 없음.
- e2e: 같은 데이터와 작업 폴더의 서버(포트 8094)로 전체 435건 통과.
