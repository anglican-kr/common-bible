## 요약

버전을 2.2.1에서 2.2.2로 올린다(`python3 scripts/release.py patch`). 2.2.1 뒤에 검색할 책을 검색창 아래의 알약으로 보인 것(#615, ADR-049), 아이폰 홈 화면 앱의 시작 화면(#617), 창 폭이 바뀌어도 검색 화면을 지키는 것(#618), 누른 알약에 남는 호버 바탕(#619)이 들어간다. 하단 입력창 CSS 정리(#614)와 휴대폰 검색 입력창의 Esc와 지우기 포커스의 대비책(#616)도 들어간다.

아래 「릴리스 노트 초안」은 머지한 뒤 GitHub Release에 그대로 쓴다. 「변경 사항」은 `python3 scripts/changelog.py 2.2.1 HEAD`의 출력이고, 끝의 비교 링크만 2.2.2 태그를 가리키게 고쳤다.

## 릴리스 노트 초안

### 기능 개선

- 검색할 책을 검색창 아래에 알약으로 보여 줍니다. 책을 두 권 이상 고르면 ‘전체’와 책마다의 알약에 결과 수가 적히고, 책 알약을 누르면 그 책의 결과만 볼 수 있습니다. 알약의 ‘×’를 누르면 그 책을 빼고 다시 찾습니다. 지금까지는 고른 책이 검색창 안에 들어가 셋째 책부터 가려졌고, 결과도 합친 수만 보였습니다.

### 버그 수정

- 아이폰에서 홈 화면에 추가한 앱을 열면 십자가가 있는 시작 화면 대신 흰 화면이 한동안 보이던 문제를 고쳤습니다. 최근 아이폰과 아이패드의 화면 크기에도 시작 화면을 맞췄습니다.
- 검색 결과를 내려 보다가 아래의 돋보기 단추를 누르면, 화면이 맨 위로 천천히 올라가는 동안 키보드가 올라오던 문제를 고쳤습니다. 이제 바로 맨 위로 갑니다.
- 컴퓨터에서 브라우저 창의 폭을 바꾸면 검색 화면이 처음부터 다시 그려져, 입력하던 검색어와 검색 결과, 보던 자리가 사라지던 문제를 고쳤습니다.
