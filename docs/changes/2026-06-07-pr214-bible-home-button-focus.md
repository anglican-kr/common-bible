# feat: 홈 버튼으로 책 목록 이동 시 읽던 책에 포커스

## 요약

성서를 읽다가 헤더 **홈 버튼**을 누르면 그 책의 구분 탭(책 목록)으로 올라가는데, 이때 **방금 읽던 책 항목에 키보드 포커스**가 가도록 했습니다. 긴 목록에서 맨 위가 아니라 읽던 맥락에 포커스를 떨어뜨려 다음 탐색이 자연스럽게 이어집니다(접근성).

본문·장 목록·머리말 세 화면의 홈 버튼 모두에 적용됩니다.

## 구현

- `buildHomeBtn(target, ariaLabel, focusBookId)` — 세 번째 인자로 읽던 책 id 를 받아, 클릭 시 1회성 `setPendingBookFocus(id)` 후 `navigate(target)`
- `renderBookList` 가 렌더 직후 `focusPendingBook()` 으로 펜딩 값을 소비 — `.book-list a[data-book-id="…"]` 항목을 `focus({preventScroll:true})` + `scrollIntoView({block:"center"})`(sticky 헤더에 안 가리게 중앙)
- 펜딩 값은 소비 즉시 비워, 일반 탭/뒤로 이동이 낡은 포커스를 물려받지 않음
- 홈 버튼 내비는 PUSH 라 ADR-031 스크롤 복원(POP/탭 전환만)과 무관 → `scrollIntoView` 유지
- 책 목록 앵커에 `data-book-id` 식별자 추가
