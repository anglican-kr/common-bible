# fix: 선택된 마지막 절 hover 라운드 처리 회귀

## 증상

북마크할 절을 연속으로 선택하면, 인접한 절끼리는 배경 블록이 이어져 보이고 그 경계는 라운드 없이 평평하게 처리되는 것이 정상 동작이다. 그런데 선택된 마지막 절은 좌측 모서리(top-left, bottom-left)까지 라운드되어, 직전 절과의 연결이 끊긴 것처럼 보이는 현상이 있었다.

스크린샷 비교:
- 14-15절 선택: 끝 모서리 우측만 라운드 (정상)
- 14-16절 선택: 마지막 절 16의 좌측 모서리까지 라운드 (회귀)

## 원인

`body.verse-select-active .verse[data-vref]:hover` 규칙이 `border-radius: 5px`를 4 모서리 전체에 적용한다.

| 셀렉터 | 명세도 |
| --- | --- |
| `body.verse-select-active .verse[data-vref]:hover` | 0,4,1 |
| `.verse.verse-selected.verse-selected-join-prev` | 0,3,0 |

iOS Safari의 sticky hover 특성상 절을 탭한 직후 `:hover` 상태가 그 절에 그대로 남는다. 마지막으로 탭한 절(= 선택된 마지막 절)은 hover 규칙이 join-prev 규칙을 명세도로 이기면서 좌측 라운드가 복원된다.

## 수정

이미 선택된 절은 hover 규칙을 적용하지 않도록 `:not(.verse-selected)`를 추가했다. join 규칙이 그대로 유지된다.

```diff
- body.verse-select-active .verse[data-vref]:hover {
+ body.verse-select-active .verse[data-vref]:not(.verse-selected):hover {
    background: color-mix(in srgb, var(--accent) 10%, transparent);
    border-radius: 5px;
  }
```

선택되지 않은 절의 hover 피드백(연한 강조 배경)은 그대로 유지된다.

- [ ] 데스크톱: 미선택 절에 마우스 오버 시 hover 강조 배경이 정상 표시되어야 한다.
