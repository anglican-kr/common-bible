## 요약

교회력 설계서 `docs/design/liturgical-engine.md`를 절마다 고쳐 쓰며 내용을 검증하는 작업(known-issues §24)의 일곱째 PR이다. §7(테스트 계획)과 §8(구현 단계)을 다뤘다. 처음 계획은 §7-§9를 한 PR로 묶었는데, §9(미결)가 67KB로 다른 차수의 두 배가 넘어 따로 뺐다. 그래서 설계서 고쳐 쓰기는 PR 11개가 된다.

- 사실을 하나씩 뽑아 CI 설정, 테스트 파일, 픽스처, 엔진, 데이터, GitHub의 PR 기록과 대조했다. 낡은 내용은 고쳤다(아래 「확정 · 근거」).
- 문장을 `docs/writing.md`에 맞게 고쳐 썼다. 가운뎃점으로 잇던 케이스 id와 낱말을 쉼표와 문장으로 풀었고, 픽스처 표는 묶음 이름을 굵게 해 읽기 쉽게 나눴다. 「throw」는 「예외를 던진다」로, 「단언」은 「확인」으로, 「뷰」는 「화면」으로 바꿨다. 숫자 구간의 물결표는 하이픈이나 「부터 … 까지」로 바꿨다.
- 두 표는 표 그대로 두었다. 다른 문서, 픽스처, 테스트가 「§7 B1 행」, 「§7 이동 계산 행」처럼 표의 행을 20곳 넘게 가리키기 때문이다.

## 확정 · 근거

어긋난 것은 모두 문서가 구현이나 기록을 설명하다 낡은 경우였다. 사용자 결정이나 기도서 규칙과 코드가 어긋난 곳은 없었다.

- **픽스처 표에 케이스 하나가 빠져 있었다.** #404에서 더한 W-2025-04-23-george-easter-octave(부활 8일 평일의 축일)를 「부활 8일 평일의 축일」 묶음으로 더했다. 세 픽스처 파일의 케이스(33, 26, 29)와 표의 id가 이제 하나씩 맞는다.
- **소재일을 빼는 기간의 끝.** 「12.25~세례주일」이라 했는데, 엔진의 `christmasToBaptism`은 주님의 세례 전날에 끝난다(2026년은 1.10까지, 세례는 1.11). 「12.25부터 주님의 세례 전날까지」로 고쳤다.
- **물결표 셋이 한 칸에 있었다.** 기간 축 행의 「E−7~E+7」, 「12.25~세례주일」, 「E+40~E+48」은 GitHub에서 물결표 쌍이 취소선으로 그려질 자리였다. 「부터 … 까지」로 바꿨다.
- **§8의 PR 날짜를 머지한 날로 맞췄다.** 표의 날짜가 PR을 연 날, 커밋한 날, 머지한 날로 섞여 있었다. GitHub 기록으로 머지한 날(한국 시간)을 확인해 #319는 09-05(문서 09-01), #325는 09-17(문서 09-13), #346은 10-14(문서 10-12), #347은 10-15(문서 「10-13 ~ 10-14」), #349는 10-17(문서 10-16)로 고쳤다. 그 밖은 맞았다.
- **§8에 #402-#404를 더했다.** 기도서 대조로 밀린 prec 7 축일의 기념(#402), 연쇄 범위 규칙 폐기(#403), 부활 8일 평일의 축일(#404)이 엔진을 바꿨는데 구현 단계 표에 없었다. 「3 후속 4」 한 행으로 더했다. 「이후」 행에는 A2 캘린더 탭 2단계와 A4 검색 이원화가 남았다는 것을 적었다(ADR-038 머리와 같다).
- **없어진 문서를 가리키던 곳.** 「머지 시 … `docs/status.md` … 를 함께 갱신한다」의 `docs/status.md`는 docs 재구성 #371(2026-10-23)에서 주제 문서로 나뉘어 없어졌다. 교회력 주제 문서(`docs/topics/liturgical.md`)의 「지금 동작」으로 고치고, 옛 이름이 왜 없는지 적었다.
- **「옮길 수 있는 공통 분류 성인 8건」**이 data#37 뒤에도 8건이고 모두 자기 날짜의 고유 독서를 가진다는 것을 다시 확인해 적었다.

확인했고 맞았던 것:

- `test.yml`의 필수 `Unit tests`는 서브모듈 없이 `node --test tests/unit/*.test.js`를 돈다. `engine-data.yml`은 main push에 돌고 `liturgical-engine.data.test.js`를 포함한다. `sync-data.yml`이 `docs-data-consistency.test.js`, `sw.test.js`, `liturgical-engine.data.test.js`를 돈다.
- 엔진 테스트 하네스의 `extractBlock`, 컨텍스트의 `Date`, `JSON.parse(JSON.stringify(v))` 정규화.
- 1900-2100의 부활 3.23-4.25, 재의 수요일 2.5-3.10, 9.14와 12.13이 수요일인 해 각 28회. `transferGuard` E−7부터 E+7까지, `ascensionToPentecost` E+40부터 E+48까지. 범위 밖 해(2060)의 음력 후보는 예외 없이 0건이다.
- 성탄주간 1.3-1.5의 독서(1요한 2:29-3:6과 요한 1:29-34, 3:7-10과 1:35-42, 3:11-21과 1:43-51). 01.01에 거룩한 이름 예수 독서 2건이 있다.
- 성인 공통 폴백의 불변식 79, 13, 17과 양성, 음성 케이스는 실데이터 테스트(C-5.6-4)가 그대로 확인한다. 안드레아의 분류 `apostle`은 공통 분류가 아니다.
- 픽스처의 잠정, skip 표시(T-2026-07-27-anna-joachim, 동률 둘, A-2030-02-03, W-2027-09-26, W-2025-12-29, T-2032-02-12의 skip)가 표의 표시와 같다. 미결33은 대기다.
