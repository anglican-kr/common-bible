## 개요

ADR-026 Stage 1b — 노트 **캘린더(월/주) 뷰 + 백업 + 에디터 북마크 삽입**. 1a에서 보류했던 피처들을 마무리합니다. base = `release/1.6.0`.

## 포함

**캘린더 뷰** (`js/app/notes.js`)
- 노트 화면 뷰 토글 **목록 / 월 / 주** (선호 `localStorage["bible-notes-view"]`).
- **월**: 순수 JS 6×7 그리드(일요일 시작), 노트 있는 날 점/개수 마커, 오늘 강조, 이전/다음/오늘, 셀 탭 → 그날 노트 + "이 날짜로 새 노트".
- **주**: 7일 행에 노트 제목 인라인 + 날짜별 "+", 이전/다음/이번 주.
- 캘린더에서 만든 노트는 `date` 미리설정.

**백업** (§4.6)
- ⋯ 메뉴 → JSON 내보내기/가져오기(병합·덮어쓰기), 전체 마크다운 내보내기.
- `notesStore.importNotes(list, mode)` — merge=새 id 추가, overwrite=tombstone 후 추가. Blob 다운로드(무의존).

**북마크 삽입** (§4.5)
- 에디터 도구모음 📑 → 저장된 구절 북마크 시트 → `loadChapter` + `extractVersesText(verseSpec)` → 인용블록 + 출처 링크를 커서에 삽입(스냅샷).
