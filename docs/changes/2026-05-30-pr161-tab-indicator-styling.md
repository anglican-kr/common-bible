# style: 구분 탭 인디케이터를 떠 있는 칩으로 변경

## 요약

성서 목록의 구분 탭(구약·외경·신약) 활성 인디케이터를 **테마색 아웃라인 + 옅은 틴트** 박스에서 **트랙 위에 떠 있는 입체 칩**으로 변경.

요청 사항 3가지를 반영:
1. **배경색을 트랙과 동일하게** — accent 12% 틴트 → `background: var(--bg-card)` (트랙과 동색)
2. **그림자로 입체감** — `box-shadow: 0 1px 3px rgba(0,0,0,.12), 0 1px 2px rgba(0,0,0,.08)` (iOS 세그먼트 컨트롤 톤)
3. **윤곽선에서 테마색 제거** — `2px solid var(--accent)` → `1px solid var(--border)` (중립)

## 세부

- 다크 테마는 그림자가 묻히므로 칩 배경을 트랙보다 살짝 밝게(`color-mix(... #fff 8%)`) + 그림자 알파 보강.
- 활성 탭 **텍스트 색은 `var(--accent)` 유지** — 윤곽선만 중립화 (요청 범위).
- 슬라이드 transform / `_prevDivisionIdx` 애니메이션 로직은 불변 → JS 변경 없음.
