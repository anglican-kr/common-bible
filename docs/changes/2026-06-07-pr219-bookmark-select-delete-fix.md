# feat: 북마크 이동 모달 재정비 + 상위 폴더 지정 새 폴더, ≡ 핸들 색 완화

## 배경

선택 모드 두 모달의 디자인 패턴이 어긋나고(이동 모달엔 상단 `새 폴더…` 행, 저장 모달은 콤보박스), ≡ 재정렬 핸들 색이 과하게 진했다(스크린샷). 디자인 가이드(DESIGN.md §2)엔 약화 어포던스용 색 tier 자체가 없었다.

## 변경

### 1. 이동 모달 재정비 (`#bm-move-modal`)
- 상단 `새 폴더…` 행을 들어내고 **① 최상위 먼저 ② 폴더 목록(들여쓰기) ③ 목록 하단 "새 폴더" 버튼** 순서로 재배치.
- "새 폴더" 버튼은 hairline 으로 목록과 분리, `--accent` 틴트로 *목적지가 아닌 액션*임을 신호.
- (요청대로) 본격 트리 위젯은 **미채택** — 목록 + 들여쓰기로 충분하고 저장 모달과 일관.

### 2. 상위 폴더 지정 가능한 새 폴더 모달 (`#bm-new-folder-modal`)
- **"상위 폴더" 필드 신설** — 저장 모달과 **동일한 폴더 콤보박스**(`_buildFolderCombobox`)를 재사용.
- 콤보박스를 `{ idPrefix, allowNewFolder }` 로 파라미터화: `idPrefix` 로 id 충돌 회피(두 콤보박스 공존), `allowNewFolder:false` 로 내부 "+새 폴더"의 자기-재귀 호출 방지.
- **미지정 = 최상위**(`insertItem(store, null, …)`), 지정 시 그 폴더 하위 생성 후 자동 펼침.
- 이동 흐름의 "새 폴더"는 이 모달을 열고, 생성된 폴더로 선택 항목을 이동.

### 3. ≡ 재정렬 핸들 색 완화 + 색 tier 기준 수립
- DESIGN.md §2 팔레트에 **`--text-tertiary`** 신설(라이트 `#948e83` / 다크 `#707070`) — 보조 텍스트보다 한 단 연한 **약화 어포던스 글리프**용("있되 물러난" 표식, 재정렬 핸들·disclosure·비활성 보조 아이콘).
- `.bm-drag-handle` 색을 `--text-secondary` → `--text-tertiary`.

> 
> **Overview**
> 북마크 **이동**·**새 폴더** 모바일 흐름을 저장 모달과 맞추고, 재정렬 ≡ 핸들용 약한 텍스트 토큰을 추가한다.
> 
> **이동 모달(`#bm-move-modal`)**에서는 상단 `새 폴더…` 행을 없애고 **최상위 → 들여쓰기된 폴더 목록 → hairline 아래 `--accent` 틴트의 "새 폴더" 버튼** 순으로 재배치한다. **새 폴더 모달**에는 **상위 폴더** 필드를 넣고, `_buildFolderCombobox`를 `idPrefix`·`allowNewFolder:false`로 재사용해 저장 모달과 동일한 콤보를 띄운다. 폴더 생성은 루트 push 대신 **`insertItem` + 선택 시 부모 `expanded`**로 바뀌며, 이동 경로의 "새 폴더"는 **`folderFilter`로 이동 중인 폴더·하위를 상위 후보에서 제외**한 뒤 만들고 선택 항목을 그 폴더로 옮긴다.
> 
> **디자인**으로 `DESIGN.md`·`css/style.css`에 **`--text-tertiary`**(라이트/다크)를 정의하고 `.bm-drag-handle` 색을 `--text-secondary`에서 이 토큰으로 낮춘다. ADR-029·`CLAUDE.md`와 e2e `test_move_new_folder_with_parent`·`test_move_new_folder_excludes_selected_parent`가 함께 갱신된다.
