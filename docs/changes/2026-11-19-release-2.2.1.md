## 요약

버전을 2.2.0에서 2.2.1로 올린다(`python3 scripts/release.py patch`). 2.2.0 뒤에 전례일 검색 결과를 이번 전례년의 날로 통일하고 사계재를 날마다 한 줄로 나눈 것(#608, 데이터 #88), 검색어를 지울 때 키보드를 내린 것(#610), 휴대폰의 검색 입력창을 검색 화면 위쪽으로 옮긴 것(#612, ADR-048)이 들어간다.

아래 「릴리스 노트 초안」은 머지한 뒤 GitHub Release에 그대로 쓴다. 「변경 사항」은 `python3 scripts/changelog.py 2.2.0 HEAD`의 출력이고, 끝의 비교 링크만 2.2.1 태그를 가리키게 고쳤다.

## 릴리스 노트 초안

### 기능 개선

- 전례일 검색 결과의 날짜를 모두 이번 전례년(대림 1주일부터)의 날로 맞췄습니다. 지금까지는 해마다 같은 독서를 읽는 날만 다가오는 날을 보여 주어, ‘대림’을 검색하면 주일은 지난 대림의 날짜가, 평일은 다가오는 대림의 날짜가 섞여 나왔습니다. 해마다 같은 독서를 읽는 날에는 다음 전례년에 그날이 언제인지도 함께 적습니다. 지난 날짜 앞에 붙던 ‘지난’은 뺐습니다.
- 사계재를 날마다 한 줄로 보여 줍니다. ‘춘계재’로 검색하면 ‘춘계재 수요일’, ‘춘계재 금요일’, ‘춘계재 토요일’이 따로 나오고, ‘사계재’로 검색하면 춘계재, 하계재, 추계재, 동계재의 사흘이 모두 나옵니다.
- 휴대폰의 검색 입력창을 검색 화면 위쪽으로 옮겼습니다. 아래의 돋보기 단추를 누르면 검색 화면으로 가고, 검색 화면에서 한 번 더 누르면 입력창에 커서가 들어가 키보드가 올라옵니다. 지난 검색 결과를 보러 왔을 때 키보드가 결과를 가리지 않습니다.

### 버그 수정

- 검색 입력창의 ‘×’를 눌러 검색어를 지우면 키보드가 올라와 최근 검색 목록을 가리던 문제를 고쳤습니다. 이제 지우면 키보드가 내려갑니다.
- 아이폰에서 검색 화면의 입력창을 누르면 화면이 위로 튀었다가 돌아오던 문제를 고쳤습니다.
