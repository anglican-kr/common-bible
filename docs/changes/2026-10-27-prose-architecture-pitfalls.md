## 결정 대기

정해야 할 낱말이라 고치지 않고 두었다. 권장안은 검토한 Claude의 의견이다. 사용자가 정한 것은 「리뷰 반영」에 있다.

- **「ghost」**(`coding-pitfalls.md` 90행): 북마크를 끄는 동안 포인터를 따라 움직이는 행의 사본이다(`bookmark-gestures.js`의 `ghost`). 후보는 「끄는 동안 보이는 행 사본」, 「드래그 그림자」, 「끌려오는 복제 요소」다. 권장은 「끄는 동안 보이는 행 사본」이다. 하는 일로 지은 이름이고, 「그림자」는 CSS의 그림자와 헷갈린다.
- **「동기 dispatch」**(`coding-pitfalls.md` 196행): `enable()`이 상태를 그 자리에서 바꾸던 호출이다. 후보는 「동기 전이」, 「동기 전이 호출」, 그대로다. 권장은 「동기 전이」다. 같은 절의 181, 182행이 「동기적으로 … 전이한다」를 쓴다.
- **제목 줄의 영어 낱말과 비유 동사**: `coding-pitfalls.md`의 §5 「보일러플레이트」, §7 「bump」, §10 「quirk」, §12 「leak」과 「flow별 transport」, §15 「sidecar」, §16 「init」, 「facade」, 「race」, §23 「닿는」, §33 「풀린다」와 「길」, §35 「샜다」, §38 「옛 판」(「용어」 표는 「옛 버전」), `architecture.md` 4.3의 「appdata」. 권장은 다음과 같다.
  - 주제 문서로 옮긴 절은 #444에서 고쳐 쓴 주제 문서의 제목을 그대로 쓴다. 주제 문서의 제목에도 남은 말은 두 곳을 함께 고친다. §7은 「셸 버전 올리기와 콘텐츠 매니페스트 두 가지다」, §23은 「연쇄 범위가 적용되는 곳」, §38은 「옛 버전이 저장한」이다.
  - 이 문서에 본문이 있는 절은 §5를 「모달과 접근성에 늘 넣는 코드 누락」, §10을 「플랫폼마다 다른 동작을 놓침」, §35를 「가져오기 검사가 리뷰마다 경우를 빠뜨렸다」로 쓴다.
  - `architecture.md` 4.3은 본문과 같게 「동기화 (Drive 앱 전용 폴더와 PKCE)」로 쓴다.

## 요약

문장 교정 반복 실행의 넷째 묶음이다. 진행 목록 「2. 루트 문서와 `docs/`의 나머지」에서 위에서부터 남은 `docs/architecture.md`(322줄)와 `docs/coding-pitfalls.md`(197줄)를 골랐다. 합이 519줄로 400줄 안팎보다 많지만, 둘째 파일만 빼면 322줄이라 둘을 한 묶음으로 했다. 파일마다 Sonnet 서브에이전트로 교정하고, 바뀐 내용을 Claude가 다시 읽어 고쳤다. 330줄 남짓이 바뀌었다.

- **기계 검사의 전후**(2개 파일): `particle` 54에서 2, `tilde` 1에서 0, `term` 1에서 0, `particle?` 5에서 3, `term?` 27에서 26, `verb?` 9에서 1, `english?` 197에서 51, `arrow?` 10에서 0, `dot?` 548에서 48, `dash?` 168에서 4.
  - 남은 `particle` 둘은 `coding-pitfalls.md`의 제목 줄이라 처음에는 두었고, 사용자가 정한 뒤 붙였다(「리뷰 반영」).
  - 남은 `term?`은 화면 이동, 장 이동, 이동 축일, 북마크 선택 모드의 「이동」 단추, 검색 결과가 늦게 「도착」하는 경우라 바른 쓰임이다. 남은 `dot?`와 `dash?`는 제목 줄, 표의 빈 칸 「—」, 부록 A의 상태 꼬리, 「2026-05-09 · 05-10」이다.
- **검토하며 다시 고친 곳은 14곳이다.**
  - 코드 표기를 나눈 곳 셋을 되돌렸다. `verse-spec.js isWellFormedSpec`(두 파일)과 `SYNC_ENABLED_KEY = "1"`이다.
  - 「main부터」를 「이 PR 전부터」로 옮긴 세 곳은 어느 PR인지 흐려 「이전부터」로 고쳤다.
  - 「빈 값으로 호출해」는 「인자 없이 호출해」로, 「참 거짓」은 한 낱말 「참거짓」으로, 「옛 스크롤 위치로 갔다」는 「옮겨 갔다」로, 「이유는 셋이다」는 이어지는 이유가 넷으로 읽혀 「이유는 다음과 같다」로 고쳤다.
  - `architecture.md`의 「(SPA)** 이고」의 띄어 쓴 조사, 「그 초기 형태라 할 수 있다」(주장의 강도가 바뀐 것), 「토글 하나로 켜고 끄는 그리기」, 「등록부(registry)를 역전한다」를 고쳤다.

## 리뷰 반영

사용자가 「결정 대기」를 정했다(2026-10-28). 권장안이 있는 것은 권장안대로 하고, 전략 이름과 cold-start는 사용자가 고른 말로 썼다.

- **제목 줄의 가운뎃점과 줄표**: 가운뎃점은 「과」, 「와」, 「이나」나 쉼표로, 줄표는 쌍점으로 바꿨다. 같은 제목에 든 「/」, 「+」, 「vs」, 「↔」도 같은 규칙으로 고쳤다.
  - 이미 머지된 묶음(#444, #447)의 제목에 같은 쓰임이 있어 함께 고쳤다. 함정 제목을 옮겨 적은 `workflow.md`와 `writing.md`의 제목도 `coding-pitfalls.md`와 같게 맞췄다. `writing.md`는 아직 본문을 교정하지 않았지만 제목만 고쳤다.
  - §18-§25는 #444에서 고친 `docs/topics/liturgical.md`의 제목과 같게 썼다. 그래서 §19의 「자」가 「자색」이 되었다.
  - §17은 「— 작업 방식 교정」을 쌍점으로 바꾸면 뒤의 말이 제목의 풀이처럼 읽혀, §26과 §30처럼 괄호 안으로 옮겼다.
  - `coding-pitfalls.md` 「패턴 추가 가이드」의 서식 예도 새 제목 형식과 본문의 사례 형식(「`<커밋해시>`: 한 줄 요약」)으로 고쳤다.
  - 바꾼 제목을 가리키는 곳은 둘이었다. `architecture.md` 337행의 README 링크 앵커와 `writing.md` 84행의 「학술과 법률 문체 낱말」이다.
  - 그대로 둔 것: 문서 검사(`tests/unit/docs-wiki.test.js`)가 읽는 앞머리 「### pitfalls §N — 」와 「### known-issues §N — 」, `known-issues.md`의 「— 해소 (날짜)」 상태 표시, 날짜 사이의 가운뎃점, 코드 블록 안의 원장 서식 「## 확정 · 근거」.
  - 아직 교정하지 않은 ADR-011(721-723행)이 옛 함정 제목을 목록으로 옮겨 적었고, `tests/unit/transport.test.js` 418행의 구분 주석도 옛 제목을 쓴다. 이 둘은 그 파일의 교정 차례에 고친다. ADR-011은 열린 #451도 고치고 있다.
- **제목 줄의 띄어 쓴 조사**: 「3.01은」, 「`// @ts-check`가」로 붙였다.
- **전략 이름**(`coding-pitfalls.md` 28-30행): 「제너레이션 카운터」, 「순번」, 「단일 실행 플래그」로 썼다.
- **cold-start**: 「앱을 처음 여는 경로」로 썼다. `architecture.md` 324행의 「앱을 다시 켰을 때(콜드 스타트)」에서도 괄호를 뺐다. 문장 검사(`tools/prose/prose.py`)의 낱말 목록에는 더하지 않았다. 열린 #451이 같은 목록의 바로 옆 줄을 고쳐 충돌하기 때문이다.
- **권장안대로 둔 것**: scrim과 elevation(`DESIGN.md`와 ADR-028을 따른다), 부록 A의 dispatch, registry, explode, 부록 A 상태 꼬리의 가운뎃점.
- **남은 결정**: ghost와 동기 dispatch는 권장안이 없었다. 제목 줄의 영어 낱말은 처음 「결정 대기」에서 기호와 함께 적었지만 권장안이 기호만 다뤘다. 셋 모두 권장안을 붙여 「결정 대기」에 남겼다.
- 다시 검증했다. `same-code`는 주석과 문서 말고 바뀐 파일 0개, 문서 검사는 30개 통과와 1개 건너뜀, 교회력 사실 토큰 비교는 사라진 토큰과 줄어든 토큰 0이다. 고친 열두 문서의 일반 토큰 비교는 `writing.md`에서 사라진 토큰이 하나 나왔다. 이름을 바꾼 소제목을 가리키던 인용 「학술 · 법률 문체 낱말」이라 의도한 것이다. `prose.py lint`는 이 묶음의 두 파일에서 `particle`, `tilde`, `term`이 모두 0이다. 고친 문서 전체로는 `workflow.md` 85행의 `particle` 하나가 남는다. 사용자의 말을 그대로 옮긴 인용이라 #447에서 둔 것이다.
