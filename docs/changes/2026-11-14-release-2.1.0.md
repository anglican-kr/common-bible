## 요약

버전을 2.0.1에서 2.1.0으로 올린다(`python3 scripts/release.py minor`). 2.0.1 뒤에 설정의 소속교회와 세례명(#539, #542, #543, #545, #548), 인앱브라우저에서 기기의 브라우저로 자동 전환(#554), 명절과 주일의 우선순위(#541), 성서 인물 이름의 표기(#552)가 들어왔다. 앞 본문의 일부인 「또는」을 한 독서로 그리는 변경(#557)과 그 코드 리뷰를 반영한 변경(#558, #559)은 사용자 결정(2026-11-14)에 따라 이 릴리스 브랜치에 머지했다. 이 PR을 머지한 뒤 태그와 GitHub Release를 만들고 dev와 운영에 배포한다(`docs/workflow.md` 「릴리스」).

아래 「릴리스 노트 초안」은 머지한 뒤 GitHub Release에 그대로 쓴다. 「변경 사항」은 `python3 scripts/changelog.py 2.0.1 HEAD`의 출력이고, 끝의 비교 링크만 2.1.0 태그를 가리키게 고쳤다.

## 확정 · 근거

- **판 번호**(사용자 결정 2026-11-14): 2.1.0으로 올린다. 버전은 기능 PR(#554)과 따로 릴리스 PR에서 올린다. 태그, GitHub Release, 배포의 시점은 사용자가 정한다.
- **노트의 짜임**(구현하며 정함). 소속교회, 세례명, 인앱브라우저 자동 전환은 2.0.1에 없던 것이라 「새 기능」이다. 교회 축성일 목록(#537)과 성서 인물 이름(#552)은 있던 내용을 고친 것이라 「기능 개선」이다. 명절과 주일(#541)은 2.0.1에서 캘린더가 책자와 다르게 보이던 문제라 「버그 수정」이다. 세례명 안내의 문장(#548)과 소속교회, 세례명, 자동 전환을 만들며 고친 것은 이번 판에서 새로 만든 기능이라 따로 적지 않았다.
- **노트에 넣지 않은 것.** 성무일과 전례독서 데이터(#547, data#72)는 아직 화면이 없어 사용자가 겪지 않는다. 장을 건너뛰는 성구 범위의 가운데 장 누락(data#74)은 성무일과 표기에서 찾은 오류이고, 감사성찬례 전례독서의 화면에서 달라지는 곳이 있는지는 확인하지 않아 넣지 않았다. 문서, 시험, 설정 코드 정리(#540, #549, #555)도 넣지 않았다.
- **확인하지 못한 것.** #554의 마지막 변경(기본 브라우저가 네이버 앱인 Android 기기에서 일반 설치 안내를 보임)은 e2e로만 확인했고, 실기기와 dev에서는 보지 않았다. 라인과 인스타그램의 자동 전환도 실기기에서 확인하지 않았다(`docs/topics/install-a11y.md` 「남은 일」).
- **릴리스마다 하는 정리**(CLAUDE.md 「지식 베이스 루프」 3번): 2.0.1(2026-11-09) 뒤의 원장은 #557, #558, #559의 것까지 16개다. 새 설계 문서는 없고 새 ADR은 ADR-042 하나다. ADR-042는 상태가 「제안됨」이라 `docs/architecture.md` 부록 A에 아직 없다. `docs/index.md`와 실제 파일, 링크, 번호 대장은 문서 검사가 맞는지 본다(통과). 200줄을 넘긴 문서는 2.0.1 때와 같은 여섯이고, 그 가운데 `docs/topics/liturgical.md`가 699줄에서 751줄로 늘었다. 이번에도 나누지 않는다.

## 검증

버전 파일 둘을 2.1.0으로 바꾼 상태에서 점검했다.

- `node --test tests/unit/*.test.js`: 1,752건 통과(#557, #558, #559를 합친 뒤 다시 돌렸다). 타입 검사(`npm run typecheck`): 통과.
- CSP 점검: `python -I tools/csp/csp_sweep.py http://localhost:8092`(서비스 워커 막음)과 `--sw`(켬) 모두 위반 0종. 건너뛴 단계는 이 브라우저에서 할 수 없는 데스크톱 오디오 재생 하나다(2.0.1과 같다).
- e2e: 버전과 관련된 `test_update_toast.py`, `test_liturgical_lazy_load.py`와 #554가 바꾼 `test_install_guide.py`를 합쳐 48건 통과. #557, #558, #559가 바꾼 전례독서 e2e의 결과는 그 원장들(`2026-11-14-saints-common-readings-render.md`, `2026-11-14-alternative-merge-review.md`, `2026-11-14-lectionary-merge-followup.md`)에 있다. CSP 점검과 이 48건은 세 PR을 합치기 전에 돌렸다. 세 PR은 전례독서 화면의 코드와 문서를 바꾸고, #558은 `css/style.css`에 규칙 하나를 더한다. 전체 e2e는 돌리지 않았다(`docs/workflow.md` 「작업 중 함정」).
- 배포한 뒤 dev와 운영의 `version.json`이 2.1.0인지 실제 사이트에서 확인한다.

## 릴리스 노트 초안

### 새 기능

- 카카오톡, 라인, 네이버, 인스타그램, 페이스북에서 링크를 누르면 본문이 보인 뒤 Safari나 Chrome 같은 기기의 브라우저로 넘어갑니다. 이런 앱 안의 화면에서는 홈 화면에 앱을 설치할 수 없고, 저장한 북마크도 브라우저와 따로 보관되기 때문입니다. 넘어가지 못한 때에는 「브라우저에서 열기」와 「주소 복사」 단추가 있는 안내가 열립니다.
- 설정의 「전례독서」에서 소속교회를 고를 수 있습니다. 고른 교회의 축성일에는 전례독서가 축성일 독서를 먼저 보여 줍니다. 그날이 주일이나 대축일이면 축성일은 전례독서 목록의 맨 앞 줄에 나옵니다.
- 소속교회가 속한 교구의 설립일에는 그날의 본기도 뒤에 교구 설립 본기도가 이어집니다. 서울교구와 대전교구는 5월 27일, 부산교구는 6월 1일입니다.
- 설정의 「전례독서」에서 세례명을 고를 수 있습니다. 고른 성인의 축일에는 전례독서 목록에 그 성인의 독서가 나옵니다.

### 기능 개선

- 전례독서에 나오는 교회 축성일을 「2026 전례독서」 책자에 맞췄습니다.
- 전례독서에서 「시편 116 또는 116:1-9」처럼 뒤의 본문이 앞 본문의 일부인 독서를 「독서 1」, 「독서 2」로 나누지 않고 하나로 보여 줍니다. 긴 본문을 싣고, 짧게 읽을 때 빼는 절을 〔 〕로 묶습니다. 성 십자가의 날(9월 14일), 성 십자가 발견(5월 3일), 라틴 문 앞의 사도 성 요한(5월 6일)의 시편, 성지주일 가해와 다해의 수난 복음, 세례명의 축일에 나오는 성인 공통 독서가 해당합니다. 화면 낭독기는 〔 〕로 묶은 절의 처음과 끝을 「선택 구절 시작」, 「선택 구절 끝」으로 읽습니다.
- 성서에 나오는 인물의 이름을 공동번역 성서의 표기로 바꿨습니다. 「스테파노」는 「스데파노」로, 「미카엘」은 「미가엘」로 나옵니다.

### 버그 수정

- 설날이나 추석이 주일과 겹치는 날에 캘린더와 전례독서 제목이 주일이 아니라 명절로 나오던 문제를 고쳤습니다. 이제 주일이 먼저 나오고, 명절 독서는 전례독서 목록에서 고를 수 있습니다. 2027년 2월 7일이 처음 해당하는 날입니다.
