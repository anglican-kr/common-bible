## 요약

전례독서 화면에서 대안 세트 세그먼트(「독서 1 · 2」, 「사순 2주일 · 주의 변모 주일로 지킬 때」) 위의 「대안 독서」 글자를 뺐다(사용자 결정 2026-11-04, 2026-11-22 왕이신 그리스도 주일의 화면). 독서와 본기도를 함께 고르는 단추(5.1, 사계재 금요일) 위의 「독서 · 본기도」는 남긴다. ADR-038 §3 「대안 세트·트랙 전환」.

## 확정 · 근거

- **트랙 세그먼트와 맞췄다.** 2026-11-03에 트랙 세그먼트 위의 「독서」 글자를 단추 이름과 겹친다는 이유로 뺐다. 대안 세트 세그먼트는 그때 논의에 없어 「대안 독서」가 남아 있었다. 사용자에게 세 안을 보였고, 사용자가 글자만 빼는 안을 골랐다. 버린 두 안(그대로 두기, 단추 이름을 두 세트가 다른 곳으로 바꾸기)은 ADR-038 「검토한 대안 — 대안 세트 세그먼트 위의 글자」에 적었다.
- **2025-2027년 실데이터에서 대안 세트 세그먼트는 82일에 보인다.** 76일은 「독서 1 · 2」, 3일은 조건부 세트, 3일(5.1)은 「독서 · 본기도」다. 트랙 세그먼트와 한 화면에 함께 나오는 날은 없어, 두 세그먼트가 같은 「독서 1 · 2」여도 헷갈리지 않는다. 2026-11-22(가해)의 두 세트는 시편만 다르다(시편 100, 시편 95:1-7).
- **남긴 것.** 「독서 · 본기도」 글자는 단추가 본기도까지 바꾼다는 것을 알린다. 스크린 리더가 읽는 세그먼트 이름은 「대안 독서」 그대로다(트랙 세그먼트의 「독서 트랙」과 같다).

## 검증

- 유닛 `node --test tests/unit/*.test.js`: 1475개 가운데 1474개 통과, 1개 건너뜀(실패 0). 타입 검사 통과(작업 폴더에 `node_modules`가 없어 원래 폴더의 `tsc`로 `npm run typecheck`와 같은 두 설정을 검사했다). 바뀐 것은 화면을 그리는 함수(`buildControls`)라 유닛이 보지 않는다.
- e2e 전체(`pytest tests/e2e/`, 작업 폴더 서버 8091): 421개 모두 통과(11분 26초).
- e2e 더함(`test_lectionary_view.py`): 부활대축일의 「독서 1 · 2」와 사순 2주일의 조건부 세트 위에 글자가 없고, 세그먼트의 접근 가능한 이름이 「대안 독서」인지 본다. 5.1의 「독서 · 본기도」 글자는 기존 시험이 본다.

## 갱신한 문서

## 리뷰 반영

1회차(서브에이전트 코드 리뷰, 2026-11-04). 고칠 것은 없었다. 접근 가능한 이름(`<nav aria-label>`)이 남는 것, 세그먼트 하나만 남아도 CSS 간격이 트랙 세그먼트와 같은 것, 원장의 날짜 수(82일, 76, 3, 3)와 두 세그먼트가 한 화면에 함께 나오는 날이 없다는 것(모든 칩과 트랙 조합, 2025-2050년)을 확인했다. 참고로 받은 둘을 반영했다. CSS 주석의 「labelled」를 「독서 · 본기도」 단추에만 글자가 있다고 고쳤고, `tests/README.md`의 e2e 행에 새 확인을 적었다.
