# feat: 즐겨찾기(북마크) 기능

## 개요

읽고 있는 장 또는 선택한 절을 북마크로 저장하고, 폴더로 분류·관리할 수 있는 기능을 추가합니다.

## 주요 변경 사항

### URL 확장
- 비연속 절 범위 지원: `/john/3/1-5,10-15` 형식
- 절 세그먼트 식별자 지원: `/ps/23/3a,3b` 또는 `/ps/23/3a,5-7` 형식 (운문 헤미스티치 단위 선택)
- `parseVerseSpec()` · `selectedVersesToSpec()` · `mergeVerseSpecs()` · `collapseFullVerseRefs()` 유틸리티 추가
- `parsePath()` · `renderChapter()` · `route()` 연동

### 북마크 저장소
- `localStorage("bible-bookmarks")` 기반, 오프라인 완전 지원
- 스키마: `Bookmark | Folder` 중첩 트리 구조

### UI 컴포넌트
| 컴포넌트 | 설명 |
|----------|------|
| 헤더 북마크 아이콘 | 장 헤더 우측, 저장된 장은 채워짐 |
| 북마크 드로어 | 오른쪽 슬라이드인 패널, ARIA tree |
| 저장 모달 | 제목·메모·저장 위치 입력 |
| 병합 다이얼로그 | 동일 장 재저장 시 합치기/따로 저장 선택 |
| 절 선택 바 | 롱프레스(300ms) 진입, 하단 고정 바 |
| 드래그 앤 드롭 | 그립 핸들 → 순서 변경 및 폴더 이동 |

### 기능 상세
- **장 저장**: 드로어 "이 장 저장" → 저장 모달
- **절 저장**: 롱프레스 또는 "절 선택" → 클릭으로 절 토글 → 저장
  - 세그먼트(헤미스티치) 단위 선택 지원: "3a", "3b" 개별 선택 가능
  - 절의 모든 세그먼트 선택 시 자동으로 "3" 으로 통합
- **병합**: 같은 장에 북마크 이미 있을 때 합치기/따로 저장 선택
- **폴더 CRUD**: 추가·이름 변경·삭제, 중첩 폴더 지원
- **북마크 CRUD**: 수정·삭제
- **드래그 앤 드롭**: Pointer Events 기반(마우스·터치), 폴더 내부 이동, 순환 참조 방지

### 접근성
- ARIA tree widget (`role="tree"`, `role="treeitem"`, `role="group"`)
- 포커스 트랩 + 배경 inert 처리 (기존 패턴 재사용)
- `aria-live` 절 선택 카운트, 저장 완료 announce
- `prefers-reduced-motion` 드로어 슬라이드 전환 비활성화
