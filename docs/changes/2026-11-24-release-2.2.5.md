## 요약

버전을 2.2.4에서 2.2.5로 올린다(`scripts/release.py patch`). 2.2.4 뒤에 운문의 줄바꿈과 들여쓰기(#640, #642, #644), 글자 크기를 따르는 칸의 폭(#645), 가로로 든 아이폰의 안전 영역(#646, #647), 구글 애널리틱스의 측정 ID와 CSP(#648, #653), 본문 데이터 고침 셋(데이터 #93, #94)이 들어간다.

릴리스 커밋과 릴리스 PR의 타입을 이 판부터 `chore`에서 `release`로 바꾼다.

아래 「릴리스 노트 초안」은 머지한 뒤 GitHub Release에 그대로 쓴다. 「변경 사항」은 `python3 scripts/changelog.py 2.2.4 HEAD`의 출력이고, 끝의 비교 링크만 2.2.5 태그를 가리키게 고쳤다.

## 확정 · 근거

- **버전과 순서**(사용자 지시 2026-11-24): 2.2.5다. 릴리스 PR을 머지한 뒤 dev.anglican.kr에 배포하고 운영에도 반영한다.
- **릴리스 커밋의 타입은 `release`다**(사용자 결정 2026-11-24). `scripts/release.py`가 `release: X.Y.Z 릴리스`로 커밋한다. `scripts/changelog.py`는 변경 목록에서 릴리스 커밋을 뺄 때 옛 표기(`chore`)와 새 표기를 모두 본다. 2.2.4까지의 커밋과 원장은 그대로 둔다.
- **운영에는 버전을 올려서 낸다.** #648이 바꾼 측정 ID는 서비스 워커의 셸 캐시에 든 `index.html`과 `js/gtag-init.js`에 있어, 버전이 올라야 앱을 이미 쓰는 기기가 새로 받는다.
- **릴리스 전 CSP 점검이 #653을 찾았다.** #648만 들어간 dev에서는 점검이 위반 38종으로 실패했다. #653을 머지한 뒤 다시 돌려 위반 0종을 확인했다(아래 「검증」).
- **노트의 짜임**(구현하며 정함, `docs/writing.md` 「릴리스 노트」).
  - 「기능 개선」: 운문의 줄바꿈과 들여쓰기, 글자 크기를 따르는 칸의 폭. 이용 통계에 연령대, 성별, 관심 분야의 추정이 더해진 것도 여기에 적었다. 사용자가 알아야 할 변화이고 개인정보 처리방침이 바뀌었다.
  - 「버그 수정」: 2.2.4에도 있던 문제다. 가로로 든 아이폰에서 탭 바의 양 끝 단추와 긴 안내, 북마크 창이 안전 영역에 놓이던 것(#647), 가로로 든 작은 아이폰에서 오디오 막대의 단추가 겹치던 것(#647), 본문 데이터 고침 셋.
  - 「새 기능」은 없다.
- **노트에 넣지 않은 것.** 가로로 든 아이폰에서 큰 글자의 본문을 다이내믹 아일랜드가 가리던 것(#646)은 이번 판의 #645가 만든 문제라 넣지 않는다. 운문의 들여쓰기를 두 번 고친 것(#642, #644)은 이번 판의 #640을 바로잡은 것이라 결과만 「기능 개선」에 적는다. 측정 ID(#648)와 CSP(#653)는 사용자가 겪지 않는다.
- **본문 칸 40rem은 아직 확정하지 않았다.** ADR-055 §2는 dev.anglican.kr에서 실제 기기로 써 보고 운영에 내기 전에 정하기로 했다(`docs/topics/design-system.md` 「남은 일」). 이 결정이 남아 있다고 알린 뒤 사용자가 운영 반영을 지시했다. 「남은 일」의 항목은 사용자가 확정을 말할 때까지 그대로 둔다.
- **이번 판에 들어가지 않는 열린 PR.** #649(주석 툴팁), #650(방문 중복 기록), #651(검색 실패 화면), #652(known-issues)는 다른 세션이 진행 중이다.
- **릴리스마다 하는 정리**(CLAUDE.md 「지식 베이스 루프」 3번).
  - 2.2.4(2026-11-22) 뒤의 원장은 #637, #638, #640, #642, #644, #645, #646, #647, #648, #653의 것이다(#641과 #643은 자동 포인터 PR이라 원장이 없다). 새 ADR은 052, 053, 054, 055이고 모두 `docs/architecture.md` 부록 A에 있다.
  - `docs/index.md`와 실제 파일, 링크, 번호 대장은 문서 검사가 본다(통과). 끝나서 `archive/`로 옮길 설계 문서는 없다. `design/responsive-composition.md`는 남은 항목이 있어 그대로 둔다. 200줄을 넘긴 문서는 전부터 넘었고 이번에 새로 넘긴 것은 없다.

## 검증

버전 파일 둘을 2.2.5로 바꾸고 #653까지 들어간 dev 위에서 점검했다.

- `node --test tests/unit/*.test.js`: 1,991건 통과(실데이터 시험 포함). `npm run typecheck`: 통과. `scripts/test_changelog.py`: 32건 통과.
- CSP 점검: `python -I tools/csp/csp_sweep.py http://localhost:8097`(서비스 워커 막음)과 `--sw`(켬) 모두 위반 0종. 건너뛴 단계는 이 브라우저에서 할 수 없는 데스크톱 오디오 재생 하나다(2.2.4와 같다).
- e2e(서버 8097): 219건 통과. 버전과 관련된 `test_update_toast.py`와 `test_liturgical_lazy_load.py`, 이번 판에서 바뀐 `test_poetry_wrap.py`, `test_rem_widths.py`, `test_safe_area_sides.py`, `test_lectionary_view.py`, 그리고 `test_navigation.py`다. #653을 머지하기 전의 dev에서 돌렸다. #653이 바꾼 것은 CSP의 허용 주소와 `privacy.html`이라 e2e가 보지 않는다.
- 배포한 뒤 dev와 운영의 `version.json`이 2.2.5인지, 내려 주는 측정 ID가 `G-2Q4SRGVNQN`인지 실제 사이트에서 확인한다.
- 실제 아이폰에서는 확인하지 못했다. 구글 시그널의 요청이 WebKit에서도 CSP에 막히지 않는지는 dev.anglican.kr에서 사용자가 본다.

## 릴리스 노트 초안

### 기능 개선

- 시편처럼 운문으로 된 본문은 띄어쓰기 자리에서 줄을 바꿉니다. 지금까지는 낱말 가운데에서 줄이 바뀌어 ‘지날지라도’가 두 줄로 나뉘기도 했습니다.
- 운문의 행은 첫 줄을 반 글자 들여 쓰고, 화면 끝에서 넘어간 줄은 들여 쓰지 않습니다. 선창 끝의 ‘◯’와 낱말에 붙은 따옴표가 혼자 다음 줄로 넘어가지도 않습니다.
- 설정에서 글자 크기를 바꾸면 본문 칸과 화면 아래에서 올라오는 창, 옆 창의 폭도 같은 비율로 달라집니다. 글자를 키워도 넓은 화면의 한 줄에 들어가는 글자 수가 같습니다.
- 앱 이용 통계에 이용자의 연령대, 성별, 관심 분야를 Google이 추정한 값이 더해집니다. 수집하는 내용과 거부하는 방법을 개인정보 처리방침에 적었습니다.

### 버그 수정

- 아이폰을 가로로 들었을 때 화면 아래 탭 바의 양 끝 단추와 긴 안내, 북마크 창이 화면의 둥근 모서리나 카메라 자리에 걸리던 문제를 고쳤습니다.
- 화면이 작은 아이폰을 가로로 들고 오디오를 들을 때 재생 속도 단추가 검색 단추와 겹치던 문제를 고쳤습니다.
- 시편 31:2의 쉼표 뒤 띄어쓰기, 역대기상 7:24의 깨져 있던 지명(‘우쩬세에라’), 전례시편 23:4에 빠져 있던 마침표를 바로잡았습니다.
