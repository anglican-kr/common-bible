## 요약

전례독서 화면에서 시편 자리의 칸 제목이 「시편」으로 보였다. 이제 「성시」로 보인다. 바꾼 곳은 칸 이름을 정하는 상수 `SLOT_LABEL`(`js/app/lectionary.js`) 한 줄이다. 칸 안의 성구 표기(「시편 116」 등)와 데이터는 바뀌지 않았다.

## 확정 · 근거

- 사용자가 칸 제목만 바꾸라고 범위를 정했다(2026-11-06). 성구 표기의 책 이름 「시편」과 데이터의 예시 줄은 그대로 둔다.
- 칸 제목을 확인하는 시험은 없어 시험은 고치지 않았다. e2e 시험의 설명 글 두 곳은 새 이름에 맞췄다.

## 검증

- 유닛 `node --test tests/unit/*.test.js` 1,505건 모두 통과. 타입 검사는 작업 폴더에 `tsc`가 설치되어 있지 않아 실행하지 못했다(CI에서 확인).
- 화면에서 칸 제목을 직접 열어 보는 확인은 하지 않았다.
