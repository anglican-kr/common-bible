# style: 헤더 그림자 간격·강도 보정 + 복음서 4권 모바일 축약명

## 배경

읽기 헤더 관련 두 가지 시각 보정 요청.

### 1. 헤더 그림자–본문 사이 빈 여백 + 라이트 모드 그림자 미인지 (ADR-025)

- `#sticky-group::after` fade gradient(0.25rem `var(--bg)`→transparent)가 `top: 100%` 에 위치해 **그림자가 떨어지는 영역 상단을 불투명하게 덮어**, 헤더와 그림자 사이에 빈 여백이 있는 것처럼 보이게 했다. → fade 제거, 그림자가 헤더 하단 경계에서 바로 시작.
- 라이트 모드 그림자 알파 `rgba(0,0,0,0.04)` 는 흰 배경 위에서 사실상 보이지 않아 elevation 신호로 기능하지 못했다. → `0.04` → `0.12` 로 보강(다크는 `0.25` 유지).
- 경계 신호는 **hairline(always-on) + shadow(스크롤 elevation)** 두 가지로 정리. ADR-025 에 개정 블록 2건 추가.

### 2. 복음서 4권 '~의 복음서' 접미사 생략

- 마태오/마르코/루가/요한의 복음서를 `NT_MOBILE_NAME` 맵에 추가(`마태오`·`마르코`·`루가`·`요한`).
- 기존 NT 축약 인프라를 그대로 재사용 → **성서 목록 모바일(touch)** 에서는 무조건 축약명, **읽기 헤더**에서는 공간 부족 시(`.compact`)만 축약명으로 swap. 사도행전은 변경 없음.
