## 요약

버전을 2.2.3에서 2.2.4로 올린다(`scripts/release.py`의 `patch`와 같은 고침). 2.2.3 뒤에 화면 레이아웃을 앱 화면의 크기로 정한 것(#631, 결정은 #630)과, 전례독서 검색에서 사계재를 지향별 줄만 보이게 한 것(#632, 데이터 #91, 포인터 #635)이 들어간다. ADR-051(#633) 뒤 처음으로 dev에서 main으로 앞당겨 운영에 내는 판이다.

아래 「릴리스 노트 초안」은 머지한 뒤 GitHub Release에 그대로 쓴다. 「변경 사항」은 `python3 scripts/changelog.py 2.2.3 HEAD`의 출력이고, 끝의 비교 링크만 2.2.4 태그를 가리키게 고쳤다.

## 확정 · 근거

- **버전**(사용자 지시 2026-11-22): 2.2.4다. 운영 반영은 ADR-051 §3의 순서를 따른다. dev 배포, 운영 반영 PR, main 앞당기기, 태그와 GitHub Release, 운영 배포는 하나씩 사용자에게 묻는다.
- **노트의 짜임**(구현하며 정함, `docs/writing.md` 「릴리스 노트」).
  - 「기능 개선」: 사계재의 줄(#632)과 iPad와 컴퓨터 창의 화면 배치(#631). 둘 다 있던 기능을 바꾼 것이다. 2.2.1 노트가 「사계재를 날마다 한 줄로 보여 줍니다」라고 알렸으므로, 바뀐 것을 노트에 다시 적는다.
  - 「버그 수정」: 2.2.3에도 있던 문제다. 컴퓨터에서 브라우저를 확대해 창의 폭이 경계에 걸리면 아래 탭 바와 위쪽 메뉴의 검색창이 함께 보이던 것(#631).
  - 「새 기능」은 없다.
- **노트에 넣지 않은 것.** #631의 조건을 한 곳에 모은 일과 북마크 선택 모드의 조건, #633의 브랜치 운영, #629와 #630의 문서는 사용자가 겪지 않는다. 큰 화면의 iPad에서 손가락으로 누르기에 작은 단추 넷(ADR-050 「후속」)은 고치지 않은 문제라 넣지 않는다.
- **실제 iPad.** #631은 iPad 크기의 Chromium으로만 확인했다(ADR-050 「구현하며 확인할 것」). dev.anglican.kr에서 iPad를 가로와 세로로 들어 위쪽 메뉴와 옆 패널, 북마크 줄 밀기, 긴 책 이름을 보아 주기를 사용자에게 부탁한다.
- **릴리스마다 하는 정리**(CLAUDE.md 「지식 베이스 루프」 3번).
  - 2.2.3(2026-11-21) 뒤의 원장은 #629, #630, #631, #633, #632의 다섯이다(#634와 #635는 자동 포인터 PR이라 원장이 없다). 새 ADR은 050과 051이고, 둘 다 `docs/architecture.md` 부록 A에 있다. ADR-044 §1, §3과 ADR-037 §5가 고쳐졌다.
  - ADR-051의 상태를 「구현 중」에서 「구현 완료」로 고쳤다. 상태에 적힌, 머지한 뒤 적용할 일 넷이 모두 끝났다. dev 브랜치와 그 보호, 기본 브랜치 dev, 데이터 저장소의 동기화 요청(common-bible-data#92), 서버 저장소의 배포 확인(common-bible-server#5)이다.
  - `docs/index.md`와 실제 파일, 링크, 번호 대장은 문서 검사가 맞는지 본다(통과). 새 설계 문서 `design/responsive-composition.md`(#631)는 초안이라 그대로 둔다. 끝나서 `archive/`로 옮길 설계 문서는 없다. 200줄을 넘긴 문서(DESIGN.md, ADR-044, `docs/design/lectionary-search.md`)는 전부터 넘었다.

## 릴리스 노트 초안

### 기능 개선

- 전례독서 검색에서 사계재는 ‘성직자의 성소를 위한 동계재’처럼 지향별 이름으로만 나옵니다. 지금까지는 같은 날이 ‘동계재 수요일’ 같은 계절 이름으로 한 번 더 나왔습니다. ‘춘계재’로 찾으면 그 계절의 네 지향이, ‘사계재’로 찾으면 네 계절의 지향이 모두 나옵니다.
- iPad에서 앱을 화면 가득 쓰면, 가로로 들든 세로로 들든 화면 위쪽 메뉴와 옆 창을 씁니다. 책 이름과 장 제목도 들어가는 만큼 길게 보입니다. 지금까지는 휴대폰처럼 화면 아래 탭 바였습니다. 휴대폰은 어느 방향이든 지금처럼 화면 아래 탭 바입니다.
- 컴퓨터에서는 창을 조금 좁혀도 화면 위쪽 메뉴가 그대로 남고, 창의 높이가 낮으면 휴대폰처럼 화면 아래 탭 바로 바뀝니다.

### 버그 수정

- 컴퓨터에서 브라우저 화면을 확대하거나 줄일 때, 창의 폭에 따라 화면 아래 탭 바와 위쪽 메뉴의 검색창이 함께 보이던 문제를 고쳤습니다.
