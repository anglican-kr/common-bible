> **Overview**
> ADR-034 **PR5a** moves SPA routing out of `views-routing.js` into new **`js/app/routing.js`** (~510 lines), with **no intended behavior change**.
> 
> **`routing.js`** now owns `parsePath`, `navigate`, `route()`, page meta/analytics, reading-position scroll tracking (`startScrollTracking`, `_routeSeq`), and global link-click / `popstate` listeners. It **ESM-imports** core view entry points from `views-routing.js` (`renderBookList`, chapter/prologue renderers, `divisionOrder`, `DIVISION_LABELS`, etc.) and **`data-fetch.js`** for loads. Search, bookmark, settings, and citations still go through **`window.*`** because those modules call back into routing.
> 
> **`views-routing.js`** drops the routing block (~480 lines → ~1,350 lines) and **exports** the renderers `routing.js` needs; routing symbols (`parsePath`, `route`, `navigate`, `routeSeq`) are removed from its facade.
> 
> **Wiring/docs:** `index.html` adds a module script for `routing.js` (after `views-routing.js`); **`sw.js`** precaches the new file. **ADR-034**, **CLAUDE.md**, and **`docs/architecture.md`** record PR5a complete; **PR5b** (registry + `closeAllOverlays`) remains.
