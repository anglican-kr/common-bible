# style: 탭 바↔검색 간격 8px 통일 + 인디케이터 바 높이로 확대

## 요약

모바일 하단 탭 바(ADR-030)의 두 가지 레이아웃 문제를 정리했습니다.

### 1. 탭 바와 검색 버튼 사이 갭 축소
- 짧은 4탭 pill 과 우측 검색 원형 사이의 빈 가운데가 너무 넓었음.
- `#tab-bar` 를 `flex:1` 로 늘려 검색 원형 바로 앞까지 채우고, `#tab-dock` 에 `gap: --space-2`(8px)만 남김.
- 이 **8px** 는 오디오 바와 탭 dock 사이 **수직 간격(72−64=8px)과 정확히 동일** — 가로·세로 여백을 같은 수준으로 통일.
- 아이콘 분배는 `.tab-item { flex:1 }`(균등 컬럼)이 담당. 넓은 화면에서 컬럼이 `max-width` 상한에 닿으면 `justify-content: space-between` 이 펼침(좁은 폰에선 무효).

### 2. 활성 인디케이터를 탭 바 높이까지 확대
- 기존 `44px` 고정 인디케이터 안에서 아이콘이 비좁게 느껴졌음.
- `#tab-bar` 상하 패딩을 0 으로(높이 60px 명시), `.tab-icon-wrap` 을 `height:100% + aspect-ratio:1`(+`max-width:100%` 로 좁은 화면 이웃 침범 방지)로 바꿔 인디케이터가 **바 안쪽 높이를 그대로 채우는 정원**이 되게 함.
- 아이콘은 `1.9rem → 1.7rem`(검색 아이콘도 동일)으로 약간 줄여 커진 인디케이터 안에서 여백 확보.

## 모핑·축소 호환
검색 모핑(`.searching`)·스크롤 축소(`.collapsed`) 상태는 `#tab-bar { flex:0 0 auto; width:60px }` 등으로 base 규칙을 그대로 오버라이드하므로 영향 없음.
