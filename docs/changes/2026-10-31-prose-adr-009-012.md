## 먼저 보실 곳

뜻이 달라질 수 있는 고침이다. 숫자, 날짜, 인용, 코드 표기는 바꾸지 않았다(아래 「검증」의 사실 토큰 비교).

- ADR-009 「맥락」: ADR-001의 결론을 큰따옴표로 옮긴 「"SEO 불리 — PWA이므로 수용 가능"」을 「SEO에 불리하지만 PWA이므로 받아들일 수 있다고」로 풀었다. ADR-001에 이 글이 그대로 있지 않아 인용 표시를 뺐다.
- ADR-009: 「navigation fallback」을 「탐색 요청 폴백」으로, 「sitemap」을 「사이트맵」으로(파일 이름 `sitemap.xml`과 「sitemap」 절을 가리키는 인용은 그대로), Google이 신뢰도를 「배운다」를 「판단한다」로, 「prerender나 SSG」를 「사전 렌더링이나 정적 사이트 생성(SSG)」으로 바꿨다.
- ADR-010 「결정」: 「URL path에 spec 문자열로 인코딩한다」를 「URL 경로에 문자열 표기로 인코딩한다」로, 「spec」을 대부분 「절 범위 표기」로 풀었다. 「다중 행」, 「단일 행」은 「여러 줄」, 「한 줄」로 썼다.
- ADR-010 절 선택 막대: 「탭 dock 미러」, 「floating glass」, 「pill」, 「글래스 레시피」를 「탭 독을 따른다」, 「떠 있는 글래스」, 「알약 버튼」, 「글래스 효과」로 바꿨다. 「pill 래퍼와 노트 버튼만 따로 있다」는 「…만 새로 더했다」로 썼다. 기존 ID를 지키고 두 요소만 새로 만든 뜻으로 읽었다.
- ADR-010 「하단 chrome」은 「하단 UI」로, 제스처끼리의 「경합」은 「충돌」로 썼다(「용어」 표의 「경쟁 상태」는 비동기 코드의 뜻이다).
- ADR-010 스와이프: 「full-swipe」를 「끝까지 밀기(full-swipe)」로, 「플릭은 커밋으로 승격되지 않는다」를 「플릭으로는 끝까지 밀어 실행하지 않는다」로, 「트위치」를 「손이 잠깐 튄 것」으로, 「재그랩 베이스 오프셋」을 「다시 잡을 때의 기준 오프셋」으로 풀었다.
- ADR-010 「폴더 + 내용물 cascade」를 「폴더를 삭제하면 안의 내용물도 함께 삭제된다」로, 「그룹만 풀고 싶으면」을 「폴더만 없애고 싶으면」으로 바꿨다.
- ADR-010 행 높이: 「노트, 캘린더 같은 후속 목록, 혼합 항목」을 「노트, 캘린더처럼 나중에 만들 목록과, 여러 종류가 섞인 항목」으로 풀었다.
- 세 파일의 「검토한 대안」에서 「채택 안 함 2026-05-07 · 이유: … · 재검토: …」를 ADR 001-008(#459)처럼 「채택 안 함(2026-05-07). 이유: …. 재검토: …」로 맞췄다. 날짜 뒤 괄호의 설명은 「(2026-10-22, 사용자 결정)」처럼 날짜와 함께 넣었다. 「보류」 줄은 가운뎃점만 마침표로 바꿨다.

## 결정 대기

- ADR-010 「B. 스와이프-투-리빌만」(제목): 후보는 「스와이프로 드러내기」, 「밀어서 드러내기」, 그대로 두기다. 권장안은 「스와이프로 드러내기」다.
- ADR-010 「squircle」(제목 1개), 「tabbar scrim」(본문): 후보는 「스퀴클」, 「둥근 사각형」, 그대로 두기(scrim은 「배경 가림막」)다. 권장안은 그대로 두기다. scrim은 코드 이름(`#bookmark-scrim`)과 이어지고, squircle은 DESIGN.md와 ADR 029, 030도 같은 말을 쓴다.

## 요약

문장 교정 진행 목록 3절(ADR)의 ADR 009, 010, 012를 고쳤다(한글 줄 422줄). ADR 011과 015는 열린 PR #460이 바꾸고 있어 건너뛰었다.

- 기계 검사 항목 전체: 356건에서 55건으로 줄었다. `particle`, `tilde`, `term`은 고친 뒤 0건이다(처음 ADR-010에 `term` 7건). 남은 것은 `english?`(History API, Googlebot, Google Search Console 같은 이름, 역따옴표로 묶은 코드), `term?`(화면을 「이동」하는 뜻), `particle?` 1건(「`// @ts-nocheck` 한 줄」의 관형사)이다.
- 기계 검사 밖에서 고친 곳은 약 170곳이다. 화살표(→), 줄표, 「=」, 「+」로 이은 토막 문장을 조사와 서술어로 풀었고, 「닿다」, 「걸다」, 「얹다」, 「돌린다」, 「쏟아졌다」, 「들고」, 「안고」 같은 비유 동사와 「렌더링된다」, 「하이라이트」, 「디바이스 간」 같은 음차어를 바꿨다.
- 서브에이전트의 고침 가운데 9곳을 되돌리거나 다시 고쳤다. 실제 화면 제목 표기인 「창세기 1장 — 공동번역성서」를 쌍점으로 바꾼 곳, 역따옴표 안의 코드 4곳(`--bg 50%`, `[아이콘 글래스 pill] + [취소 글래스 원형]`, `bookmark-core.js migrateStoredBookmarks`, `storage.js rewriteBookmarks`)과 `fixed`를 `position: fixed`로 바꾼 곳, 「」 인용 「재정렬 가능 + 현재 직접 정렬 모드」, ADR-012에 상수 이름을 더한 곳, 「신뢰도를 정한다」, 「후속 목록, 혼합 항목」이다.
- 제목 21개를 고쳤다. ADR-009는 3개(「+」, 「/」, 영어 「sitemap」), ADR-010은 18개(줄표와 「=」를 쌍점이나 조사로, 「query string」, 「path segment」, 「hash fragment」를 「쿼리 문자열」, 「경로 조각」, 「해시 조각」으로, 「6-dot」을 「6점」으로, 「리스너를 row에 걸기」를 「리스너를 행에 등록하기」로, 「picker」를 「선택기」로, 「pill」을 「알약 버튼」으로)다. 이 제목들로 오는 링크 앵커와 제목 인용은 저장소에 없었다. ADR-012 제목의 「JSDoc + `tsc --noEmit`」은 두 도구를 함께 쓴다는 코드 표기로 보고 그대로 두었다.
