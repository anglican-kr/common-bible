# fix: 절 복사 시 인용 칩·주석 마커 제외

## 문제

인용·주석(ADR-022) 기능 도입 후, 절을 복사하면 인용 구절 표시(`<cite>` → `.cite-chip`)와 `<note></note>[^id]` 입력으로 나타나는 주석 마커(※)가 본문과 함께 복사되었습니다.

## 원인

복사 직렬화기 `serializeVerseRange`(`js/app/bookmark.js`, VERSE_SERIALIZE 블록)가 클론한 range 에서 `.verse-num` 과 줄바꿈 마커만 정리하고 `textContent` 를 반환해, `.cite-chip` 칩 텍스트와 `.note-anchor--variant`(※) 마커가 그대로 포함되었습니다. 이 직렬화기는 시스템 복사(Cmd/Ctrl+C 드래그 선택)와 절 선택바 `복사` 버튼 두 경로가 공유합니다.

## 변경

- `serializeVerseRange` 에서 `.cite-chip` 과 `.note-anchor--variant` 를 제거 — 둘 다 읽기 보조 UI 이지 성서 본문이 아님.
- 어절을 감싸는 텍스트 앵커 주석(`.note-anchor`, 비변형)은 **실제 본문 단어**를 감싸므로 그 텍스트는 그대로 유지.
- 두 복사 경로가 같은 직렬화기를 쓰므로 한 곳 수정으로 양쪽 모두 해결.

## 테스트

- 유닛 536 케이스 전부 통과 (`node --test tests/unit/*.test.js`).
- DOM-heavy 직렬화는 e2e 책임 — `tests/e2e/test_copy.py::test_copy_excludes_citation_chip_and_note_marker` 회귀 추가. 합성 마커를 v16/v17 에 주입해 데이터 의존 없이 칩·※ 제외와 본문(텍스트 앵커 단어 포함) 보존을 검증.
- ADR-022 개정 노트 + CLAUDE.md 현재 상태 갱신.
