# style: 북마크 헤더 액션을 iOS 26 스타일로 재구성 '⋯' 팝업 메뉴로 통합 + 목록 행 여백 확대

## 배경

북마크 페이지 재구성 요청. Apple Music 앱처럼 헤더의 어포던스를 단일 "⋯" 버튼으로 모으고, 목록 항목을 더 여유있게 배치한다.

## 변경 사항

### 1. 헤더 액션 → "⋯" 단일 팝업 메뉴 (Apple Music 패턴)
- 별도 **"+"(새 폴더) 버튼 제거**. 모든 전역 관리 액션을 **"⋯"(더 보기) 한 개**의 팝업 메뉴로 통합.
- 메뉴 항목 3종 (위→아래): **새 폴더 · 내보내기 · 가져오기**, 각 행에 **선행 라벨 + 후행 SF 스타일 글리프**(`folder.badge.plus` / `square.and.arrow.up` / `square.and.arrow.down`).

### 2. 팝업 디자인 (Apple HIG + iOS 26)
- **큰 곡률** — `--radius-xl`(16px) + `corner-shape: superellipse(2)`(squircle, 미지원 시 둥근 모서리 폴백).
- full-bleed 행 + 행 사이 hairline(iOS 그룹 메뉴 룩), `overflow:hidden`으로 하이라이트를 곡률에 클립.
- 리퀴드 글라스 sheen/inset 질감(ADR-030 후속⁵ 공유) + `--shadow-4` elevation, 진입 스케일 애니메이션.
- 각 행 `min-height: --touch-target`(**44px**, WCAG/HIG 터치타깃).
- `prefers-reduced-transparency` / `prefers-reduced-motion` 폴백.

### 3. 북마크 목록 행 여백 확대
- 데스크탑: 패딩 `--space-3/--space-4`, `min-height 4rem`, gap 상향.
- 모바일: 콘텐츠 `min-height 3.5rem`, 패딩 상향(≥44px 유지).
- 라벨 `--font-sm→--font-md`, 참조 `--font-2xs→--font-xs`, 타입/토글 아이콘 1.4→1.6rem.

> **Overview**
> 북마크 탭·목록 UX를 Apple Music/iOS 26 패턴에 맞춰 크게 확장한다. 헤더 **"+"를 없애고 "⋯" 팝업 하나**에 새 폴더·보내기·가져오기와 **정렬 5종**(`menuitemradio`)을 넣고, squircle·글래스·full-bleed 행·공유 아이콘 열로 스타일을 맞춘다. 목록은 **여백·타이포를 키우고** 북마크 뷰는 **가로 패딩을 빼 full-bleed 스와이프**가 화면 끝까지 닿게 한다.
> 
> **표시 전용 정렬**(`sortBookmarkNodes`)과 기기별 `localStorage`(정렬·최근 본 시각), 북마크/폴더 **`updatedAt`/`createdAt`**(수정 날짜 정렬·Drive 동기화용 `_contentKey` 확장)을 추가한다. **`window.confirm` 대신 `#bm-confirm-modal`**로 삭제·헤더 토글을 통일하고, 모바일 읽기 헤더 북마크는 **미저장 시 "+" 배지·저장 시 채워진 아이콘 + 삭제 확인 토글**로 바꾼다.
>
