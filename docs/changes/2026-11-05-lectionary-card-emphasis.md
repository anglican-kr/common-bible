## 요약

dev에서 실제 아이폰으로 본 독서 카드(#478)를 사용자 의견대로 다듬는다(ADR-038 §3 「독서 카드」).

- 두 카드에서 다른 성구를 더 진한 색과 굵기 500으로 보인다. 색 차이만으로는 차이가 약했다.
- 카드 이름 아래에 가로선을 두어 성구와 나눈다.
- 고른 카드의 테두리를 `--accent` 2px에서 `--accent`의 60%, 1px로 바꾼다. 제목 글자와 색이 같아 보였다.
- 웹 글꼴 목록에 Noto Sans KR 500을 더한다.

## 확정 · 근거

- **굵기 500과 테두리 60%는 사용자 결정이다**(2026-11-05). 지금 모양, 굵기 600, 굵기 500, 같은 성구를 더 옅게 한 안을 캔버스에 나란히 그려 골랐다. 테두리는 사용자가 50%쯤을 말했는데 라이트에서 대비가 2.72:1과 2.56:1로 3:1(WCAG 1.4.11)에 못 미쳐, 60%를 함께 그려 고르게 했다. 버린 안은 ADR-038 「검토한 대안 — 다른 성구의 표시」, 「고른 카드의 테두리」에 있다.
- **글꼴 목록에 500을 더한 까닭.** 앱이 받던 Noto Sans KR은 400과 700뿐이라, 웹 글꼴을 쓰는 기기(안드로이드, 윈도우)에서 500은 400으로 보여 굵기 차이가 사라진다. 아이폰과 Mac은 시스템 글꼴이라 영향이 없다.
- **함께 달라지는 곳이 있다.** 이미 `font-weight: 500`을 쓰던 규칙 다섯(`.settings-drive-info-email`, `#drive-disconnect-file-question`, `.settings-action-btn`, `.cache-clear-btn`, 정렬 메뉴의 고른 항목)이 웹 글꼴을 쓰는 기기에서 400 대신 지정한 500으로 보인다. 원래 뜻대로 보이는 것이라 고치지 않았다.
- **글꼴 전략은 그대로다**(pitfalls §8). 같은 링크에 굵기만 더했으므로 `preload`와 `display=swap` 방식이 같다. 글꼴 CSS의 주소가 바뀌지만 이 CSS는 릴리스마다 비우는 `SHELL_CACHE`에 들어가므로 새 위험은 없다. 500 글꼴 파일은 그 굵기의 글자가 나올 때 받으므로, 처음 받는 동안은 카드의 다른 성구가 잠깐 다른 글꼴로 보일 수 있다.
- **가로선은 모든 카드에 넣었다.** 사용자는 「연속 독서」, 「복음 주제」를 말했지만, 「독서 1」과 「사순 2주일」도 같은 부품이라 날마다 모양이 달라지지 않게 함께 넣었다.
- **일부러 바꾸지 않은 것.** 접은 알약과 번호의 모양, 「독서 · 본기도」 단추는 그대로다.

## 검증

- 유닛 `node --test tests/unit/*.test.js`: 1,499건 가운데 1,498건 통과, 건너뜀 1건. 문서 검사 `docs-*`도 이 안에서 통과했다.
- 타입 검사: 원래 폴더의 `tsc`로 `tsconfig.json`과 `tsconfig.worker.json`을 검사했다. 오류 없음. CSP 해시 검사(`scripts/csp_hashes.py`)도 통과했다.
- e2e `tests/e2e/`: 430건 통과(작업 폴더 서버 8091, 사본). axe 접근성 검사와 키보드 시험도 이 안에서 통과했다. 새 시험 하나는 굵기 500과 400, 테두리 1px과 60%, 가로선, 글꼴 목록을 보고, 좁은 폭 시험에 한쪽 이름이 두 줄일 때 가로선 높이가 같은지를 더했다.
- 화면 확인: Chromium에서 폭 390px의 라이트와 다크, 폭 320px을 찍어 보았다. 웹 글꼴 400, 500, 700이 실제로 받아지는 것도 확인했다. 실제 아이폰과 Safari에서는 보지 않았다.
- 대비: 테두리는 카드 쪽과 바깥쪽이 라이트 3.49:1과 3.29:1, 다크 3.68:1과 3.98:1이다.
