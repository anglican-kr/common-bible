## 요약

전례독서 화면 본문 맨 위의 차례와 여백을 바꿨다(사용자 요청 2026-11-03, 아이폰 스크린샷).

- 전례색과 해(「● 녹색 짝수해」)의 줄이 회색 설명 줄(옮겨 지킨다는 문장, 기리는 성인과 기념일) 아래에 있었다. 이 줄을 제목 바로 아래로 옮겼다.
- 제목 위 여백을 16px에서 다른 화면과 같은 32px(`#app` 기본값)로 늘렸다. 제목이 머리에 붙어 보였다.

## 확정 · 근거

- **차례는 제목, 전례색과 해, 옮겨 지킨다는 문장, 기리는 성인과 기념일이다.** 사용자는 색과 해를 「제목 바로 아래로」라고 했다. 옮겨 지킨다는 문장(「12월 6일에서 옮겨 지킵니다」)은 #463에서 제목 바로 아래에 두었다. 요청대로 색과 해의 줄을 제목 바로 다음에 두고, 이 문장은 그 아래 회색 줄들의 맨 앞에 두었다. 회색 작은 글씨의 줄이 한데 모이고, 이 문장이 기리는 성인 줄보다 먼저인 것은 그대로다.
- **위 여백.** `#app:has(.lectionary)` 규칙이 위 여백을 16px로 줄이고 있었다. 전례독서 화면을 처음 만들 때(#346) 본문 맨 위에 날짜 이동 줄이 있던 때의 값이다. #463에서 날짜 이동 줄을 머리로 옮긴 뒤로 본문 맨 위가 제목이 되었다. 이 규칙을 지워 기본값 32px를 쓴다. 사용자가 말한 「최소 1줄」은 기본 글자 크기에서 본문 한 줄(16px × 1.8, 약 29px)이고, 32px는 그보다 크다.
- **일부러 바꾸지 않은 것.** 여백 단위(`--space-*`)는 글자 크기 설정과 상관없는 px다(DESIGN.md). 그래서 글자 크기를 크게 고르면 32px가 본문 한 줄보다 작아진다. 다른 화면과 같게 두었다. 캘린더 화면도 위 여백을 16px로 줄이지만(`#app:has(.calendar)`), 본문 맨 위가 날짜 이동 줄이고 요청 범위 밖이라 그대로 두었다.

## 검증

- 휴대폰 폭(390px) 화면을 찍어 확인했다. 11.4(제목, 색과 해, 기념일), 12.7(옮겨 지킨다는 문장과 성인 줄이 함께 있는 날), 2.14(「적색 또는 백색」). 세 날 모두 머리 아래 선과 제목 사이가 16px에서 32px로 바뀌었다.
- 유닛 `node --test tests/unit/*.test.js`: 1472개 가운데 1471개 통과, 1개 건너뜀(실패 0). 타입 검사 통과(작업 폴더에 `node_modules`가 없어 원래 폴더의 `tsc`로 `npm run typecheck`와 같은 두 설정을 검사했다).
- e2e 전체(`pytest tests/e2e/`, 작업 폴더 서버 8091): 420개 모두 통과(11분 44초).
- e2e 고침(`test_lectionary_view.py`): ③ 12.7의 차례 검사를 머리 전체의 차례로 바꿨다. ⑧ 11.6 레오나드 시험에 제목 위 여백이 32px인지 보는 줄을 더했다.
