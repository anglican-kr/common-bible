## 요약

전례독서 화면 본문 맨 위의 차례와 여백을 바꿨다(사용자 요청 2026-11-03, 아이폰 스크린샷).

- 전례색과 해(「● 녹색 짝수해」)의 줄이 회색 설명 줄(옮겨 지킨다는 문장, 기리는 성인과 기념일) 아래에 있었다. 이 줄을 제목 바로 아래로 옮겼다.
- 제목 위 여백을 16px에서 제목 한 줄의 높이(기본 글자 크기에서 33.6px)로 늘렸다. 제목이 헤더(앱 맨 위 막대)에 붙어 보였다. 글자 크기 설정을 따라 여백도 늘어난다.

## 확정 · 근거

- **차례는 제목, 전례색과 해, 옮겨 지킨다는 문장, 기리는 성인과 기념일이다.** 사용자는 색과 해를 「제목 바로 아래로」라고 했다. 옮겨 지킨다는 문장(「12월 6일에서 옮겨 지킵니다」)은 #463에서 제목 바로 아래에 두었다. 요청대로 색과 해의 줄을 제목 바로 다음에 두고, 이 문장은 그 아래 회색 줄들의 맨 앞에 두었다. 회색 작은 글씨의 줄이 한데 모이고, 이 문장이 기리는 성인 줄보다 먼저인 것은 그대로다.
- **위 여백.** `#app:has(.lectionary)` 규칙이 위 여백을 16px로 줄이고 있었다. 전례독서 화면을 처음 만들 때(#346) 본문 맨 위에 날짜 이동 줄이 있던 때의 값이다. #463에서 날짜 이동 줄을 헤더로 옮긴 뒤로 본문 맨 위가 제목이 되었다. 처음에는 이 규칙을 지워 다른 화면과 같은 기본값 32px를 썼다. 사용자가 검토하고 「최소한 제목 행 높이만큼」으로 정했다(2026-11-04). 그래서 이 규칙의 값을 제목의 글자 크기와 줄 간격을 곱한 값(`calc(var(--font-xl) * var(--leading-snug))`)으로 바꿨다. 여백 단위(`--space-*`)는 글자 크기 설정과 상관없는 px라서(DESIGN.md), 32px로 두면 큰 글자에서 제목 한 줄보다 작아졌다. 이 값은 `rem`이라 글자 크기 설정을 따른다.
- **용어.** 처음에는 앱 맨 위 막대(`#app-header`)와 본문 맨 위의 제목 묶음(`.lect-head`)을 둘 다 「머리」로 적었다. 영어 header를 옮긴 말이고, 한 낱말이 두 곳을 가리켜 헷갈렸다. 사용자가 막대는 「헤더」, 제목 묶음은 「제목 영역」으로 정했다(2026-11-04). 이 PR은 새로 쓴 줄만 고쳤다. 이미 머지된 문서와 코드 주석에 남은 「머리」(백 곳 남짓)는 다음 PR에서 고치고 `writing.md` 「용어」에 규칙을 남긴다(사용자 결정).
- **일부러 바꾸지 않은 것.** 캘린더 화면도 위 여백을 16px로 줄이지만(`#app:has(.calendar)`), 본문 맨 위가 날짜 이동 줄이고 요청 범위 밖이라 그대로 두었다.

## 검증

- 휴대폰 폭(390px) 화면을 찍어 확인했다. 11.4(제목, 색과 해, 기념일), 12.7(옮겨 지킨다는 문장과 성인 줄이 함께 있는 날), 2.14(「적색 또는 백색」). 세 날 모두 헤더 아래 선과 제목 사이가 16px에서 늘었다(32px로 찍어 본 뒤 제목 한 줄 높이로 바꿨다). 글자 크기 16px, 20px, 24px에서 여백이 제목 한 줄 높이(33.6px, 42px, 50.4px)와 같다.
- 유닛 `node --test tests/unit/*.test.js`: 1472개 가운데 1471개 통과, 1개 건너뜀(실패 0). 타입 검사 통과(작업 폴더에 `node_modules`가 없어 원래 폴더의 `tsc`로 `npm run typecheck`와 같은 두 설정을 검사했다).
- e2e 전체(`pytest tests/e2e/`, 작업 폴더 서버 8091): 32px로 고친 코드에서 420개 모두 통과(11분 44초). 제목 한 줄 높이로 바꾼 뒤에는 전례독서, 교회력, 접근성, 탭 바의 시험 7개 파일(138개)을 다시 돌려 모두 통과했다(3분 47초). 바뀐 것이 전례독서 화면의 위 여백 값 하나라 전체는 다시 돌리지 않았다.
- e2e 고침(`test_lectionary_view.py`): ③ 12.7의 차례 검사를 제목 영역 전체의 차례로 바꿨다. ⑧ 11.6 레오나드 시험에 제목 위 여백이 제목 한 줄 높이 이상인지, 글자 크기 24px에서도 그런지 보는 줄을 더했다.
