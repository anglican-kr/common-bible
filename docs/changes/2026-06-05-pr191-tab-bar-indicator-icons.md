# style: 탭 바 활성 인디케이터 원형화 + 아이콘 크기 일치 + 모핑 홈 강조

## 개요

모바일 하단 탭 바(ADR-030)의 세 가지 시각 다듬기.

### 1. 활성 인디케이터 원형화
선택된 탭의 배경 인디케이터를 stadium(가로로 긴 알약, `3rem × 44px`)에서 **정원(`44px × 44px` + pill 반경)**으로 변경. 검색 원형 버튼·모핑 원과 형태 언어가 통일된다. — `css/style.css` `.tab-icon-wrap`

### 2. 아이콘 크기 일치 (설정 아이콘 기준)
톱니(설정) 아이콘 glyph 가 24 viewBox 의 ~22 를 채우는 반면 홈·북마크·노트·검색 glyph 는 ~15–17 만 채워 **작게 보이던 문제**를 해결.

각 아이콘의 `viewBox` 를 glyph 바운딩박스 중심으로 **동일 비율(22/24)** 로 좁히고, `stroke-width` 를 비례 보정해 **렌더 glyph 크기와 획 굵기 모두 설정 아이콘과 동일**하게 맞췄다. 설정 아이콘만 `0 0 24 24` · `stroke-width 1.8` 기준으로 유지. **원본 path 데이터는 그대로 재사용**(아트워크 변형 없음). — `index.html`

검증(렌더 1.9rem 기준): 네 아이콘 모두 glyph 지배 변 ≈ **1.74rem**, 획 ≈ **0.1425rem** 으로 설정 아이콘과 수렴.

### 3. 모핑 시 홈 강조
검색 모핑(`.searching`)·스크롤 축소(`.collapsed`)로 탭 바가 홈 원형 캡슐이 되면:
- 안쪽 활성 인디케이터(이중 원)를 제거(`background:none`)
- 홈 아이콘을 `--theme`(색상 스킴 추종 테마색)로 틴트

— `css/style.css`
