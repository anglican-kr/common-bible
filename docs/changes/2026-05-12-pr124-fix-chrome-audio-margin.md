# fix: Chrome iOS 오디오 바 아래 불필요한 여백 제거

## 요약

iOS Chrome에서 `#audio-bar` 아래에 ~34px 정도의 빈 여백이 생기던 문제를 수정.

## 원인

`#audio-bar`의 `padding-bottom`은 `max(0.75rem, env(safe-area-inset-bottom, 0px))`로 홈 인디케이터를 피하도록 설정돼 있다. Safari iOS는 하단 툴바 상태에 따라 `env(safe-area-inset-bottom)` 값을 동적으로 조정해서 문제가 없지만, **iOS Chrome은 하단 툴바가 홈 인디케이터 영역을 이미 덮고 있어도 이 값을 ~34px로 계속 보고한다.** 그 결과 오디오 바 아래에 사용되지 않는 여백이 생긴다.

## 변경

- `@media (display-mode: browser)`에서 `#audio-bar { padding-bottom: 0.75rem }` 로 고정.
  - 브라우저 모드(Safari + Chrome)에서는 브라우저 자체 하단 UI가 safe area를 처리하므로 inset을 더할 필요 없음.
  - PWA standalone 모드에서는 기존 `max(0.75rem, env(safe-area-inset-bottom, 0px))`를 그대로 유지 — 홈 인디케이터를 직접 피해야 함.
- `version.json` 1.4.9 → 1.4.10, `sw.js` SHELL_CACHE shell-65 → shell-66 (CSS 변경 반영용 shell-only 릴리스).

## 테스트 계획

- [ ] iOS Safari (툴바 펼침/접힘 둘 다): 기존과 동일하게 보이는지 확인
- [ ] iOS PWA (홈 화면 추가 후 실행): 오디오 바가 홈 인디케이터를 가리지 않는지 확인
- [ ] 데스크톱 Chrome/Safari: 회귀 없음 확인
