## 요약

버전을 1.6.4에서 2.0.0으로 올린다(`python3 scripts/release.py major`). 1.6.4(2026-06-11) 뒤에 캘린더와 전례독서가 새로 들어와 주 버전을 올린다(사용자 결정 2026-11-07). 이 PR을 머지한 뒤 태그와 GitHub Release를 만들고 dev와 운영에 배포한다(`docs/workflow.md` 「릴리스」). 운영 승격은 그 직전에 사용자에게 다시 묻는다.

아래 「릴리스 노트 초안」은 머지한 뒤 GitHub Release에 그대로 쓴다. 「변경 사항」은 `python3 scripts/changelog.py 1.6.4 main`의 출력이고, 끝의 비교 링크만 2.0.0 태그를 가리키게 고쳤다.

## 확정 · 근거

- **노트의 짜임**(사용자 결정 2026-11-08): 「새 기능」, 「기능 개선」, 「버그 수정」으로 나눈다. 이번 판에서 새로 만든 기능(캘린더, 전례독서, 교회력 계산, 새 설정 항목, 전례시편과 송가)의 문제를 고친 것과 사용자가 겪지 않는 변경은 넣지 않았다. 1.6.4에는 책이 73권이었고 전례시편과 송가가 없어(지금 75권) 새 기능으로 넣었다. 커밋 종류가 버그 수정인 구절 표기 검색(#514)은 읽는 표기를 넓힌 것이라 기능 개선에 넣었다(구현하며 정함).
- **노트 문장 교정**(사용자 교정 2026-11-08): 고친 문제는 언제 생기는지와 무엇이 문제였는지를 함께 쓴다. 북마크 합치기와 앱 버전이 다른 기기의 동기화 두 문장을 고쳤다. 「포커스」는 「키보드로 누른 단추에서 이어 움직일 수 있습니다」로 바꿨다(사용자 결정 2026-11-08). 노트 끝에는 비교 링크만 두고 커밋 목록은 이 본문에만 둔다(2026-11-08).
- **CLAUDE.md의 사실과 다른 문장**: 「데이터 수정과 릴리스」 4번은 `release.py`가 push, 태그, GitHub Release까지 한다고 적었지만, 스크립트는 `version.json`과 `sw-version.js`를 고쳐 커밋까지만 한다. 릴리스 PR로 머지하고 태그와 Release를 만든 뒤 배포하는 순서로 고쳤다.
- **CSP 점검 도구**: 선택자가 낡아 두 단계가 돌지 못했다(#509의 상단 바, #473의 전례독서 목록). 그 선택자를 고치고 캘린더 목록 화면 단계를 더했다(`tools/csp/csp_sweep.py`).
- **릴리스마다 하는 정리**(CLAUDE.md 「지식 베이스 루프」 3번): 200줄을 넘긴 현행 문서가 열다섯 개다(가장 긴 것은 `docs/design/liturgical-engine-review.md` 1,394줄, `docs/decisions/011-bookmark-sync.md` 1,016줄, `docs/topics/liturgical.md` 681줄). 나눌지는 사용자에게 묻고, 이 릴리스에서는 나누지 않는다.

## 릴리스 노트 초안

### 새 기능

#### 캘린더

아래 탭에 「캘린더」가 생겼습니다. 컴퓨터에서는 화면 위쪽의 캘린더 단추를 누릅니다.

- **월간 보기**는 날마다 전례색 점과 그날의 이름을 보여 줍니다.
- **목록 보기**는 평일까지 모든 날을 한 줄씩 보여 주고, 위아래로 끝없이 넘길 수 있습니다.
- 오른쪽 위 단추로 두 보기를 오갑니다. 「오늘」을 누르면 오늘로 돌아옵니다.
- 전례독서를 보고 돌아오면 보던 줄로 돌아옵니다.

#### 전례독서

캘린더에서 날짜를 누르면 **전례독서** 화면이 열립니다.

- 그날의 본기도, 제1독서, 성시, 제2독서, 복음을 한 화면에서 읽습니다.
- 성시와 송가는 대한성공회 기도서의 전례시편과 송가로 읽습니다. 선창과 응답을 나눠 기도서처럼 보여 줍니다.
- 고를 수 있는 전례일이 여럿인 날은 제목 아래 목록에서 고릅니다.
- 「또는」으로 나뉘는 독서는 카드 두 장으로 고릅니다. 연속 독서와 복음 주제 가운데 마지막으로 고른 것을 기억합니다.
- 그날 기리는 성인과 기념일, 교회의 축성일과 축복일, 다른 날로 옮겨 간 축일을 제목 아래에 알려 줍니다.

#### 설정

- 앱을 열 때 처음 볼 화면을 성서와 전례독서 가운데 고를 수 있습니다.
- 축일에 밀린 그날의 평일과 주일 독서를 전례독서 목록에 보일지 고를 수 있습니다.

### 기능 개선

- 설정 화면을 시작, 성서, 전례독서, 모양, 시스템의 다섯 부분으로 나누었습니다.
- 본문의 따옴표를 바른 모양으로 바꿨습니다.
- 검색할 때 따옴표를 무시합니다. 따옴표가 든 구절도 그대로 찾을 수 있습니다.
- 검색창에 「요한 3:16, 18-19」처럼 쉼표로 이은 절이나 「사무상 18:6-9, 19:1-7」처럼 장을 넘는 구간을 적어도 그 구절을 찾습니다.
- 여러 절을 한꺼번에 고르기 쉬워졌습니다. 컴퓨터에서는 Shift를 누른 채 누르고, 휴대폰에서는 길게 눌러 범위를 넓힙니다.
- 절 선택을 시작하는 길게 누르기를 조금 늘려(0.5초), 화면을 넘기다 절을 선택하는 실수를 줄였습니다.
- 고른 절의 배경색이 절 끝의 인용 표시까지 이어집니다.
- 북마크의 순서는 ≡ 손잡이를 끌 때만 바뀝니다. 목록을 넘기다 순서가 바뀌지 않습니다.
- 처음 방문했을 때는 설치 안내가 뜨지 않습니다.
- 스크린 리더와 키보드로 쓰기 편해졌습니다. 짧은 알림을 읽어 주고, 화면이 바뀐 뒤에도 키보드로 누른 단추에서 이어 움직일 수 있습니다. 검색 결과의 쪽을 넘기면 몇 쪽인지 알려 줍니다.
- 성서만 읽을 때는 캘린더와 전례독서의 코드를 받지 않아, 처음 열 때 더 빠릅니다.

### 버그 수정

#### 성서 읽기와 검색

- 짝이 맞지 않던 본문의 따옴표를 고쳤습니다.
- 절을 고를 때 번호가 같은 다른 절이 함께 골라지던 문제를 고쳤습니다. 반쪽 절은 「8ㄱ」처럼 적습니다.
- 공유 링크의 절 범위 때문에 앱이 멈추던 문제를 고쳤습니다.
- 절 선택 막대로 복사할 때와 본문을 끌어 골라 복사할 때 출처를 같은 모양으로 적습니다.
- 이어 읽기로 돌아가면 읽던 절이 화면 위쪽 막대 바로 아래에 옵니다. 들어갈 때마다 한두 절씩 뒤로 밀리던 문제도 고쳤습니다.
- 없는 장이나 없는 주소로 가면, 앞 화면이 남지 않고 무엇이 없는지와 갈 곳을 알려 줍니다.
- 주석 표지를 눌러 연 설명 창이 화면 위쪽 막대에 가리지 않습니다.
- 화면 낭독기가 절을 누를 때 다른 장에서 옮겨 실린 절과 추가 본문의 번호를 구별해 읽습니다.

#### 북마크와 동기화

- 동기화에 실패했는데 성공한 것처럼 보이던 문제를 고쳤습니다.
- 동기화하는 동안 고친 내용과 시계가 느린 기기에서 고친 내용이 덮어써지지 않습니다.
- 동기화하는 도중에 연결을 해제하면 그 동기화를 멈춥니다. 「파일도 삭제」는 구글 드라이브의 파일을 끝까지 지우고, 지우지 못하면 알려줍니다.
- 기기마다 앱 버전이 다를 때, 동기화하면서 한쪽이 모르는 설정을 지우던 문제를 고쳤습니다.
- 지운 북마크가 다른 기기에서 되살아나지 않게 했습니다.
- 한 기기에서 폴더를 지우는 사이 다른 기기에서 그 폴더에 넣은 북마크가 사라지던 문제를 고쳤습니다.
- 북마크를 가져올 때 형식이 맞지 않는 북마크는 가져오지 않습니다. 병합할 때 같은 폴더가 있으면 그 안의 새 북마크도 들어옵니다.
- 기기의 저장 공간이 가득 차 저장하지 못하면 알려 줍니다.
- 같은 장에 이미 북마크가 있을 때 새로 고른 절을 그 북마크에 합치면, 직접 지은 제목이 절 번호로 바뀌던 문제를 고쳤습니다.

#### 그 밖에

- 아이폰에서 탭 바의 선택 표시가 화면만큼 커지던 문제를 고쳤습니다.
- 아이폰 홈 화면 앱에서 화면 위쪽 막대가 본문 첫 줄을 가리던 문제를 고쳤습니다.
- 오프라인에서 이 기기에 받아 두지 않은 장의 오디오를 열면, 인터넷에 연결하면 들을 수 있다고 알려 줍니다.
- 업데이트 알림이 두 개 뜨던 문제를 고쳤습니다.
