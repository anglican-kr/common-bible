## 먼저 보실 곳

뜻이 달라질 수 있는 고침이다. 숫자, 날짜, 인용, 코드 표기는 바꾸지 않았다(아래 「검증」의 사실 토큰 비교). 줄 번호는 지금 파일의 줄이다.

- `docs/writing.md` 147행: 스낵바 사례에서 사용자의 물음 「여기 한국어 문장 어색하다?」 뒤에 서술어가 없어 「라고 물었다」를 더했다. 줄표 뒤의 세 평가는 새 문장으로 나눴고, 「사실이 없다」를 「사실이 빠졌다」로 썼다.
- `docs/writing.md` 178행: 「같은 표기 — PR 페이지에서 가운데가 취소선이 됐다」를 「같은 표기에서 PR 페이지의 가운데가 취소선이 됐다」로 바꿨다.
- `docs/writing.md` 190행: 「144군데(「글꼴」 제외 — 문서 · 주석 …)」를 「「글꼴」을 뺀 144군데(문서, 주석, …)」로 짰다.
- `tests/README.md` 19행: 「"tsc 통과 = 안전"이 아니다 —」를 「tsc를 통과했다고 안전한 것은 아니다.」로 풀었다.
- `tests/README.md` 26행: 「예외 둘 — A와 B」를 「예외는 둘이다. A와 B다」로 나누고, 픽스처 설명을 「교회력 엔진이 실제 연도에서 내야 할 값의 기준이고, 스키마는 …에 있다」로 풀었다. 「Node 자체 테스트 러너」는 뒤의 「자체 `vm` 하네스」와 구분하려고 「Node의 내장 테스트 러너」로 썼다.
- `tests/README.md` 38행: 「보호 기간 guard」를 「보호 기간 검사」로, 「프리로드 전 throw」를 「프리로드 전 호출은 예외를 던짐」으로, 계산 범위 밖 날짜가 「옮김 계산에 닿지 않는다」를 「옮김 계산을 거치지 않는다」로 바꿨다.
- `tests/README.md` 46행: 대안 세트의 「「또는」 = 독서 N · 조건부 = 조건 라벨 · 괄호 선택 구절 = 바탕에 합침 + 선택 절 판정」을 「「또는」은 독서 N, 조건부는 조건 라벨, 괄호 선택 구절은 바탕에 합치고 선택 절을 판정」으로 풀었다.
- `tests/README.md` 63행: 「한꺼번에 묶음 = 그 화면 모듈의 정적 import − 부팅 그래프」를 「한꺼번에 묶음은 그 화면 모듈의 정적 `import`에서 부팅 그래프를 뺀 것과 같다」로 풀었다.
- `tests/README.md` 116행과 같은 표의 여러 칸: 화살표(→)를 「…를 누르면 …」, 「…에서 …로」 같은 서술어로 풀었다(「링크를 누르면 이동하고 드로어가 닫힘」, 「책 목록에서 장을 불러옴」, 「칸에서 전례독서로, 다시 위 단계로 올라가기」).
- `tests/README.md` 152행: 「skip 1건으로 빠진다」를 「모듈 단위로 건너뛰어, 건너뛴 1건으로 센다」로, 「그전엔 하드 import라」를 「그전에는 이 패키지를 무조건 `import`해서」로 바꿨다.

## 요약

문장 교정 진행 목록 2절(루트 문서와 `docs/`의 나머지)에 남은 두 파일을 고쳤다. 이 묶음으로 2절이 끝난다.

| 파일 | 한글 줄 | 기계 검사(`particle`, `tilde`, `term`) 전 → 후 | 기계 검사 전체 전 → 후 |
| --- | --- | --- | --- |
| `docs/writing.md` | 197 | 0 → 0 | 91 → 48 |
| `tests/README.md` | 99 | 19 → 0 | 664 → 598 |

- 기계 검사 밖에서 고친 곳은 약 60곳이다. 실행을 「돌다」로 쓴 곳, 「걷다」, 「닿다」 같은 비유 동사, `throw`, `skip`, 「하드코딩」처럼 영어를 술어로 쓴 곳, 등호와 화살표와 「+」로 이은 문장, 역따옴표 없이 쓴 코드 이름(`span`, `prec`, `null`, `import`, `before`/`after`/`into`)이 그렇다. 「옛 판」은 「용어」 표대로 「옛 버전」으로 썼다.
- `docs/writing.md`는 규칙 문서라 「용어」 표의 왼쪽 칸, 사례에 인용한 잘못된 예, 날짜 사이의 가운뎃점을 그대로 두었다. 남은 판단 항목 48건이 그것이다.
- `tests/README.md`의 남은 판단 항목은 대부분 표 칸의 가운뎃점과 줄표다(「결정 대기」). `term?` 15건은 화면 이동, 드래그 이동, 모듈이 늦게 「도착」하는 뜻이라 그대로 두었다.
- 서브에이전트의 고침 가운데 7곳을 되돌리거나 다시 고쳤다. 「」 안의 「-하다 · -되다」를 둘로 나눈 2곳, 「독」, 「선택기」, 「탐색」, 「경계 닿음」(`test_boundary_touch_does_not_drag_in_next_verse`의 이름이라 그대로 둠), 「promise 캐시」를 `Promise`로 바꾼 곳이다.
- 제목 줄 7개를 고쳤다(`docs/writing.md` §37). `tests/README.md`의 「각 겹이 혼자만 잡는 것: 왜 셋 다 필요한가」, 「1. 유닛 테스트: `tests/unit/`」, 「2. 타입 검사: `tsc`」, 「3. E2E 테스트: `tests/e2e/`」, 「북마크(이 영역이 가장 촘촘하다: 11개 파일)」, 「읽기, 내비게이션, 검색, 본문」, 「오디오, 동기화, 설정, 셸」이다. 이 제목들로 오는 링크 앵커와 제목 인용은 저장소에 없었다. 다른 문서는 「`tests/README.md` §1」처럼 번호로 가리키고, 번호는 그대로다.

## 리뷰 반영

- **결정 대기 6건을 정했다**(사용자 결정 2026-10-31, 권장안대로).
  - `tests/README.md` 표 칸의 가운뎃점과 줄표는 그대로 둔다. 표가 파일별 테스트 목록이라 나열이 본래 할 일이다.
  - 「모듈 간 배선」은 「모듈 간 연결」(2곳), 「seek」는 「재생 위치 옮기기」, 「탭 dock」은 「탭 막대」, 「피커」는 「장 선택 창」, 「LWW」는 「마지막 쓰기 우선(LWW)」으로 썼다.
  - `docs/writing.md` 100행의 「아래 표」는 「「용어」 표」로 고쳤다. 비유 동사를 하나씩 더해 온 곳은 위의 「용어」 표이고(「걷다」, 「흡수한다」, 「도착」, 「켜다」 등), 바로 아래 「학술과 법률 문체 낱말」 표는 한자어만 담는다.
- **main을 합쳐 충돌을 풀었다.** #456이 `tests/README.md`의 세 줄(유닛 개수, `state-machine`과 `store-v2` 설명)을 바꿔 이 PR과 겹쳤다. 공통 조상과 비교해 이 PR은 표현만, #456은 개수와 설명만 바꾼 것을 확인하고 둘을 함께 살렸다.
- **스킬의 커밋 제목 예를 고쳤다.** 「…를 고침」을 「…수정」으로 바꿨다. PR 제목은 명사로 맺는다는 규칙(`docs/workflow.md` pitfalls §30, 2026-10-31)에 맞춘 것이다.
