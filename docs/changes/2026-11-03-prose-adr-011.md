## 먼저 보실 곳

뜻이 달라질 수 있는 고침이다. 숫자, 날짜, 인용, 코드 표기는 바꾸지 않았다(아래 「검증」의 사실 토큰 비교).

- 「무음」(로그인 방식과 토큰 갱신)을 「조용한」, 「조용히」로 바꿨다. 「결정」의 「Android(GIS 무음)」은 방식의 이름이라 「GIS 조용한 로그인」으로 풀었다.
- 「결정」: 「사용자가 켤 때만(Opt-in) 하고」를 「켤 때만 동작하고(옵트인)」로 썼다. 주어 없는 「하고」에 동사를 채웠다.
- 「맥락」: 「아키텍처 유지 필수 — 서버 인프라 추가 불가」를 「아키텍처를 유지하는 것이라, 서버 인프라를 추가할 수 없다」로 풀었다.
- 「cold start」(약 15곳)를 「용어」 표대로 「앱을 처음 열 때」, 「앱을 처음 여는 경로」로 바꿨다.
- Phase 2h 머리: 「ADR-구현 정합성이 깨졌다」를 「ADR과 구현이 어긋났다」로, 결정표의 「거부」를 「채택하지 않는다」로 썼다. 「근본 원인이 refresh token 부재」는 「refresh token이 없는 것」으로, 「회귀하면서」는 「돌아가면서」로 풀었다.
- Phase 2h: 「carry forward」를 「그대로 이어받아」로, 「DISABLED 상태를 IDLE로 끌어올림(사용자 의도 무시)」를 「DISABLED 상태가 IDLE로 바뀌어 사용자의 뜻을 어겼다」로, 「만성 401」을 「401이 반복되는」으로 바꿨다.
- Phase 2f 후속 정제: 「prompt=none을 즉시 발사 → 토스트 파괴」를 「prompt=none을 즉시 보내, 토스트가 사라지고」로 썼다.
- Phase 2i: 「재생성 폴백」을 「캐시를 다시 만든다(폴백)」로 썼다. 다시 만드는 것이 fileId 캐시라고 읽었다. 「too noisy on Safari private mode」는 「Safari 사생활 보호 모드에서 기록이 너무 많아진다」로 옮겼다.
- Phase 2j: 「가설 A 확정」을 「가설 A가 맞다」로, 「3건 drop → 3.3초 절감 / 10초 윈도우」를 「나머지 3건 모두 버려 10초 윈도우에서 3.3초를 줄인다」로, 「unit 78 → 479 케이스 중 sync 관련 46 케이스 0 fail」을 「전체 unit 케이스가 78개에서 479개로 늘었고, 그중 sync 관련 46 케이스는 실패가 0건이다」로 풀었다.
- 「옛 버전의 북마크 절 범위」: 「창 객체는 `bookmark.js`가 건다」를 「`bookmark.js`가 `window` 객체에 등록한다」로 썼다.

## 결정 대기

- 「silent」(약 30곳, 「silent 재발급」, 「silent-blocked」): 후보는 「조용한」으로 바꾸기, 코드 이름(`silent-blocked` 플래그)만 두고 설명 문장만 바꾸기, 그대로 두기다. 권장안은 코드 이름만 두고 설명 문장을 「조용한」으로 바꾸는 것이다. 이번에는 바꾸지 않았다.
- 「race」, 「fast path」, 「throttle」: 후보는 「경쟁 상태」(이미 「용어」 표에 있다), 「빠른 경로」, 「호출 제한」이다. 권장안은 이 셋으로 바꾸기다. 「race lost」는 테스트 이름(`tests/unit/state-machine.test.js` 25번)에도 있어 그 인용은 그대로 둔다.
- 「top-level IIFE」, 「canonical 이름 인계」: 후보는 「최상위 즉시 실행 함수」, 「정식 이름 넘겨받기」, 그대로 두기다. 권장안은 그대로 두기다.

## 요약

문장 교정 진행 목록 3절(ADR)의 ADR-011을 고쳤다(한글 줄 583줄). 600줄이 넘지 않아 나누지 않았다. 열린 PR #463은 이 파일을 바꾸지 않는다.

- 기계 검사 항목 전체: 337건에서 222건으로 줄었다. `particle`, `tilde`, `term`은 17건에서 0건이 됐다. 남은 것은 대부분 `english?`(코드 이름, 상태 이름, 서비스 이름)와 `dot?`, `dash?` 가운데 표와 「검토한 대안」 줄의 형식이다. 「이동」(화면 안내 토스트 문구)과 「도착」(PKCE 콜백이 주소로 오는 뜻)은 「용어」 표가 막은 뜻이 아니라 두었다.
- 기계 검사 밖에서 고친 곳은 약 170곳이다. 줄표와 가운뎃점으로 이은 토막 문장(약 55곳)과 화살표(→)로 이은 동작(약 45곳)을 조사와 서술어로 풀었다. 「파킹해」, 「정착」, 「끌어올림」, 「깔기만」, 「떨어뜨리는」, 「흡수」, 「stash」, 「캐시 클리어」 같은 비유 동사와 개발자끼리 쓰는 말을 바꿨고, 「16↓」를 「16 이하」로 썼다. 상태 이름(`OFFLINE → NET_RECOVERED`), 테스트 벡터, 화면 메뉴 경로의 화살표는 그대로 두었다.
- 검토 단계에서 4곳을 다시 고쳤다. 서브에이전트가 「16↓은」을 「16 이하은」으로 남긴 곳을 「이하는」으로, 남아 있던 「cold start」 2곳(Phase 2h 머리, 마이그레이션 호환성)을 풀었고, 「78 → 479」 문장을 다듬었다. 「cold start 1회」를 「한 번」으로 바꿔 사실 토큰 「1회」가 줄어든 3곳과, 「3건 drop」을 「3건은」으로 써 토큰 「3건」이 줄어든 곳은 숫자 표기를 되살렸다.
- Phase 2d-2h 구현 기록(약 380-830줄)은 상태 이름과 코드 이름이 촘촘해 음슴체 메모(「…발생함」, 「…누락」)를 상당수 그대로 두었다. 다음 묶음에서 더 볼 수 있다.
- 제목 1개를 고쳤다. 「### 회귀 방어 — 유닛 테스트 (단계 1·2 시점)」의 가운뎃점을 「단계 1과 2」로 바꿨다. 이 제목으로 오는 링크 앵커와 제목 인용은 저장소에 없었다. 줄표로 이은 「## Phase 2a — …」 같은 제목은 다른 문서가 이 표기로 인용할 수 있어 그대로 두었다.
