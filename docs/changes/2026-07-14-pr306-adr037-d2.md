# docs: ADR-037 §1·§2·§5 개정 — D2 전례독서 구현 반영

데이터 저장소에서 D2(전례독서 데이터) 구현이 끝나(anglican-kr/common-bible-data#12), ADR-037 을 실제 구현에 맞춘다. 문서 전용.

## 원안을 고친 것

- **송가는 기도서 번역이 정본** — 원안은 `bookId:"lps"` + 전례시편 부록 장(151+) + `scripture_ref` 병기였다. 실제로 데이터를 넣어 보니 창조송가·Te Deum 등은 감사성찬례 시편이 아니라 **성무일과 송가**라 전례시편에 얹을 자리가 아니었고, 기도서에 고유 번역이 있어 전례에서 실제로 낭송하는 본문이 그것이었다. 별도 책 `cant`(13편, ADR-039 v2)로 옮기고 시편 슬롯도 그 번역을 렌더한다. 기도서에 없는 송가만 공동번역 성구로 폴백.
- **트랙은 연중 주일에만** — 제목 말미의 `1`·`2` 를 무조건 `reading_track` 으로 읽으면 안 된다. RCL 트랙은 연중 주일(146건)뿐이고, 재의 수요일·성 금요일·부활대축일의 '2'(26건)는 그날의 **다른 독서 선택지**다.
- **`cov` 는 연속 구간마다 한 행** — ref 를 `[min, max]` 로 뭉개면 `시편 80:1-7,17-19` 가 `80:1-19` 가 되어 **읽지도 않는 8~16절이 그날의 독서로 검색**된다(3,214행 중 465행).

## 새로 확정한 것

- **id 슬러그 규칙** (좌표만의 순수 함수 — 정렬·입력 순서·기사 수에 의존하지 않는다)
- **슬롯 배정** — core 3칸/4칸. 다만 위치로 우기지 않고, 마지막 칸이 복음서가 아니면 복음 없는 날로 본다.
- **세트 번호는 결정적 정렬로** — 입력 순서에 기대면 재스크랩 한 번에 id→독서 매핑이 뒤집힌다(§10 "잠정 순번 id 금지"의 재발). 실제로 폐기된 2019년 자료가 기본 세트를 차지하고 있었다.

## 검증이 놓치고 있던 구멍

§2 가 요구한 "모든 ref 가 실존 절 범위인지 대사" 를 **장의 최대 절만 비교**하는 것으로 구현하면 **장 중간의 결번을 놓친다.** 그 구멍으로 두 건이 빠져나가 리포트가 "오류 0" 을 찍고 있었다.

- **루가 1:68** — `[68]` 마커 유실로 즈가리야의 노래 첫 소절이 67절에 흡수. 본문은 화면에 나오지만 **그 절을 번호로 부를 수 없어** 전례독서·인용·북마크·딥링크가 전부 못 찾았다.
- **히브 1:12** — 성탄 낮 제2독서의 마지막 절, 같은 유실.

둘 다 복구했고 `tests/test_verse_gaps.py` 로 73권 전체 결번을 못박았다.

## 미결 사항에 추가

- 교회력 격자의 빈 칸 6개(사순5주 나해 등) — 원료에 그 날 기사가 없다
- 에스델 하위 절(`4:17(12-16)`) 표기 — `verseSpec` 문법 확장 여부(ADR-010 과 공유)
- 날짜를 모르는 성인일 3건 — ADR-036 §9 성인 달력 2차와 동기

문서 전용이라 앱 코드 변경 없음. 다음은 A1(교회력 계산 엔진).
