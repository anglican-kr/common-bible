# feat: 북마크 폴더 단위 모아 읽기 화면 (ADR-035)

## 요약

북마크 **폴더마다** 본문을 하나의 연속 읽기 화면으로 모아 봉독하는 기능. 각 폴더 행의 `읽기`(menu_book 아이콘) 버튼 → `/bookmarks/read/<folderId>`.

스크린샷의 사용 패턴(한 전례의 제1독서·제2독서·복음서·시편을 폴더로 묶음)을 그대로 한 화면에서 읽도록 한다.

## 동작

- **진입점**: 폴더 행의 `읽기` 버튼(상시 표시, 선택 모드에선 숨김). 폴더 = 전례 독서 묶음이라 폴더 단위로 독립 읽기.
- **순서/구성**: 북마크 목록에 보이는 순서 그대로, **네스팅 폴더는 소제목**으로(부모 폴더 읽기 = 하위 전체 포함, 하위 폴더는 자기 행으로 독립 읽기도 가능).
- **이어 붙이기**: 목록에서 **인접 + 연속**(같은 책의 연속 절/장, 예: `창세 1장` + `창세 2:1-3,4a`)이면 끊김 없이 병합하고 합친 참조 제목(`창세 1:1–2:4a`)으로 표시. 폴더 경계는 병합을 끊는다.
- **공유**: `localStorage` 북마크에서 클라이언트 생성 → URL을 보내도 상대 기기엔 재현되지 않음(**사실상 공유 불가**, 의도된 성질). 정규 URL/sitemap 미포함.

## 구현

- `renderChapter`의 절 렌더 루프(시·산문·인용 칩·절 번호·단락 구분 ~180줄)를 **`appendVerses(article, verses, opts)`로 추출** → 절 부분집합 렌더를 공유. `renderChapter`는 한 줄 위임(동작 동일).
  - 🌱 이 절-부분집합 렌더러는 향후 **감사성찬례 전례독서 페이지 자동 생성**(교회력 입력 → 같은 렌더 경로)의 기반 기술.
