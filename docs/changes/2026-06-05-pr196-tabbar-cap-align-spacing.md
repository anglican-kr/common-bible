# style: 끝 탭 인디케이터 캡 정렬 + 하단 chrome 간격 대칭

## 요약

ADR-030 모바일 탭 바의 두 가지 정렬 문제를 바로잡았습니다.

### 1. 양 끝(홈·설정) 인디케이터가 pill 캡과 어긋나 초승달 sliver 가 보임
- 직전 변경에서 `.tab-item { flex: 1 }`(균등 컬럼)이라 끝 아이콘이 컬럼 중앙에 놓여, 끝 인디케이터(정원)와 pill 둥근 캡 사이에 초승달 모양 틈이 남았습니다.
- `.tab-item` 을 `flex: 0 1 auto`(콘텐츠 폭 = 인디케이터 폭)로 바꾸고 `#tab-bar { justify-content: space-between }` 으로 양 끝 탭을 캡 안쪽에 밀어넣어, **끝 인디케이터가 캡 내부 정원과 동심으로 겹치게** 했습니다. 중간 두 탭(북마크·노트)은 균등 분배.
- 좁은 화면은 `flex-shrink` + `.tab-icon-wrap { max-width: 100% }` 로 이웃 침범 방지.

### 2. 하단 chrome(홈·미니 오디오·검색) 간격 비대칭 + 홈 좌측 ≠ 검색 우측 여백
- **근본 원인**: 직전에 넣은 `#tab-dock { gap: --space-2 }` 가 dock 의 마지막 자식 **`#tab-search-close`**(키보드 전용, idle `width: 0`)와 `#tab-search-dock` 사이에도 끼어, 검색 원형이 8px 왼쪽으로 밀렸습니다 → 검색 우측 여백(24px) ≠ 홈 좌측 여백(16px), 그리고 홈↔오디오↔검색 간격 불균등.
- base dock gap 을 제거하고(원래 설계대로 idle 은 `margin-left:auto` 우측 정렬), 탭 바↔검색 8px 간격은 **`#tab-bar { margin-right: --space-2 }`** 로 옮겼습니다(width:0 닫기 버튼 앞에 gap 이 끼지 않음).
- 검색 모핑 중 입력↔닫기 간격은 기존 `#tab-dock.searching { gap }` 이 그대로 담당하고, `.searching/.collapsed #tab-bar { margin-right: 0 }` 으로 이중 간격(16px)을 방지.

**결과**: 홈 좌측 여백 = 검색 우측 여백 = `--space-4`(16px), 홈↔오디오 = 오디오↔검색 = `--space-2`(8px) — 축소 오디오 바의 `left/right` calc 과 정확히 일치.
