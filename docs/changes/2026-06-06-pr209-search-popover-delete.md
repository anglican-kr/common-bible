# feat: 북마크 ⋯ 메뉴 일괄 삭제(다중 선택 + 확인) 구현

## 요약

북마크 뷰의 **⋯ 더 보기 메뉴**(스크린샷의 팝오버 액션 메뉴) 맨 아래에 파괴색 **"삭제"** 항목을 추가해, 북마크든 폴더든 **한 번에 골라 지우는 다중 선택 흐름**을 구현했습니다. 요청하신 대로 (1) 삭제 대상을 고르는 **체크박스**와 (2) 실제 삭제 전 **확인 메시지**를 모두 갖췄습니다.

## 동작

1. ⋯ 메뉴 → **삭제** (휴지통 글리프, danger 색) → `#bm-bulk-delete-modal` 오픈
2. 트리 전체를 **pre-order(폴더 → 자식, depth 들여쓰기)** 체크박스 목록으로 펼침
   - **tri-state "전체 선택"**
   - **폴더 cascade** — 폴더를 체크하면 그 하위 행이 체크+비활성(폴더와 함께 삭제됨), `삭제 (N)`의 N은 실제 제거될 노드 수
3. **`삭제 (N)`** → 곧장 지우지 않고 기존 **공유 파괴 확인 알림(`#bm-confirm-modal`)** 을 스택해 최종 확인
4. 확인 시 `removeItemById`(폴더는 splice 로 subtree cascade) + `_forgetViewed`(중첩 북마크 viewed 맵 정리) + 재렌더 + 헤더 갱신
5. 목록이 비면 메뉴의 삭제 항목 비활성

## 구현 메모

- **기존 패턴 재사용**: chapter-delete 선택 모달 구조 + `createOverlay`(ADR-032) + `_selectAllState`/`_deleteBtnLabel` 헬퍼
- **스택**: 모달 z-index 74/75 로 confirm(76/77) 아래에 둬 알림이 위로 뜨고, Escape 라우터에 `confirm > bulk-delete > …` 순으로 삽입
- **순수 헬퍼 신설**: `_flattenBookmarkTree`(depth/parentId 태깅), `_descendantIds`(폴더 subtree id) — `BOOKMARK_QUERY` 블록에 추가
