# docs: 쓰지 않는 기록을 정리한다

## 요약

docs 재구성 시리즈의 첫 PR이다. 사용자가 2026-10-22에 「읽지도 않는 쓰레기같은 정보는 남기고 싶지 않고, 너와 내가 협업하는데 필요한 정보들만 유지하고 싶고, 일관성 있는 형태의 정보 아카이브가 필요해」라고 했다. 시리즈의 목표는 docs/를 작업 영역별 문서로 다시 짜는 것이다. 이 PR은 그 전에 쓰지 않는 기록을 지운다.

- **소급 원장 340개를 지웠다.** #331이 원장 제도를 세우며 들여온 옛 PR 본문 308개와 worklog 블록 32개다. 표본을 확인한 결과 이 파일들에만 있는 정보는 없었다. PR 본문 원본은 GitHub에, worklog는 git 이력에 있다. 원장 디렉터리에는 2026-09-20 이후의 원장 33개만 남는다.
- **원장 게이트에 일회성 예외를 두었다.** CI(`ledger.yml`)와 커밋 훅(`pre-commit-ledger.sh`)은 머지된 원장의 수정과 삭제를 막는다. #331이 들여온 340개의 삭제만 허용하도록 고쳤다. 고치기와 이름 바꾸기는 계속 막는다. 삭제가 머지되면 예외가 하는 일이 없으므로 시리즈의 다음 정리 PR에서 지운다.
- **PRD, GEMINI.md, QA 보고서를 지웠다.** `docs/prd.md`는 5월 이후 갱신되지 않았다. `GEMINI.md`는 5월에 쓴 다른 에이전트용 지시문이다. `docs/archive/qa/`의 보고서 28개는 6월 22일 이후 새로 쓰이지 않았다. PRD의 대상 사용자, 핵심 가치, 제품 원칙은 `architecture.md` §1 끝으로 옮겼다.
- **Claude의 비공개 메모에만 있던 할 일을 known-issues로 옮겼다.** 새 번호 §20-§25를 두고, 기존 §6, §11, §12에도 더했다. 보안 항목 셋은 공개 저장소에 적지 않고 비공개 server 저장소에 따로 기록한다.

## 확정 · 근거

- 사용자 결정(2026-10-22): 소급 원장 340개는 지운다. 선택지는 archive로 옮기기, 지우기, 그대로 두기였고 사용자가 지우기를 골랐다. `docs/prd.md`, `docs/archive/qa/`, `GEMINI.md`도 지운다.
- 사용자 결정(2026-10-22): 메모리에 멈춰 있던 작업 가운데 노트 탭(ADR-026) 재개, 모바일 북마크 드로어 정리, 디자인 시스템 아티팩트는 계속한다. CSP 위반 보고 받기와 Google Search Console 수동 크롤링 요청은 지운다.
- 사용자 허용(2026-10-22): 커밋 훅 수정. 자동 모드 분류기가 훅 편집을 「CI 우회」로 막아 사용자에게 물었고, 사용자가 「훅 수정 허용」이라고 답했다.
- 즈가리야 2장의 절 번호 의심은 계획과 달리 설계서 미결16이 아니라 known-issues §25에 두었다. 미결16은 축일 이동 날짜의 대조라 주제가 다르고, 설계서는 구조를 테스트가 검사한다.
- data PR #14 리뷰 후속 여덟 가운데 `_review` 발행은 없어졌고, 추수감사주일의 `commemorate_only`는 엔진이 처리한다. 나머지 여섯과 도미닉 날짜는 data 저장소(`cbae51a`)에 그대로 있음을 확인했다.
- 절 번호 중복 다섯 곳(욥 32:9 등)이 지금 데이터에도 그대로 있음을 확인했다.
