# 성무일과 설계

> 구현하기 전에 쓰는 설계다. 정한 것은 ADR-056(엔진), ADR-057(성무일과 독서 화면), ADR-058(캘린더 목록과 내려오는 달력), ADR-060(전례독서 화면의 세 탭과 주간 라벨 목록)에 적었고, 예식문 화면(§6)은 「미결」(§7)을 정한 뒤 ADR-059로 옮긴다.

- 작성: 2026-11-24
- 상태: 작성 중. 엔진 규칙은 ADR-056에, 독서 화면과 캘린더는 ADR-057과 ADR-058로 정했다가 ADR-060으로 바꾸었고, 예식문 화면은 미결이다
- 상위 결정: ADR-042(성무일과 전례독서 데이터), ADR-056(성무일과 엔진), ADR-057(성무일과 독서 화면), ADR-058(캘린더 목록과 내려오는 달력), ADR-038(캘린더와 전례독서 화면), ADR-036(전례일과 교회력 표), ADR-039(데이터 저장소. 전례시편 `lps`와 성무일과 송가 `cant`), ADR-045(오프라인 저장), ADR-001(로드맵의 넷째 단계 「성무일과 본문 자동 생성」)
- 실측 기준: 데이터 저장소 `82c056b`(2026-11-24, data#96). 이 문서의 숫자와 견본은 이 커밋에서 읽었다.

## 1. 목표와 범위

기도서의 아침기도와 저녁기도를 날짜에 맞춰 보여 준다. 두 단계로 만든다.

| 단계 | 보여 줄 것 | 쓰는 사람 |
| --- | --- | --- |
| 1. 독서 | 캘린더 목록의 줄에서 그날 성무일과의 장절을 보고, 성무일과 독서 화면에서 시편과 독서를 감사성찬례 독서처럼 바로 읽는다 | 기도 예식을 따르지 않고 그날의 성서만 읽는 사람 |
| 2. 예식문 | 그날의 시편, 독서, 송가, 본기도가 제자리에 들어간 아침기도와 저녁기도 전체 | 아침기도와 저녁기도를 드리는 사람 |

두 단계를 따로 두는 까닭은 이렇다. 아침기도와 저녁기도가 습관인 교인이 많지 않다. 독서를 예식문 안에만 두면 예식문이 부담스러운 사람은 독서도 읽지 않게 된다. 독서만 읽는 길을 먼저 연다. 두 단계는 같은 엔진(§4)을 쓴다.

이 설계에서 다루지 않는 것은 다음과 같다.

- 낮기도, 밤기도, 간략한 기도 예식. 데이터에는 있지만(§2) 만들지 않는다.
- 성무일과 독서의 검색(`docs/design/lectionary-search.md` §8이 자리만 두었다)과 시작 화면 설정의 「성무일과」(ADR-041 §2). 화면이 생긴 뒤에 정한다.

## 2. 지금 있는 것

**데이터 둘**(데이터 저장소 `lectionary/`). 앱은 아직 어느 것도 읽지 않는다.

- `office-readings.json`(ADR-042): 기도서 508-554쪽의 표. 날 하나와 해 하나가 레코드 하나이고 모두 804개다. 칸마다 `office`가 `morning`, `evening`, `day` 가운데 하나다.
- `daily-office.json`(data#96): 기도서 148-191쪽의 예식문. 일러두기 일곱, 예식 여섯(아침기도, 낮기도, 저녁기도, 밤기도, 간략한 기도 예식, 성무일과 송가), 요일별 송가 배정표. 줄은 인쇄된 한 줄씩이고, 시편과 송가는 정본(`lps`, `cant`)을 `ref`로 가리킨다.

**엔진**(`js/app/liturgical-engine.js`). 날짜에서 전례일, 절기와 주, 전례색, 감사성찬례 독서와 본기도를 구한다. 성무일과에 관한 것은 없다. 해 1과 해 2를 구하는 함수도 없다.

**화면**(`js/app/lectionary.js`). 전례독서 날 화면(`/lectionary/YYYY-MM-DD`)은 캘린더 탭에 속하고, 날짜 이동 줄, 그날 머리, 본기도, 독서 구역으로 이루어진다. 탭은 없다. ADR-038이 대안 세트를 탭으로 보이는 안을 버렸는데, 까닭은 탭마다 따로 보일 화면이 없어서였다.

## 3. 정한 것

1. 독서와 예식문을 둘 다 만들고, 독서를 먼저 만든다(§1).
2. 하루의 독서 셋은 아침에 구약, 저녁에 서신과 복음을 싣는다. 「전례독서」 책자를 따른다(ADR-056 §3).
3. 예식은 아침기도와 저녁기도만 한다(§1).
4. 성무일과 독서는 전례독서 화면의 아침기도, 저녁기도 탭이다. 처음 여는 탭은 감사성찬례다(§5, ADR-060 §1. ADR-057 §1의 따로 된 화면을 대체했다).
5. 캘린더 목록은 주일마다 주간 라벨을 두고, 줄마다 그날의 감사성찬례, 아침기도, 저녁기도의 장절을 적는다. 줄 전체가 그날 전례독서 화면으로 가는 링크 하나다(ADR-060 §2. ADR-058 §2의 링크 둘을 대체했다). 작은 화면(휴대폰)의 캘린더는 목록 보기 하나이고, 월간 달력은 상단 바 오른쪽 아이콘을 누르면 내려오며, 날짜 고르기 시트는 없앤다. 전례독서와 성무일과 화면에서도 같은 달력이 내려오고, 날을 누르면 그날의 같은 독서 화면으로 간다. 큰 화면(태블릿, 데스크톱)은 월간과 목록을 그대로 두고, 월간 칸을 누르면 목록의 그날 줄로 간다(§5, ADR-058).
6. 독서 후 송가는 예식문의 짝을 기본으로 하고, 설정으로 송가 배정표를 켠다(§6, §7의 1).

## 5. 독서 화면(1단계)

**2026-11-27에 ADR-060으로 바뀌었다.** 성무일과 독서는 전례독서 화면 상단 바 둘째 줄의 아침기도, 저녁기도 탭이고, 캘린더 목록의 줄은 링크 하나다. 이 절의 아래 그림과 글은 ADR-057과 ADR-058로 정했던 2026-11-25의 설계다. 내용(아침에 시편과 구약, 저녁에 시편과 서신과 복음)과 다시 쓸 함수는 탭에 그대로 쓴다. 바뀐 모양은 디자인 캔버스의 「전례독서 탭」, 「전례독서 본문」, 「캘린더 목록」 페이지에 있다.

**캘린더 목록의 줄**(ADR-058 §2, 두 레이아웃 모두). 줄마다 두 독서의 장절을 적고, 각각 그 독서 화면으로 간다. 줄 안에 가로선을 두지 않는다. 제목의 요일은 왼쪽 날짜 칸과 겹쳐 뺀다(「연중 34주 화요일」은 「연중 34주」). 「감사성찬례」와 「성무일과」는 따로 한 줄에 적고 그 아래에 장절을 적는다.

```
┌────────────────────────────────────┐
│ 오늘     ‹ 2026년 11월 ›        ▦  │  ▦를 누르면 아래로 달력이 내려온다
├────────────────────────────────────┤
│ 24  연중 34주                      │
│ 화  ● 녹색  짝수해                 │
│     성프란시스수녀회 설립 기념일   │
│     감사성찬례                     │
│     묵시 14:14-19 · 시편 96 ·      │ ›  → /lectionary/2026-11-24
│     루가 21:5-11                   │
│     성무일과                       │
│     아침 시편 [120], 121, 122, 123 │ ›  → /office/2026-11-24
│     · 즈가 11:4-17                 │
│     저녁 시편 124, 125, 126, [127]│
│     · 1고린 3:10-23 ·              │
│     루가 18:31-43                  │
├────────────────────────────────────┤
│ 25  연중 34주                      │
│ …                                  │
```

- 줄의 높이(2026-11-25 견본): 11월 24일 줄이 지금 100px이고, 이 모양으로 390px에서 261px, 320px에서 303px다. 성무일과를 아침과 저녁 두 줄로 적은 뒤 다시 재었다. 이름을 장절 앞에 붙이면 227px(320px에서 249px), 줄 안에 가로선을 두면 283px였다. 390px 화면에 보이는 날이 약 6일에서 3일이 채 안 되게 준다.
- 감사성찬례의 장절은 전례독서 화면이 처음 보이는 독서 하나다. 트랙이나 대안 독서가 있는 날에도 하나만 적는다.

**내려오는 월간 달력**(ADR-058 §3, 작은 화면). 큰 화면은 월간 보기와 날짜 고르기를 그대로 두고, 월간 칸을 누르면 목록의 그날 줄로 간다(ADR-058 §1). 날짜와 전례색 점만 있는 달력이 상단 바 아래로 내려온다. 날을 누르면 달력이 올라가고 목록이 그 날짜의 줄로 간다. 전례독서와 성무일과 화면의 같은 아이콘도 이 달력을 내리고, 날을 누르면 그날의 같은 독서 화면으로 간다.

```
┌────────────────────────────────────┐
│ 오늘     ‹ 2026년 11월 ›       [▦] │
├────────────────────────────────────┤
│ 2026년 11월 ⌄               ‹   ›  │  머리를 누르면 달 판, 해 판
│  일  월  화  수  목  금  토        │
│   1   2   3   4   5   6   7        │
│   ·   ·   ●   ●   ●   ·   ●        │
│  …                                 │
│  29  30                            │
│   ●   ●                            │
╰────────────────────────────────────╯
│ (뒤의 목록은 흐리게)               │
```

**성무일과 독서 화면**(ADR-057). 주소는 `/office/YYYY-MM-DD`다.

```
┌────────────────────────────────────┐
│ 2026년 11월 24일   ‹  ›  [24]  ▦  │  [24]: 오늘(ADR-061), ▦: 달력을 내린다, 날을 누르면 그날 성무일과
├────────────────────────────────────┤
│ 연중 34주 화요일                   │
│ ● 녹색 · 해 2                      │
│                                    │
│ 아침기도                           │
│ 시편 121, 122, 123 〔시편 120〕    │  추가할 수 있는 시편(미결3)
│   …본문…                           │
│ 1독서  즈가 11:4-17                │
│                                    │
│ 저녁기도                           │
│ 시편 124, 125, 126 〔시편 127〕    │
│   …본문…                           │
│ 2독서  1고린 3:10-23               │
│ 복음  루가 18:31-43                │
│                                    │
│ [아침기도 예식문] [저녁기도 예식문]│  2단계에서 생긴다
└────────────────────────────────────┘
```

- 언제나 「아침기도」와 「저녁기도」 두 구역이다. 하루의 독서는 아침에 구약, 저녁에 서신과 복음이고, 저녁 시편이 없는 다섯 줄의 날은 아침에 독서 셋을 싣는다(ADR-056 §3). 인쇄된 배치가 다른 날(주요축일, 12월 26-28일, 성주간과 부활주일의 일부, 전일과 전야)은 인쇄된 대로다.
- 본기도는 싣지 않는다. 성무일과의 본기도는 예식문 화면(§6)이 보인다.

**있는 것을 다시 쓴다.** 독서 구역은 `buildReading`, 장 받기는 `loadSlotChapters`, 생략할 수 있는 절의 표시는 `markOptionalVerses`, 반절은 `trimHalfVerses`, 날짜 이동 줄은 `commitDateBar`다. 내려오는 달력의 날 판은 날짜 고르기 시트의 날 판(`pickerDays`, `buildPickerDays`)이다.

## 6. 예식문 화면(2단계)

- 주소: `/office/YYYY-MM-DD/morning`, `/office/YYYY-MM-DD/evening`. 캘린더 탭에 속한다.
- 차례는 `daily-office.json`의 소제목 차례 그대로다. 날마다 바뀌는 자리만 엔진이 채운다.

| 자리 | 채우는 것 | 기도서의 근거 |
| --- | --- | --- |
| 시작송가의 초대 시편(아침기도) | 시편 95:1-7을 기본으로, 시편 100을 「또는」으로. 부활주일부터 성령강림주일까지는 부활송가 | 149-150쪽 「아래의 시편 중에 하나를 선택한다」, 「부활주일에서 성령강림주일까지는 아래의 송가를 사용한다」 |
| 오늘의 시편 | 그날 아침 또는 저녁의 시편. 한 편이 끝날 때마다 송영 | 151, 164쪽 「성시 끝마다 아래 송영을 한다」 |
| 성서독서와 독서 후 송가 | 아침기도: 1독서(구약) → 송가. 저녁기도: 1독서(서신) → 송가 → 2독서(복음) → 송가. 아침에 독서가 셋인 날은 무엇을 읽을지 정해야 한다(미결1) | 508쪽 「2독서까지 읽는다면 복음을 포함한다」, 182쪽 「모든 독서 후에는 송가를 한다」, 「독서가 하나일 경우 첫 번째 송가를 한다」 |
| 독서 후 송가 | 기본은 예식문의 짝이다. 아침기도는 즈가리야송가와 이사야 첫째 송가, 저녁기도는 성모 마리아송가와 시므온송가. 설정에서 송가 배정표를 켜면 그날의 요일과 절기에 맞는 송가로 바뀐다(미결1) | 152, 164쪽, 182-183쪽 |
| 오늘의 본기도 | 그날 지정 전례일의 본기도. 전례독서 화면과 같은 조회(`findCollects`) | 155, 167쪽 「교회력에 따른 오늘의 본기도를 드린다」 |
| 그 밖의 기도 | 인쇄된 본문 그대로 | |

- 인도자(○)와 회중(⦿)의 줄을 구별해 보인다. 안내(빨간 글자)는 본문과 다른 모양으로 보인다.
- 선택 안내(「여기서 특별한 의향의 기도를 드릴 수 있다」, 「위의 기도 대신에 아래 별세자를 위한 기도를 드릴 수 있다」, 「마감성가를 부를 수 있다」. 저녁기도는 「마침성가」로 인쇄되어 있다)는 안내 글로 그대로 보인다.
- 시편과 송가의 본문은 정본(`lps`, `cant`)에서 그린다. 정본이 없는 부활송가와 「은혜로운 빛이여」만 `daily-office.json`의 본문을 쓴다.
- 「성서독서」와 「독서 후 송가」는 데이터에 따로 차례로 있다. 독서와 송가를 번갈아 엮는 일은 앱이 한다.

목업은 미결4를 정한 뒤에 그린다. 결정은 ADR-059로 옮긴다.

## 7. 미결

번호는 이 문서 안에서만 쓴다. 「전례독서」 책자 2025-2027년과 대조해 닫은 미결(축일을 지키는 날의 독서, 12월 17일-1월 12일의 주일, 12월 26-31일 안내의 범위, 옮긴 축일의 전야)은 ADR-056 §2에 있다.

1. **송가 배정표를 켰을 때의 세부.** 독서 후 송가는 예식문의 짝(152, 164쪽. 아침기도에 즈가리야송가와 이사야 첫째 송가, 저녁기도에 성모 마리아송가와 시므온송가)을 기본으로 하고, 설정으로 송가 배정표(182-183쪽 「다양한 송가의 사용을 원하면」. 예: 화요일 아침은 찬양송가와 어린양송가)를 켜기로 정했다. 설정은 처음에 꺼져 있다. 늘 예식문의 짝만 쓰는 안과 늘 배정표를 쓰는 안은 채택하지 않았다.
   - 남은 것은 배정표에 적혀 있지 않은 세 가지다. 절기 칸에 송가가 하나뿐인 곳(월요일 저녁 사순절: 참회송가)이 첫째 송가만 바꾸는지, 성탄과 성주간이 어느 절기 칸인지, 「대축일, 주의 축일」 줄에 성모 축일이 해당하는지.
   - 목요일 아침은 통상 칸에도 송가가 하나(모세송가)뿐이다. 독서를 둘 읽으면 둘째 송가를 무엇으로 할지 정해야 한다. 182쪽은 「독서가 하나일 경우 첫 번째 송가를 한다」만 적는다.
   - 아침기도는 독서가 하나(구약)뿐이라(ADR-056 §3), 182쪽대로면 첫째 송가(즈가리야송가)만 한다. 아침에 독서가 셋인 날(12월 24일, 1월 5일 등)에 예식문이 무엇을 읽고 송가를 몇 번 할지 정해야 한다.
   - 설정의 이름과 자리는 예식문 화면의 목업과 함께 정한다.
2. **전야의 저녁기도.** 전야 줄은 전날의 저녁기도로 쓴다(ADR-056 §2). 그날 저녁기도의 본기도를 다음 날 축일의 것으로 할지는 정하지 않았다. 전야 줄이 밤기도용일 수 있다는 의문(ADR-042 미결 11)은 148-191쪽에 답이 없었다.
3. **생략할 수 있는 시편과 절의 기본 표시**(ADR-042 미결 1). `[ ]`(시편 한 편)와 `( )`(절)를 기본으로 보일지 감출지. 감사성찬례 화면은 생략할 수 있는 절을 〔 〕로 묶어 함께 보인다. 「전례독서」 책자 일러두기 5항은 `( )`를 「포함하거나 생략할 수 있는」, `[ ]`를 「추가할 수 있는」 것으로 적는다.
4. **시각에 따른 기본 예식.** 저녁에 예식문을 열면 저녁기도를 먼저 보일지. 감사성찬례의 저녁 전례에도 같은 미결이 있다(ADR-038, `docs/topics/liturgical.md`).
5. **전일과 전야가 있는 날 머리의 해.** ADR-057 §3은 해가 정해지지 않은 줄(전일과 전야)에는 해를 보이지 않는다. 그런데 2026-12-24는 아침이 해 1의 줄이고 저녁이 해 없는 성탄 전일의 줄이다. 권장은 아침 줄의 해(「해 1」)를 보이는 것이다.
6. **「또는」이 있는 시편과 독서.** 데이터의 37칸에 있다(예: 2027-04-04 저녁 「로마 5:12-21 또는 갈라 4:1-7」, 연중 3주 목요일 저녁 「시편 [59, 60] 또는 시편 118」). 「전례독서」 책자는 둘을 모두 적는다. 감사성찬례는 독서 카드로 하나를 고른다(ADR-038 §3). 권장은 목록 줄에는 앞의 것만 적고(감사성찬례의 줄과 같다), 성무일과 화면에는 앞의 것과 「또는」 뒤의 것을 모두 보이는 것이다. 카드를 두지 않는 까닭은 성무일과가 시편 여러 편과 독서를 한 줄로 이어 보이기 때문이다.

## 8. 구현 차례

1. 문서: 이 설계, ADR-056, ADR-057, ADR-058. 미결을 정한 뒤 ADR-059(예식문의 조립과 화면)를 쓴다.
2. 데이터 저장소: 성무일과 레코드에 달력 표의 전례일 id를 적는다(`liturgical/parse_office_readings.py`). 날짜가 인쇄된 전야에도 적는다(ADR-056 §4). 머지하기 전에 앱의 단위 테스트를 그 데이터로 돌린다(`docs/workflow.md`).
3. 앱: 엔진(ADR-056)과 서브모듈 포인터.
   - `office-readings.json`을 오프라인 저장 대상에 넣는다(`js/offline-save.js`의 `UNUSED`에서 뺀다. ADR-045 §1).
   - 포인터는 이미 data#96(`82c056b`)이라 `daily-office.json`이 지금 오프라인 저장 대상에 들어 있다. 예식문 화면이 생길 때까지 `UNUSED`에 넣어 둔다.
   - `office-readings.json`은 캘린더 목록이 감사성찬례 독서 묶음과 함께 받는다(ADR-056 §5).
4. 앱: 캘린더 개편(ADR-058. 목록 줄의 두 독서 말고는 2026-11-26에 구현했다. 목록 줄은 ADR-060 §2로 바꾸어 주간 라벨과 감사성찬례 장절을 먼저 구현하고, 아침기도와 저녁기도 장절은 엔진과 함께 넣는다). 작은 화면에서는 월간 화면과 날짜 고르기 시트를 없애고, 캘린더와 전례독서 화면에 내려오는 달력을 넣는다. 큰 화면에서는 월간 칸이 목록의 그날 줄로 가게 한다. 두 레이아웃 모두 목록 줄에 세 독서의 장절을 적는다.
5. 앱: 전례독서 화면의 아침기도, 저녁기도 탭(ADR-060 §1. ADR-057의 따로 된 화면을 대체했다).
6. 앱: 예식문 화면(§6).

5와 6에서 새 화면 모듈을 넣을 때는 `js/app/routing.js`의 주소 풀이와 늦게 받는 모듈 목록, `sw.js`의 `SHELL_FILES`, `js/app/views.js`의 `LITURGICAL_VIEWS`, `js/app/tab-history.js`의 `tabOf`와 `pickCalendarTabDest`, `js/app/tabbar.js`의 `syncTabBarActive`, `tests/unit/sw.test.js`를 함께 고친다.
