# 설치, 런치 스크린, 접근성

소유 코드: `js/app/install.js`

PWA 설치 안내와 런치 스크린(스플래시)을 다룬다. 접근성(WCAG 2.1 AA)은 모든 주제에 적용되는 기준이라, 이 문서에는 설치 화면에 해당하는 것만 적는다.

## 지금 동작

- **런치 스크린과 설치 안내**는 Phase 1(2026-05)에 완성됐다. 스플래시 이미지는 `scripts/generate_splash.py`가 만들고(ADR-007), 설치 안내는 세 장면으로 보여 준다(ADR-008).
- **인앱브라우저**(카카오톡, 라인, 네이버, 인스타그램, 페이스북)로 들어오면 첫 화면을 그린 직후 기기의 브라우저로 옮긴다(2026-11-13, ADR-008 §7). 탭 세션에서 한 번만 시도한다. 옮기지 못했거나 이름을 모르는 웹뷰면 본문은 그대로 읽히고, 설치 안내 모달이 「브라우저에서 열기」와 「주소 복사」를 보인다.

## 결정

- ADR-008 「PWA 설치 가이드 전략」

## 남은 일

- **인앱브라우저 자동 전환을 실기기에서 확인한다** (2026-11-13). 특히 iOS의 `x-safari-https://`는 Apple이 문서로 밝히지 않은 주소 형식이다. 동작하지 않는 앱은 자동 전환 목록에서 뺀다.
