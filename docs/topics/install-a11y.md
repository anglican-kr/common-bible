# 설치, 런치 스크린, 접근성

소유 코드: `js/app/install.js`

PWA 설치 안내와 런치 스크린(스플래시)을 다룬다. 접근성(WCAG 2.1 AA)은 모든 주제에 적용되는 기준이라, 이 문서에는 설치 화면에 해당하는 것만 적는다.

## 지금 동작

- **런치 스크린과 설치 안내**는 Phase 1(2026-05)에 완성됐다. 스플래시 이미지는 `scripts/generate_splash.py`가 만들고(ADR-007), 설치 안내는 세 장면으로 보여 준다(ADR-008).
- **인앱브라우저**(카카오톡, 라인, 네이버, 인스타그램, 페이스북)로 들어오면 첫 화면을 그린 직후 기기의 브라우저로 옮긴다(2026-11-13, ADR-008 §7). 탭 세션에서 한 번만 시도하고, 문서를 다 읽는 데 3초가 넘게 걸리면 그 방문에서는 옮기지 않는다. 넘기는 주소에는 「이미 넘긴 주소」 표시(`openExternalBrowser=1` 쿼리)를 붙여, 그 주소가 다시 인앱브라우저에서 열리면 옮기지 않는다. 기기의 브라우저에 도착하면 표시를 지운다. Android에서 기본 브라우저가 네이버 앱이면 넘긴 주소가 네이버 앱에서 열리는데, 이 탭은 일반 Android 브라우저로 대한다(네이버 앱은 메뉴의 「홈 화면에 추가」로 설치할 수 있다, 2026-11-14). 옮기지 못했거나 이름을 모르는 웹뷰면 본문은 그대로 읽히고, 첫 방문에도 설치 안내 모달이 저절로 열려 「브라우저에서 열기」와 「주소 복사」를 보인다(2026-11-14). 「주소 복사」는 클립보드를 쓸 수 없으면 주소를 글상자에 보여 손으로 복사하게 한다.

## 남은 일

- **라인과 인스타그램의 자동 전환을 실기기에서 확인한다.** 카카오톡, 네이버, 페이스북은 iOS와 Android에서 동작을 확인했다(2026-11-14, ADR-008 §7). 동작하지 않는 앱은 자동 전환 목록에서 뺀다.
