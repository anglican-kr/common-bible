# 검색

소유 코드: `js/app/search.js`, `js/search-worker.js`

본문 검색(Web Worker와 청크 인덱스), 검색 옵션, 검색 기록을 다룬다. 검색 인덱스는 `common-bible-data`의 파이프라인이 만든다.

## 지금 동작

- **검색 옵션** (2026-06-07, 2026-06-09 개정, ADR-033).
  - 검색 필드 안에 토큰을 둔다(ADR-033 개정 B). 책 picker는 분류별로 여러 책을 고르는 시트(`#book-filter-sheet`)이고, 고른 책은 지울 수 있는 칩으로 보인다. 워커의 `restrictBooks`를 그대로 쓴다.
  - 빈 쿼리로 `/search`에 들어오면 최근 검색 목록을 보인다. 행 오른쪽에 검색 날짜를 절대 표기(`YYYY. M. D.`)로 적는다. ADR-014 개정으로 저장 모델에 `ts`를 더했고, 옛 `string[]`은 `{q,ts}`로 자동 마이그레이션한다. 헤더의 ▾ 드롭다운과 같은 `bible-search-history`를 쓴다.
  - 필터 상태는 주소에 넣는다(`?q&in&page`). 그래서 히스토리, 탭 복원(ADR-031), 페이지네이션, 공유가 모두 같은 상태를 본다.
  - 시트는 `createOverlay`(ADR-032)를 쓴다.
  - **「결과 내 검색」(AND)은 2026-06-09에 없앴다.** 좁히기 막대가 모바일에서 공간을 많이 차지하고, 데스크톱에서는 다른 요소와 겹치고, × 단추가 무엇을 하는지 정해지지 않았기 때문이다(ADR-033 개정). 자세한 것은 ADR-033과 ADR-014에 있다.

## 확정 사실

- **절 검색과 구절 바로가기는 히브리 본문(마소라) 절 번호를 기준으로 한다**(사용자 결정 2026-05-20). 데이터의 `number` 필드가 그 번호이고, 검색 인덱서(`common-bible-data`의 `src/search_indexer.py`)는 `number`만 인덱싱한다. 칠십인역 번호(`alt_ref`, 사본 이중 번호 `[N_M]`의 괄호 번호)와 불가타 번호는 검색에 쓰지 않는다. 시편의 장 번호처럼 번호가 어긋나는 곳이 있지만, 병기가 필요한 본문이 아직 없어 여러 번호 체계를 미리 잡지 않았다. 필요해지면(성무일과의 시편 교차 번호 등) ADR로 정한다. 칠십인역에만 있는 절(`[_N]`, `lxx_only`)은 히브리 번호가 없어 구절 바로가기로 갈 수 없는데, 이 원칙과 맞다. 절 표기의 권위는 data 저장소의 ADR-003이다.
