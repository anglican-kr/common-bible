# 검색

소유 코드: `js/app/search.js`, `js/search-worker.js`

본문 검색(Web Worker와 청크 인덱스), 검색 옵션, 검색 기록을 다룬다. 검색 인덱스는 `common-bible-data`의 파이프라인이 만든다.

## 확정 사실

- **절 검색과 구절 바로가기는 히브리 본문(마소라) 절 번호를 기준으로 한다**(사용자 결정 2026-05-20). 데이터의 `number` 필드가 그 번호이고, 검색 인덱서(`common-bible-data`의 `src/search_indexer.py`)는 `number`만 인덱싱한다. 칠십인역 번호(`alt_ref`, 사본 이중 번호 `[N_M]`의 괄호 번호)와 불가타 번호는 검색에 쓰지 않는다. 시편의 장 번호처럼 번호가 어긋나는 곳이 있지만, 병기가 필요한 본문이 아직 없어 여러 번호 체계를 미리 잡지 않았다. 필요해지면(성무일과의 시편 교차 번호 등) ADR로 정한다. 칠십인역에만 있는 절(`[_N]`, `lxx_only`)은 히브리 번호가 없어 구절 바로가기로 갈 수 없는데, 이 원칙과 맞다. 절 표기의 권위는 data 저장소의 ADR-003이다.
