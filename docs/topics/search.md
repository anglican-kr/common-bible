# 검색

소유 코드: `js/app/search.js`, `js/search-worker.js`

본문 검색(Web Worker와 청크 인덱스), 검색 옵션, 검색 기록을 다룬다. 검색 인덱스는 `common-bible-data`의 파이프라인이 만든다.

## 지금 동작

- **검색 옵션** (2026-06-07, 2026-06-09 개정, ADR-033).
  - 검색할 책은 검색창 안에서 고른다(ADR-033 개정 B). 검색창 왼쪽의 깔때기 단추(책 선택기)를 누르면 분류별로 여러 책을 고르는 시트(`#book-filter-sheet`)가 열린다. 고른 책은 검색창 안에 칩(토큰)으로 보이고, 칩을 지우면 조건에서 빠진다. 고른 책 안에서만 찾는 기능은 검색 워커(검색을 화면과 따로 돌리는 스크립트)에 있던 `restrictBooks`를 그대로 쓴다.
  - 검색어 없이 검색 화면(`/search`)에 들어오면 최근 검색 목록을 보인다. 행 오른쪽에 검색한 날짜를 `YYYY. M. D.` 표기로 적는다. ADR-014 개정으로 검색 기록에 날짜(`ts`)를 함께 저장하게 됐고, 날짜 없이 저장된 옛 기록(`string[]`)은 새 형식(`{q,ts}`)으로 자동으로 바꾼다. 헤더의 ▾ 드롭다운도 같은 기록(`bible-search-history`)을 쓴다.
  - 검색어, 고른 책, 쪽 번호는 주소에 넣는다(`?q&in&page`). 그래서 뒤로 가기, 탭 복원(ADR-031), 쪽 넘기기, 링크 공유가 모두 같은 검색 결과를 보여 준다.
  - 책 고르는 시트는 공통 오버레이 함수(`createOverlay`, ADR-032)로 연다.
  - **「결과 내 검색」(AND)은 2026-06-09에 없앴다.** 좁히기 막대가 모바일에서 공간을 많이 차지하고, 데스크톱에서는 다른 요소와 겹치고, × 단추가 무엇을 하는지 정해지지 않았기 때문이다(ADR-033 개정). 자세한 것은 ADR-033과 ADR-014에 있다.
- **검색은 따옴표를 무시한다** (2026-11-06, ADR-005 「따옴표를 무시하는 일치」).
  - 검색어와 본문 모두에서 따옴표 여섯 가지(`"` `'` `“` `”` `‘` `’`)를 지우고 비교한다. 그래서 곧은 따옴표로 친 `"빛이 생겨라!"`도, 따옴표 없이 친 `빛이 생겨라! 하시자`도 창세 1:3(`“빛이 생겨라!” 하시자`)을 찾는다.
  - 따옴표만 친 검색어는 결과가 없다.
  - 결과 목록과 장 화면의 강조는 찾은 구간을 원래 본문 위치로 되돌려 감싼다. 구간 양끝의 따옴표는 강조에서 빠진다.

## 확정 사실

- **절 검색과 구절 바로가기는 히브리 본문(마소라) 절 번호를 기준으로 한다**(사용자 결정 2026-05-20). 데이터의 `number` 필드가 그 번호이고, 검색 인덱서(데이터 저장소 `common-bible-data`의 `src/search_indexer.py`)는 `number`만 인덱싱한다. 칠십인역 번호(`alt_ref`, 사본 이중 번호 `[N_M]`의 괄호 번호)와 불가타 번호는 검색에 쓰지 않는다. 시편의 장 번호처럼 번호가 어긋나는 곳이 있지만, 번호를 함께 적어야 하는 본문이 아직 없어 여러 번호 체계를 미리 정하지 않았다. 필요해지면(성무일과의 시편 교차 번호 등) ADR로 정한다. 칠십인역에만 있는 절(`[_N]`, `lxx_only`)은 히브리 번호가 없어 구절 바로가기로 갈 수 없는데, 이 원칙과 맞다. 절 표기의 권위는 데이터 저장소의 ADR-003이다.

## 남은 일

- **장 화면의 강조는 본문 조각 경계를 넘지 못한다** (2026-11-06 확인).
  - 장 화면은 본문을 인용 태그(`<cite>`) 경계에서 조각으로 나눠 그리고, 조각마다 따로 검색어를 찾아 강조한다(`views.js`의 `appendTextWithHighlight` 호출).
  - 그래서 조각 경계를 넘는 일치는 결과 목록에서는 찾고 강조하지만, 장 화면에서는 강조하지 않는다. 예를 들어 갈라 3:8을 `아브라함에게 너로`로 찾으면 「아브라함에게 “」와 인용 조각 「너로 말미암아…」가 나뉘어 있어 강조되지 않는다.
  - 원래 있던 한계다. 다만 따옴표를 무시하면서 인용 앞뒤의 따옴표를 건너뛰는 일치가 새로 생겨 이런 경우가 늘었다.
  - **고치는 법**: 절 하나의 조각을 이어 붙인 글에서 범위를 찾고, 각 조각에 그 범위의 겹치는 부분만 감싼다.
