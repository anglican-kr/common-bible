ADR-039 가 렌더 몫으로 남긴 전례 표기를 `appendVerses`(ADR-035)에 additive 로 얹었다 — 응답 반행 시각 구분 + 선창 끝 `◯`(응답이 실제로 따라오는 줄에만), 무번호 후속 구절은 번호 대신 `¶`, 긴 시편의 부(部)는 인쇄본 그대로 `(N)` 소제목. 저장 형식에는 글리프가 없고 표시할 때만 복원한다. **함께 고친 종전 결함:** 절 부분집합 렌더의 중복 제거 키가 `number+part+lxx_only` 뿐이어서 **같은 번호의 절이 조용히 버려졌다** — 77개 장에서 130절(전례시편 69편의 `¶` 구절, 에스델 4장 31절). 절의 정체를 온전히 담는 인스턴스 키(`verse-spec.js` `verseInstanceKey(s)` — 번호·반절·`alt_ref`·`lxx_only`·`versicle`·`chapter_ref`, 원본 중복 마커는 순번 폴백)로 바꿔 DOM id 도 여기서 파생하고, 딥링크 스크롤은 정확한 id 가 없으면 번호가 맞는 첫 span 으로 폴백한다(`/job/27/24`·`/hos/14/14`·`/dan/3/24` 가 종전엔 아무 일도 하지 않았다). `bookmark-read.js` 의 `_specCoversVerse`·`_chapterMaxVerse` 는 `verse-spec.js` 로 승격해 전례독서 뷰(A3)와 공유한다. 검증: 유닛 12건 신설(`verse-spec.test.js`) + e2e 8건 신설(`test_liturgical_render.py` — 계응·¶·부·에스델·교차참조·발췌·일반 장 무회귀), 유닛 808 · e2e 223 통과. **`data-vref`(북마크 저장 문법)는 아직 번호 단위** — 에스델 하위 절 표기는 ADR-010 verseSpec 문법 확장이 필요해 후속.
