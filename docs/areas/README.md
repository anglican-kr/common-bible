# docs/areas — 영역 문서

작업 영역마다 한 장이다. 그 영역에서 일하기 전에 이 문서 하나를 읽으면 지금 동작하는 것, 결정, 조심할 것, 남은 일을 알 수 있게 한다. docs 재구성(2026-10-22)에서 시작했고, 지금은 북마크 영역이 시범이다. 나머지 영역은 다음 PR에서 옮긴다.

## 틀

```markdown
# 영역 이름

소유 코드: `js/app/bookmark*.js`, `js/app/verse-spec.js`

(이 영역이 다루는 것과 다루지 않는 것, 두세 문장)

## 지금 동작
## 결정
## 확정 사실
## 함정
## 남은 일
```

- `## ` 제목은 위 다섯만 쓰고 이 순서를 지킨다. 「지금 동작」과 「남은 일」은 반드시 두고, 내용이 없으면 「없음」 한 줄을 쓴다. 나머지 셋은 내용이 있을 때만 둔다.
- **지금 동작**: 그 영역의 기능이 지금 어떻게 동작하는지 적는다. 구현 PR을 머지할 때 갱신한다. 옛 `status.md`가 하던 일이다.
- **결정**: 이 영역에 걸리는 ADR의 번호와 제목, 걸리는 절을 적는다. 결론은 ADR에 있으므로 다시 쓰지 않는다.
- **확정 사실**: ADR에 들어가지 않은 사용자 확정을 적는다. 날짜, 사용자의 말, 원장을 함께 적는다.
- **함정**: 이 영역에서 반복된 실수다. 제목은 `### pitfalls §N — 제목 (날짜)`로 쓴다. 여러 영역에 걸치는 함정은 `coding-pitfalls.md`에 남기고 여기서는 한 줄로 가리킨다.
- **남은 일**: 이 영역의 미해결 이슈다. 항목은 `- **known-issues §N.m** …`로 시작한다. 해소하면 지우고, `known-issues.md`의 대장에 해소 기록을 남긴다.

## 소유 규칙

- `js/` 파일은 한 영역 문서만 소유한다. 「소유 코드:」 줄에 glob으로 적는다.
- 사실은 그것을 구현하는 파일을 소유한 영역에 한 번만 적는다. 다른 영역은 한 줄로 가리킨다.
- 파일을 새로 만들거나 옮겨서 두 영역의 glob에 함께 걸리면 `tests/unit/docs-wiki.test.js`가 그 파일 이름을 대며 실패한다. 그 PR에서 「소유 코드:」 줄을 고친다. 모든 영역을 옮긴 뒤에는 어느 영역에도 속하지 않는 파일도 실패로 본다.

## 번호와 대장

- 「pitfalls §N」과 「known-issues §N.m」은 영구 번호다. 코드 주석, 머지된 원장, 데이터 저장소, 교회력 설계서가 이 번호로 가리킨다. 옮겨도 번호는 그대로 쓴다.
- 옮긴 항목은 옛 파일에 대장 줄을 남긴다.
  - `coding-pitfalls.md`: 절 제목을 그대로 두고, 본문 자리에 `→ [areas/<영역>.md](areas/<영역>.md) 「함정」으로 옮겼다(날짜).`를 적는다.
  - `known-issues.md`: 그 절 안에 `- §15.1 · §15.3 → [areas/<영역>.md](areas/<영역>.md)`를 적는다.
- 옛 참조를 만나면 `grep -rn "pitfalls §38" docs/`로 정의를 바로 찾는다.
- 새 함정과 이슈는 다음 번호를 받는다. known-issues는 PR 묶음이 아니라 이슈 하나에 번호 하나를 준다.
- `docs-wiki.test.js`가 대장 줄과 영역 문서의 정의가 하나씩 맞는지 검사한다.

## 작업 절차

- **작업을 시작할 때**: `docs/index.md`에서 영역을 찾아 그 문서를 읽는다. 결정을 바꿀 때만 ADR을 연다. 이력은 `git log --format='%h %s' -- <소유 코드>`로 본다. squash 커밋마다 그 PR의 원장이 들어 있다.
- **PR을 열기 전**: 원장을 쓰고, 같은 PR에서 영역 문서를 갱신한다. 지금 동작, 확정 사실, 함정, 남은 일 가운데 바뀐 것을 고친다.
- **검사**: `node --test tests/unit/docs-*.test.js`를 돌린다. 문서를 옮기거나 고쳐 쓴 PR은 `scripts/docs_facts_snapshot.py`의 `--kinds general`과 `--from` · `--into`로 사실이 빠지지 않았음을 보인다.
